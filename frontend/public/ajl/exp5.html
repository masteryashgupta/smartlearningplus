Experiment 5: Socket programming

Client-server communication using Socket and ServerSocket. The client sends a message, and the server prints it and replies.

Check Java is ready

Both commands must print a version. If javac is not recognised, the JDK is not on PATH.

Command Prompt
java -version
javac -version

Step 1: Make a folder and create both files

Use a separate folder so the names do not clash with the RMI experiment. Click Yes when Notepad asks to create each file.

Command Prompt
mkdir %USERPROFILE%\Desktop\ajl\socket
cd %USERPROFILE%\Desktop\ajl\socket
notepad Server.java
Command Prompt
notepad Client.java

Step 2: Code

Server.java
import java.io.*;
import java.net.*;

public class Server {
    public static void main(String[] args) {
        try {
            ServerSocket ss = new ServerSocket(5000);
            System.out.println("Server is waiting for client...");

            Socket s = ss.accept();
            System.out.println("Client Connected!");

            DataInputStream dis = new DataInputStream(s.getInputStream());
            String msg = dis.readUTF();
            System.out.println("Message from Client: " + msg);

            DataOutputStream dos = new DataOutputStream(s.getOutputStream());
            dos.writeUTF("Hello Client, Message Received!");

            dis.close();
            dos.close();
            s.close();
            ss.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}
Client.java
import java.io.*;
import java.net.*;

public class Client {
    public static void main(String[] args) {
        try {
            Socket s = new Socket("localhost", 5000);

            DataOutputStream dos = new DataOutputStream(s.getOutputStream());
            dos.writeUTF("Hello Server");

            DataInputStream dis = new DataInputStream(s.getInputStream());
            String reply = dis.readUTF();
            System.out.println("Server Reply: " + reply);

            dos.close();
            dis.close();
            s.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

Step 3: Compile and run in two windows

Window 1 (server). It prints a waiting message and stays running.

Command Prompt
cd %USERPROFILE%\Desktop\ajl\socket

java Server

Window 2 (client). Open a second Command Prompt and run this after the server is waiting.

Command Prompt

java Client
Server window: Client Connected! / Message from Client: Hello Server
Client window: Server Reply: Hello Client, Message Received!

Always start the server first, or the client shows Connection refused. If Windows Firewall asks about Java, click Allow.

How it works

  • The server opens port 5000 with new ServerSocket(5000).
  • accept() blocks until a client connects, then returns a Socket.
  • The client connects with new Socket("localhost", 5000). Use the server IP address for two different computers.
  • getOutputStream() sends data and getInputStream() receives it. writeUTF() and readUTF() send and read a text string.
  • Both programs must use the same port. Address already in use means an old server is still running.

Viva answers

  • Socket: an endpoint for communication between two machines.
  • Socket vs ServerSocket: ServerSocket waits for connections on the server. Socket is the actual connection, used by the client and returned by accept().
  • What does accept() do? It waits for a client and returns a Socket for talking to it.
  • TCP vs UDP: Socket and ServerSocket use TCP (connection-oriented, reliable). DatagramSocket and DatagramPacket use UDP (connectionless).
  • Port number: identifies which application on a machine receives the data. Ports 0 to 1023 are reserved.

Likely variations

  • Server reads a message and sends back its length.
  • Client types the message from the keyboard using Scanner.
