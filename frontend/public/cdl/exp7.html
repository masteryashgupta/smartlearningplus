Compiler Design Lab, 5CS4-22

Experiment 7: LEX program to validate mobile number, URL, identifier, date and time

Aim: Write a LEX program to identify a valid mobile number (and email id), URL, identifier, date (dd/mm/yyyy) and time (hh:mm:ss).

The manual's code for this experiment has errors (spaces inside the character classes, missing actions, no code for time). These programs are corrected and complete.

Run on Windows (Flex)

One-time setup

  1. Download WinFlexBison from GitHub: https://github.com/lexxmark/winflexbison/releases. Download the asset named win_flex_bison-2.5.25.zip (Flex 2.6.4). Do not download the "Source code" files.
  2. Extract the zip into C:\flex. It contains win_flex.exe and win_bison.exe.
  3. A C compiler is needed. Check with: gcc --version. If it is not recognised, install MinGW-w64 (for example through MSYS2).
  4. Save the downloaded .l files and any input files (test.txt, test.c) in C:\flex. Open Command Prompt in that folder (click the File Explorer address bar, type cmd, press Enter).

Source code

1. Valid mobile number

%{
#include<stdio.h>
%}
%%
^[6-9][0-9]{9}$    { printf("Valid mobile number\n"); }
^.+$                { printf("Invalid mobile number\n"); }
\n    ;
%%
int yywrap() { return 1; }

int main()
{
    printf("Enter mobile number:\n");
    yylex();
    return 0;
}

Invalid mobile number

4. Valid date (dd/mm/yyyy)

%{
#include<stdio.h>
#include<stdlib.h>
int leap(int y)
{
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}
%}
D31   (0[1-9]|[12][0-9]|3[01])
D30   (0[1-9]|[12][0-9]|30)
D28   (0[1-9]|1[0-9]|2[0-8])
M31   (0[13578]|1[02])
M30   (0[469]|11)
YEAR  [0-9]{4}

%%
^{D31}"/"{M31}"/"{YEAR}$    { printf("Valid date\n"); }
^{D30}"/"{M30}"/"{YEAR}$    { printf("Valid date\n"); }
^{D28}"/02/"{YEAR}$        { printf("Valid date\n"); }
^"29/02/"{YEAR}$           {
    if(leap(atoi(yytext + 6)))
        printf("Valid date\n");
    else
        printf("Invalid date (not a leap year)\n");
}
^.+$                        { printf("Invalid date\n"); }
\n    ;
%%
int yywrap() { return 1; }

int main()
{
    printf("Enter date (dd/mm/yyyy):\n");
    yylex();
    return 0;
}

Output

Valid date
05/20/2019
Invalid date
29/02/2023
Invalid date (not a leap year)
29/02/2024
Valid date

5. Valid time (hh:mm:ss)

%{
#include<stdio.h>
%}
%%
^([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]$    { printf("Valid time\n"); }
^.+$                                       { printf("Invalid time\n"); }
\n    ;
%%
int yywrap() { return 1; }

int main()
{
    printf("Enter time (hh:mm:ss):\n");
    yylex();
    return 0;
}

Output

Enter time (hh:mm:ss):
23:59:59
Valid time
24:00:00
Invalid time
12:60:00
Invalid time

Explanation

  1. Each program has three parts separated by %%: definitions in %{ %}, rules (pattern action), and user code (yywrap and main).
  2. ^ and $ force the pattern to match the whole line, so an 11-digit number is not accepted just because its first 10 digits match.
  3. The second rule ^.+$ matches any line. LEX takes the longest match and, on a tie, the earlier rule. A valid input matches both rules with the same length, so the valid rule (listed first) wins. Anything else falls to the "Invalid" rule.
  4. [6-9][0-9]{9} means one digit from 6 to 9 followed by exactly 9 digits. Indian mobile numbers start with 6, 7, 8 or 9.
  5. The date program uses named definitions (D31, M30 and so on) to check that the day fits the month. 29/02 is checked in C code with leap(), and yytext + 6 points to the year after "29/02/".
  6. The / is quoted as "/" because an unquoted / has a special meaning in LEX.
  7. The lone \n rule ignores the newline so it is not echoed on the screen.

Viva questions

What is LEX?

A tool that generates a lexical analyzer (scanner) in C from regular expressions and actions.

What is the structure of a LEX program?

Definition section, rules section and user subroutine section, separated by %%.

What do yylex(), yytext and yywrap() do?

yylex() starts scanning, yytext holds the matched text, and yywrap() returning 1 tells LEX there is no more input.

How does LEX choose between two matching rules?

It picks the longest match. If both are the same length, the rule written first wins.

Why do we use ^ and $ in the patterns?

They anchor the pattern to the start and end of the line, so the whole input must match.

What does [0-9]{10} mean?

Exactly ten digits.

What is the rule for a valid identifier?

It starts with a letter or underscore and continues with letters, digits or underscores: [a-zA-Z_][a-zA-Z0-9_]*.

How are leap years checked?

A year is a leap year if divisible by 4 and not by 100, or divisible by 400.

Why is "/" written in quotes in a LEX pattern?

Unquoted, / is the trailing-context operator.

How do you compile a LEX program?

win_flex --wincompat file.l creates lex.yy.c, then gcc -w lex.yy.c -o file builds it.

What is a regular expression?

A notation that describes a set of strings, used to define the patterns of tokens.

What does the win_flex (lex) command do?

It reads the .l file and generates the C file lex.yy.c that contains the scanner function yylex().

What is lex.yy.c?

The C program generated by Flex from our rules. gcc compiles it into the executable.

Why is --wincompat used?

It makes the generated code compatible with Windows (it avoids the Unix-only unistd.h header).
