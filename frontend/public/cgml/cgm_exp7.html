Computer Graphics & Multimedia Lab, 5CS4-21 (Turbo C++)

Experiment 7: 2D transformations: translation, scaling, rotation, shearing and reflection

Aim: To implement the basic 2D transformations (translation, scaling, rotation, shearing and reflection) for a given 2D object.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<math.h>
#include<graphics.h>

#define PI 3.14159265

int sx(float x)
{
    return 320 + (int)floor(x + 0.5);
}

int sy(float y)
{
    return 240 - (int)floor(y + 0.5);
}

void drawtri(float x[], float y[], int color)
{
    int i, j;
    setcolor(color);
    for(i = 0; i < 3; i++)
    {
        j = (i + 1) % 3;
        line(sx(x[i]), sy(y[i]), sx(x[j]), sy(y[j]));
    }
}

void main()
{
    int gd = DETECT, gm, err, ch, r, i;
    float x[3], y[3], nx[3], ny[3];
    float tx, ty, scx, scy, shx, shy, px, py, angle, c, s;

    clrscr();
    printf("Enter the 3 vertices of the triangle (x y), one per line:\n");
    for(i = 0; i < 3; i++)
        scanf("%f%f", &x[i], &y[i]);

    printf("\n1. Translation\n2. Scaling\n3. Rotation\n4. Shearing\n5. Reflection\n");
    printf("Enter your choice: ");
    scanf("%d", &ch);

    switch(ch)
    {
        case 1:
            printf("Enter translation tx ty: ");
            scanf("%f%f", &tx, &ty);
            for(i = 0; i < 3; i++)
            {
                nx[i] = x[i] + tx;
                ny[i] = y[i] + ty;
            }
            break;
        case 2:
            printf("Enter scaling factors sx sy: ");
            scanf("%f%f", &scx, &scy);
            for(i = 0; i < 3; i++)
            {
                nx[i] = x[i] * scx;
                ny[i] = y[i] * scy;
            }
            break;
        case 3:
            printf("Enter angle in degrees (anticlockwise): ");
            scanf("%f", &angle);
            printf("Enter pivot point px py (0 0 for origin): ");
            scanf("%f%f", &px, &py);
            c = cos(angle * PI / 180);
            s = sin(angle * PI / 180);
            for(i = 0; i < 3; i++)
            {
                nx[i] = px + (x[i] - px) * c - (y[i] - py) * s;
                ny[i] = py + (x[i] - px) * s + (y[i] - py) * c;
            }
            break;
        case 4:
            printf("Enter shear factors shx shy (use 0 to skip one): ");
            scanf("%f%f", &shx, &shy);
            for(i = 0; i < 3; i++)
            {
                nx[i] = x[i] + shx * y[i];
                ny[i] = y[i] + shy * x[i];
            }
            break;
        case 5:
            printf("1. About x-axis\n2. About y-axis\n3. About origin\n4. About line y = x\n");
            printf("Enter your choice: ");
            scanf("%d", &r);
            for(i = 0; i < 3; i++)
            {
                if(r == 1) { nx[i] = x[i];  ny[i] = -y[i]; }
                else if(r == 2) { nx[i] = -x[i]; ny[i] = y[i]; }
                else if(r == 3) { nx[i] = -x[i]; ny[i] = -y[i]; }
                else { nx[i] = y[i]; ny[i] = x[i]; }
            }
            break;
        default:
            printf("Wrong choice");
            getch();
            exit(0);
    }

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    /* axes: the origin (0,0) is at the centre of the screen */
    setcolor(DARKGRAY);
    line(0, 240, 639, 240);
    line(320, 0, 320, 479);

    drawtri(x, y, WHITE);
    drawtri(nx, ny, YELLOW);
    outtextxy(10, 10, "White = original, Yellow = transformed");

    getch();
    closegraph();
}

The manual's Exp 7 has five separate programs (rotate about origin, scale, translate, rotate about a point, reflect a triangle), uses C++ (iostream.h), and has none for shearing. This single program covers all five transformations from the aim with a menu.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

The origin (0, 0) is drawn at the centre of the screen with x to the right and y upwards, like a maths graph. Enter vertices between about -300 and 300 for x and -230 and 230 for y.

Explanation

  1. The triangle is stored as three vertices in the arrays x[] and y[]. The result is calculated into nx[] and ny[]. The original is drawn in white and the result in yellow, so you can compare them.
  2. Translation moves every point by the same amount: x' = x + tx and y' = y + ty.
  3. Scaling multiplies the coordinates: x' = x · sx and y' = y · sy. It is done about the origin, so the object also moves away from (or towards) the origin.
  4. Rotation by angle θ about a pivot (px, py): x' = px + (x-px)cosθ - (y-py)sinθ and y' = py + (x-px)sinθ + (y-py)cosθ. With pivot (0, 0) this is rotation about the origin. The angle is converted from degrees to radians with angle * PI / 180.
  5. Shearing slants the object: x' = x + shx · y and y' = y + shy · x. Giving 0 for one factor gives a pure x-shear or y-shear.
  6. Reflection makes a mirror image: about the x-axis (x, -y), about the y-axis (-x, y), about the origin (-x, -y), and about the line y = x (y, x).
  7. sx() and sy() convert maths coordinates to screen pixels (the screen's y axis points down, so y is subtracted from 240).

Viva questions

What is scaling?

A transformation that changes the size of an object by multiplying its coordinates by scale factors sx and sy. A factor above 1 enlarges and a factor below 1 shrinks the object.

What are the different transformations?

Translation, scaling, rotation, shearing and reflection (also called mirroring).

How are 2D transformations represented in matrix form?

A point is written as a column vector [x; y; 1] and multiplied by a 3 x 3 matrix. In homogeneous form every transformation is one matrix, so several can be combined by multiplying their matrices. (In the matrices below rows are separated by semicolons.)

Write the matrix for 2D translation.

[1 0 tx; 0 1 ty; 0 0 1]

Write the matrix for 2D scaling.

[sx 0 0; 0 sy 0; 0 0 1]

Write the matrix for 2D rotation.

Anticlockwise by θ about the origin: [cosθ -sinθ 0; sinθ cosθ 0; 0 0 1]

Write the matrix for 2D shearing.

x-shear: [1 shx 0; 0 1 0; 0 0 1]. y-shear: [1 0 0; shy 1 0; 0 0 1].

Write the matrix for 2D reflection.

About the x-axis: [1 0 0; 0 -1 0; 0 0 1]. About the y-axis: [-1 0 0; 0 1 0; 0 0 1]. About the origin: [-1 0 0; 0 -1 0; 0 0 1]. About y = x: [0 1 0; 1 0 0; 0 0 1].

What are homogeneous coordinates?

A way of writing a 2D point (x, y) as (x, y, 1). It lets translation, which is an addition, be written as a matrix multiplication, so all transformations can be combined into one matrix.

What is a shift vector?

The translation vector (tx, ty): the distance an object is moved along x and y.

How do you rotate an object about a point other than the origin?

Translate the pivot to the origin, rotate, then translate back. The formulas in the program do this in one step.

Is the order of transformations important?

Yes. Matrix multiplication is not commutative, so rotating then translating gives a different result from translating then rotating.
