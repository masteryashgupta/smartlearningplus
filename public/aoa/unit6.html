01. Decision Problems MEDIUM
The foundation of complexity theory — yes or no?
Definition

A Decision Problem is a computational problem whose answer is either YES or NO (i.e., it has a binary output). Complexity theory primarily studies decision problems because they are the simplest class of problems and any optimization problem can be converted into a corresponding decision problem.

🇮🇳 Hinglish Explanation
Decision problem wo problem hai jiska answer sirf "Haan (YES)" ya "Nahi (NO)" hota hai. Yeh complexity theory ka base hai. Koi bhi optimization problem ko hum ek decision problem mein convert kar sakte hain.

Example: "Kya is graph mein 5 se kum edges ke saath ek Hamiltonian cycle hai?" — yeh ek decision problem hai.
📌 Examples of Decision Problems
ProblemDecision Version
Shortest PathIs there a path from u to v with cost ≤ k?
Travelling SalesmanDoes a TSP tour of cost ≤ k exist?
Graph ColoringCan the graph be colored using ≤ k colors?
KnapsackIs there a selection of items with value ≥ V and weight ≤ W?
Vertex CoverDoes a vertex cover of size ≤ k exist?
💡
Why Decision Problems? Because if we can solve the decision version efficiently, we can often solve the optimization version too. This conversion allows fair comparison of problem difficulty.

02. Class P — Polynomial Time Problems HIGH

Definition

Class P (Polynomial Time) is the set of all decision problems that can be solved by a deterministic algorithm in polynomial time, i.e., in O(nᵏ) for some constant k, where n is the size of the input.

🇮🇳 Hinglish
P class mein wo saari problems aati hain jo ek normal (deterministic) computer pe polynomial time mein solve ho sakti hain. Jaise O(n), O(n²), O(n³) — yeh sab polynomial hain. Easy problems = P class.
Examples of Class P
  • Sorting — Merge Sort is O(n log n)
  • Shortest Path — Dijkstra's Algorithm is O(V²)
  • Matrix Multiplication — O(n³)
  • Primality Testing — AKS algorithm in O((log n)¹²)
  • Linear Programming — Polynomial time solvable
Fig 1: Relationship between P, NP, NP-Complete and NP-Hard (assuming P ≠ NP)

03. Class NP HIGH

Definition

Class NP (Non-deterministic Polynomial Time) is the set of all decision problems for which a given solution (certificate) can be verified in polynomial time by a deterministic algorithm. Equivalently, NP problems can be solved in polynomial time on a non-deterministic Turing machine.

🇮🇳 Hinglish
NP class mein wo problems hain jinka solution verify karna easy hai (polynomial time mein), lekin solution find karna hard ho sakta hai.
Example: Sudoku ka solution check karna aasaan hai, lekin khud solve karna mushkil.

Non-Deterministic ka matlab: Sochiye ek aisa computer jo ek saath saare possible answers try karta hai simultaneously — agar koi bhi answer sahi nikla toh problem solved!
Key Insight: Certificate-Based Verification

For a problem to be in NP, it must have a polynomial-length certificate (proof/witness) that can be verified in polynomial time.

ProblemCertificate (Proof)Verification
SATAn assignment of TRUE/FALSE to variablesCheck all clauses are satisfied — O(n)
TSP (Decision)A complete tourCheck tour length ≤ k — O(n)
Hamiltonian CycleA sequence of verticesCheck each edge exists — O(n)
CliqueA set of k verticesCheck all edges exist between them — O(k²)
⚠️
Important: P ⊆ NP (every problem in P is also in NP), because if you can solve it in polynomial time, you can certainly verify a solution in polynomial time. The million-dollar question is: Does P = NP?

04. P vs NP Problem HIGH

Definition

The P vs NP problem asks whether every problem whose solution can be quickly verified (NP) can also be quickly solved (P). It is one of the seven Millennium Prize Problems with a $1,000,000 prize for a correct solution. Currently it is believed (but not proven) that P ≠ NP.

🇮🇳 Hinglish
P vs NP ka simple sawaal: "Agar koi cheez verify karna aasaan hai, toh kya usse solve karna bhi aasaan hai?"

Jaise — Ek lock ka combination check karna easy hai (bas try karo), lekin combination find karna bahut mushkil. Agar P = NP hota, toh check karna = find karna — encryption tod deta! Isliye duniya manta hai P ≠ NP.

05. Polynomial Reduction (≤ₚ) HIGH

Definition

Problem A is polynomial-time reducible to Problem B (written A ≤ₚ B) if there exists a polynomial-time computable function f such that for every instance x of A, x is a YES-instance of A if and only if f(x) is a YES-instance of B. This means B is at least as hard as A.

🇮🇳 Hinglish
Reduction ka matlab: "Problem A ko Problem B mein convert karna."
Agar A ko B mein polynomial time mein convert kar sako, toh B utni hi mushkil hai jitni A ya usse bhi zyada.
Real Life: Agar tum French jaante ho toh French-to-English translator se English mein bhi kaam kar sakte ho — French reduce ho gayi English mein!
Fig 2: Polynomial Reduction — A ≤ₚ B (If we can solve B, we can solve A)
💡
Key Properties of Reduction:
  • If A ≤ₚ B and B ∈ P, then A ∈ P
  • If A ≤ₚ B and A is NP-Hard, then B is NP-Hard
  • Reduction is transitive: A ≤ₚ B and B ≤ₚ C ⟹ A ≤ₚ C

06. NP-Hard Problems HIGH

Definition

A problem H is called NP-Hard if every problem in NP is polynomial-time reducible to H (i.e., L ≤ₚ H for all L ∈ NP). NP-Hard problems are at least as hard as the hardest problems in NP. NP-Hard problems need not themselves be in NP — they may not even be decision problems.

🇮🇳 Hinglish
NP-Hard wo problems hain jo NP ki sabse mushkil problems se bhi zyada ya barabar mushkil hain.
NP-Hard ∉ NP necessarily — matlab unka solution verify karna bhi polynomial time mein possible nahi ho sakta!
Simple: "Boss level ki mushkilaat" — solve karna NP-Hard hai, verify karna bhi mushkil.
Examples of NP-Hard Problems
  • Halting Problem — NP-Hard but not even decidable (not in NP)
  • TSP Optimization — Find the minimum cost tour
  • Graph Coloring (Optimization) — Minimum colors needed
  • Knapsack (Optimization) — Maximum value subject to weight limit

07. NP-Complete Problems HIGH

Definition

A decision problem C is NP-Complete if it satisfies both conditions:
(1) C ∈ NP — the solution can be verified in polynomial time
(2) C is NP-Hard — every other NP problem reduces to C in polynomial time

NP-Complete problems are the hardest problems within NP. If any NP-Complete problem is solvable in polynomial time, then P = NP.

🇮🇳 Hinglish
NP-Complete = NP ∩ NP-Hard
Matlab ye problem:
1. NP mein hai — solution verify karna poly time mein possible
2. NP-Hard bhi hai — NP ki har problem isme reduce ho sakti hai

Agar NP-Complete solve ho gayi polynomial time mein → P = NP → saari cryptography toot jaayegi!

08. Cook's Theorem HIGH ⭐ Most Important

Definition — Cook's Theorem (1971)

Cook's Theorem states that the Boolean Satisfiability Problem (SAT) is NP-Complete. It was the first problem ever proved to be NP-Complete. Cook's theorem establishes that SAT ∈ NP and that every problem in NP can be polynomial-time reduced to SAT (SAT is NP-Hard).

🇮🇳 Hinglish
Stephen Cook ne 1971 mein prove kiya ki SAT problem NP-Complete hai — yeh world's first NP-Complete problem thi!

Cook ka kamal: Unhone prove kiya ki NP mein jo bhi problem hai, usse polynomial time mein SAT mein convert kiya ja sakta hai. Matlab: SAT = NP ka King!
Formal Statement

Theorem (Cook, 1971): SAT is NP-Complete.

Proof Sketch:

  1. SAT ∈ NP: Given an assignment of truth values to variables, we can verify in polynomial time whether all clauses are satisfied. Simply substitute and check each clause — O(n) verification.
  2. SAT is NP-Hard: For any problem L ∈ NP, there exists a non-deterministic Turing Machine M that accepts L in polynomial time p(n). For any input x of length n, construct a Boolean formula φ(M, x) that is satisfiable if and only if M accepts x. This construction is polynomial-time. Therefore L ≤ₚ SAT.
  3. Conclusion: Since SAT ∈ NP and L ≤ₚ SAT for all L ∈ NP, SAT is NP-Complete. ∎
Fig 4: Standard 3-step method to prove any problem is NP-Complete

09. Satisfiability Problem (SAT) HIGH ⭐

Definition

The Boolean Satisfiability Problem (SAT) asks: Given a Boolean formula φ in Conjunctive Normal Form (CNF) — a conjunction (AND) of clauses, where each clause is a disjunction (OR) of literals — does there exist an assignment of TRUE/FALSE values to the variables such that φ evaluates to TRUE?

🇮🇳 Hinglish
SAT problem mein hume boolean variables (x₁, x₂, x₃...) ko TRUE ya FALSE assign karna hota hai taaki ek given formula TRUE ban jaaye.

CNF (Conjunctive Normal Form): Formula = (clause1) AND (clause2) AND ... AND (clauseₙ)
Clause: = (literal1 OR literal2 OR ...)
Literal: = variable (xᵢ) ya uska negation (¬xᵢ)
📌 Example of SAT

Consider the formula: φ = (x₁ ∨ ¬x₂) ∧ (¬x₁ ∨ x₃) ∧ (x₂ ∨ ¬x₃)

Is this satisfiable? Try: x₁ = TRUE, x₂ = FALSE, x₃ = TRUE

  • Clause 1: (TRUE ∨ TRUE) = TRUE ✅
  • Clause 2: (FALSE ∨ TRUE) = TRUE ✅
  • Clause 3: (FALSE ∨ FALSE) = FALSE ❌

Try: x₁ = TRUE, x₂ = TRUE, x₃ = TRUE

  • Clause 1: (TRUE ∨ FALSE) = TRUE ✅
  • Clause 2: (FALSE ∨ TRUE) = TRUE ✅
  • Clause 3: (TRUE ∨ FALSE) = TRUE ✅

Answer: YES, satisfiable with x₁=T, x₂=T, x₃=T

3-SAT

Definition

3-SAT is a restricted version of SAT where each clause contains exactly 3 literals. 3-SAT is also NP-Complete and is widely used to prove other problems NP-Complete via reduction.

10. Vertex Cover Problem HIGH ⭐

Definition

Given an undirected graph G = (V, E) and an integer k, a Vertex Cover is a subset S ⊆ V such that for every edge (u, v) ∈ E, at least one of u or v belongs to S. The Vertex Cover Decision Problem asks: Does G have a vertex cover of size ≤ k?

🇮🇳 Hinglish
Vertex Cover = Ek aise vertices ka set jisme har edge ki kam se kam ek endpoint honi chahiye.

Real Life Analogy: Ek building ke corridors (edges) mein security cameras (vertices) lagaane hain. Minimum cameras kahan lagaao taaki har corridor cover ho jaaye? Yahi Vertex Cover hai!
Fig 5: Vertex Cover Example — S = {B, C, E} covers all 6 edges

Proving Vertex Cover is NP-Complete

NP-Completeness Proof
  1. Vertex Cover ∈ NP: Given a set S of vertices, we can verify in O(E) time that every edge has at least one endpoint in S. So Vertex Cover ∈ NP.
  2. Reduce from 3-SAT (or Independent Set): It is known that INDEPENDENT SET ≤ₚ VERTEX COVER. A set S is an independent set of size k iff V−S is a vertex cover of size n−k. Since Independent Set is NP-Hard, Vertex Cover is also NP-Hard.
  3. Conclusion: Vertex Cover is NP-Complete. ∎
⭐
Key Relationship: In any graph G = (V, E), S is a Vertex Cover ⟺ V − S is an Independent Set. This gives a clean polynomial reduction between the two problems.

11. Approximation Algorithm for Vertex Cover HIGH ⭐

Definition

Since Vertex Cover is NP-Complete (exact solution in polynomial time is unlikely), we use approximation algorithms — algorithms that run in polynomial time and produce a solution whose value is guaranteed to be within a factor of the optimal solution. The approximation ratio for the algorithm below is 2 (called a 2-approximation).

🇮🇳 Hinglish
Exact solution mushkil hai, toh hum approximation algorithm use karte hain — jo exact nahi but guarantee karta hai ki answer optimal se zyada se zyada 2x bada hoga.
Yeh "good enough" solution hai NP-Hard problems ke liye!

2-Approximation Algorithm for Vertex Cover

Algorithm — APPROX-VERTEX-COVER
APPROX-VERTEX-COVER(G = (V, E)):
  C = ∅                     // Cover set (initially empty)
  E' = E                    // Copy of edge set
  while E' ≠ ∅ do
    let (u, v) be any edge in E'
    C = C ∪ {u, v}          // Add both endpoints
    Remove from E' all edges incident on u or v
  end while
  return C
📌 Step-by-Step Example

Graph G: V = {A,B,C,D,E,F}, E = {(A,B),(B,C),(C,D),(D,E),(E,F),(F,A)}

StepEdge PickedVertices Added to CEdges Removed
1(A,B)A, B(A,B), (B,C), (F,A)
2(C,D)C, D(C,D), (D,E)
3(E,F)E, F(E,F)
ResultC = {A,B,C,D,E,F} — All 6 vertices (Optimal is 3)

Approximation Ratio: |C| / |OPT| ≤ 2   → This is guaranteed.

Why is the Ratio ≤ 2?

Proof of 2-Approximation

Let A = set of edges chosen in the while loop (a maximal matching). Every edge in A is vertex-disjoint (no shared endpoints). So |A| independent edges need at least |A| vertices in any cover. Thus |OPT| ≥ |A|. Our algorithm adds both endpoints of each edge in A, so |C| = 2|A| ≤ 2·|OPT|. ∎

12. Set Cover Problem & Approximation MEDIUM ★★

Definition

Given a universe U of n elements and a collection S = {S₁, S₂, ..., Sₘ} of subsets of U (where ∪Sᵢ = U), and a cost function c(Sᵢ), the Set Cover Problem asks: Find the minimum cost sub-collection of S that covers all elements of U. The decision version asks: Is there a set cover of cost ≤ k?

🇮🇳 Hinglish
Set Cover mein kuch sets diye hote hain. Hume minimum number of sets choose karne hote hain taaki saare elements cover ho jaayein.

Real Life: Ek city mein fire stations (sets) laga rahe ho. Har station kuch areas cover karta hai. Minimum stations se saari city cover karo!
📌 Example

U = {1, 2, 3, 4, 5, 6, 7}

S₁ = {1,2,3,4}, S₂ = {2,4,5,6}, S₃ = {1,4,6,7}, S₄ = {3,5,7}

Optimal: {S₁, S₂, S₄} covers all elements with 3 sets.

Or: {S₁, S₃, S₄} also works.

Greedy Approximation Algorithm for Set Cover

Algorithm — GREEDY-SET-COVER
GREEDY-SET-COVER(U, S):
  C = ∅                   // Selected sets
  U' = U                  // Remaining uncovered elements
  while U' ≠ ∅ do
    Select Sᵢ ∈ S maximizing |Sᵢ ∩ U'|
    C = C ∪ {Sᵢ}
    U' = U' \ Sᵢ
  end while
  return C

Q1 · 10 MARKS — Most Repeated
10 MARKS
What are P, NP, NP-Hard, and NP-Complete problem classes? Explain with examples and their inter-relationships.

Class P (Polynomial Time): Set of decision problems solvable in O(nᵏ) time on a deterministic machine. Examples: Sorting (O(n log n)), Shortest Path (O(V²)), Primality Testing.

Class NP (Non-deterministic Polynomial): Set of decision problems whose given solutions can be verified in polynomial time. Examples: SAT, TSP-Decision, Vertex Cover, Hamiltonian Cycle. P ⊆ NP.

NP-Hard: A problem H is NP-Hard if every L ∈ NP satisfies L ≤ₚ H (all NP problems reduce to it in polynomial time). NP-Hard problems need not be in NP. Examples: Halting Problem, TSP-Optimization.

NP-Complete: Problems that are both in NP AND NP-Hard. The hardest problems within NP. Examples: SAT, 3-SAT, Vertex Cover, Clique, TSP-Decision. If any NP-Complete problem is in P, then P = NP.

Relationships: P ⊆ NP, NP-Complete = NP ∩ NP-Hard. Assuming P ≠ NP, these form four distinct regions. The P vs NP question (does P = NP?) is a $1,000,000 unsolved Millennium Prize Problem.

Q2 · 10 MARKS
10 MARKS
State and prove Cook's Theorem. Why is it significant?

Cook's Theorem (1971): The Boolean Satisfiability Problem (SAT) is NP-Complete.

Proof — Part 1: SAT ∈ NP. Given any truth assignment to the variables, we can substitute values into all clauses and check if each evaluates to TRUE. This verification takes O(n) time (linear in the size of the formula). Hence SAT ∈ NP.

Proof — Part 2: SAT is NP-Hard. Let L be any problem in NP. Then there exists a Non-deterministic Turing Machine M that accepts L in time p(n) (polynomial). For any input x, we construct a Boolean formula φ(M, x) in CNF such that:

  • The formula encodes all possible configurations of M on input x as Boolean variables
  • Each transition rule of M becomes a clause
  • φ is satisfiable ⟺ M accepts x ⟺ x ∈ L
  • Construction of φ takes polynomial time O(p(n)²)

Therefore L ≤ₚ SAT for any L ∈ NP, making SAT NP-Hard.

Conclusion: SAT ∈ NP and SAT is NP-Hard ⟹ SAT is NP-Complete. ∎

Significance: Cook's theorem was the first proof of NP-Completeness, establishing SAT as a universal hard problem. It gave researchers a starting point — any NP problem can be shown NP-Complete by reducing SAT (or a known NP-Complete problem) to it.

Q3 · 10 MARKS
10 MARKS
Explain the Vertex Cover Problem. Prove it is NP-Complete. Write a 2-approximation algorithm for it.

Vertex Cover: A vertex cover of graph G = (V,E) is a subset S ⊆ V such that every edge (u,v) ∈ E has at least one of u, v in S. The decision problem: Does G have a vertex cover of size ≤ k?

NP-Completeness Proof:

Step 1 — VC ∈ NP: Given a set S, check each edge (u,v) to see if u ∈ S or v ∈ S. This takes O(E) time → polynomial. So VC ∈ NP.

Step 2 — VC is NP-Hard: We show Independent Set (IS) ≤ₚ VC. Observation: S is an independent set of size k in G ⟺ V−S is a vertex cover of size n−k. Given IS instance (G, k), construct VC instance (G, n−k) — same graph, different k. This is a polynomial transformation. Since IS is NP-Complete, VC is NP-Hard. ∎

2-Approximation Algorithm (APPROX-VERTEX-COVER):

C = ∅; E' = E
while E' ≠ ∅:
  pick any edge (u,v) from E'
  C = C ∪ {u, v}
  remove all edges incident on u or v from E'
return C

Analysis: Let A = edges chosen in the while loop. A is a matching (vertex-disjoint). Any VC must include ≥1 vertex per edge in A, so |OPT| ≥ |A|. Our algorithm adds 2 vertices per edge, so |C| = 2|A| ≤ 2|OPT|. Time complexity: O(V + E).

Q4 · 10 MARKS
10 MARKS
Explain the Set Cover Problem. Describe a greedy approximation algorithm and analyze its approximation ratio.

Set Cover Problem: Given universe U of n elements and collection S of subsets of U with ∪S = U, find the minimum number of sets from S whose union equals U. Decision version: Is there a set cover of size ≤ k?

Set Cover is NP-Complete: Vertex Cover ≤ₚ Set Cover (special case where sets are neighborhoods of vertices).

Greedy Approximation Algorithm:

C = ∅; U' = U
while U' ≠ ∅:
  Select Sᵢ with maximum |Sᵢ ∩ U'|
  C = C ∪ {Sᵢ}; U' = U' \ Sᵢ
return C

Approximation Ratio Analysis:

Let OPT = k (optimal cover size). The greedy always picks the set covering the most uncovered elements. At any step with r elements remaining, the best set covers ≥ r/k elements. Using the harmonic series analysis:

|C| ≤ k · H(max|Sᵢ|) = k · (1 + 1/2 + 1/3 + ... + 1/d) ≤ k · (ln n + 1)

So greedy gives an O(ln n) approximation. While worse than the vertex cover's 2-approximation, it is the best known polynomial-time approximation for the general Set Cover problem (under the Unique Games Conjecture).

Example: U = {1..7}, S₁={1,2,3,4}, S₂={2,4,5,6}, S₄={3,5,7}. Greedy picks S₁ (4 elements), then S₂ (covers 5,6), then S₄ (covers 7). Cover = {S₁,S₂,S₄} with 3 sets.

What is a Decision Problem? Give examples and explain its significance in complexity theory.

A decision problem is a computational problem with a YES/NO answer. It takes an input instance and a parameter k, and asks whether a certain property holds.

Significance: Complexity theory (P, NP, NP-Hard) is formally defined for decision problems. Any optimization problem can be converted to a decision problem by adding a threshold k. If the decision version is in P, the optimization version is usually also in P.

What is the Boolean Satisfiability Problem (SAT)? Solve a given CNF formula.

SAT asks: Given a CNF formula φ (AND of clauses, where each clause is an OR of literals), does there exist a truth assignment making φ = TRUE?

SAT is NP-Complete (first proved by Cook, 1971). Verification: Given an assignment, check each clause → O(n). Solving: No polynomial algorithm known.

Example: φ = (x₁ ∨ ¬x₂) ∧ (¬x₁ ∨ x₂ ∨ x₃) ∧ (x₂ ∨ ¬x₃)

Try x₁=T, x₂=T, x₃=F:

  • Clause 1: (T ∨ F) = T ✅
  • Clause 2: (F ∨ T ∨ F) = T ✅
  • Clause 3: (T ∨ T) = T ✅

φ is SATISFIABLE with x₁=TRUE, x₂=TRUE, x₃=FALSE.

What is polynomial time reduction? Explain with an example how it is used to prove NP-Completeness.

Polynomial Reduction (A ≤ₚ B): A is polynomial-time reducible to B if there exists a polynomial-time computable function f such that x ∈ A ⟺ f(x) ∈ B. This means B is at least as hard as A.

Use in NP-Completeness: To prove problem X is NP-Complete:

  1. Show X ∈ NP (poly-time verifier exists)
  2. Pick a known NP-Complete problem Y
  3. Show Y ≤ₚ X (polynomial reduction from Y to X)

Example — Independent Set ≤ₚ Vertex Cover:

Given IS instance (G, k), construct VC instance (G, n−k). S is an independent set of size k ⟺ V−S is a vertex cover of size n−k. Transformation: O(1) — same graph, different parameter. Hence VC is NP-Hard (since IS is NP-Complete).

What is an approximation algorithm? Why are approximation algorithms important for NP-Hard problems?

An approximation algorithm is a polynomial-time algorithm that finds a solution whose value is guaranteed to be within a constant factor (approximation ratio ρ) of the optimal solution. For minimization: ALG(I) ≤ ρ · OPT(I). For maximization: OPT(I) ≤ ρ · ALG(I).

Importance: Since NP-Complete/NP-Hard problems likely have no polynomial-time exact solutions, approximation algorithms provide the best practical alternative — fast solutions that are provably close to optimal.

Show that 2-SAT ∈ P but 3-SAT is NP-Complete. Why does one extra literal per clause make such a difference?

2-SAT ∈ P: In 2-SAT each clause has exactly 2 literals. A clause (a ∨ b) is equivalent to two implications: ¬a → b and ¬b → a. Construct an implication graph with 2n nodes (one per variable and its negation). 2-SAT is SATISFIABLE iff no variable and its negation belong to the same Strongly Connected Component (SCC). SCC computation takes O(V+E) → polynomial. So 2-SAT ∈ P.

3-SAT is NP-Complete: Every clause in SAT can be converted to clauses of 3 literals (introduce auxiliary variables for clauses with more literals, split into 3-literal clauses). This shows SAT ≤ₚ 3-SAT, and since 3-SAT ≤ₚ SAT trivially, 3-SAT is NP-Complete.

Why the difference? The implication graph trick works for 2-SAT because each clause gives exactly 2 implications, keeping the problem structurally tractable. With 3 literals, the exponential case branching kicks in — no known polynomial algorithm can handle the combinatorial explosion of possible assignments.

Q11 · 5 MARKS — Short Note
5 MARKS
Write a short note on the P vs NP problem and its implications.

The P vs NP problem asks whether every problem whose solution can be quickly verified (NP) can also be quickly solved (P). It is one of the seven Millennium Prize Problems with a $1,000,000 reward.

If P = NP:

  • All NP-Complete problems become efficiently solvable
  • RSA encryption (based on factoring hardness) would be broken
  • Drug discovery, logistics optimization would become trivial
  • The entire field of cryptography would collapse

If P ≠ NP (widely believed):

  • NP-Complete problems have no efficient solution
  • Encryption remains secure
  • Approximation algorithms remain important

Despite decades of research, no proof exists either way. The best known algorithms for NP-Complete problems still require exponential time in the worst case.
