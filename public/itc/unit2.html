1. Uncertainty & Information High ⭐⭐⭐

English

Uncertainty of an event is a measure of how unpredictable its occurrence is — the lower the probability of an event, the higher the uncertainty/surprise when it occurs.

Information conveyed by a message is inversely related to its probability of occurrence. If event x has probability P(x), the information content is:

I(x) = log₂( 1 / P(x) ) = − log₂ P(x)    [bits]
Hinglish

Soch — agar koi event hamesha hota hai (P=1), to usme koi "naya" info nahi (I=0). Lekin agar koi rare event hota hai (P chhota), to usme bahut "surprise" / information hoti hai. Jaise "Kal Sun nikla" (P≈1 → info≈0) vs "Aaj Jaipur mein snowfall hua" (P≈0 → info bahut high!).

Units of Information

Log BaseUnitUsed When
log₂bitBinary systems (most common, default in exams)
log₁₀Hartley / decitDecimal systems
logₑ (ln)natNatural log, used in continuous/differential entropy

Properties of Information Measure Medium

  1. I(x) = 0, when P(x) = 1 (certain event carries no information).
  2. I(x) ≥ 0, since 0 ≤ P(x) ≤ 1 (information is never negative).
  3. I(x₂) > I(x₁), if P(x₂) < P(x₁) (lower probability ⇒ more information).
  4. If x₁ and x₂ are independent: I(x₁,x₂) = I(x₁) + I(x₂) (additivity property).
Example

A binary source emits '0' with P=0.25 and '1' with P=0.75. Find information carried by each symbol.

Solution:
I(0) = −log₂(0.25) = log₂4 = 2 bits
I(1) = −log₂(0.75) = 0.415 bits
→ Rarer symbol '0' carries more information than frequent symbol '1'.

1B. Postulates for a Measure of Information (Why Logarithm?) Medium ⭐⭐ — "Why log?" theory question

English

Shannon defined information using a logarithmic function based on the following postulates (axioms) that any reasonable information measure I(P) must satisfy:

  1. Postulate 1: I(P) = 0 when P = 1 (a certain event gives zero information).
  2. Postulate 2: I(P) ≥ 0 for 0 ≤ P ≤ 1 (information is non-negative).
  3. Postulate 3: I(P₁) > I(P₂) if P₁ < P₂ (monotonically decreasing — rarer event ⇒ more information).
  4. Postulate 4 (Additivity): I(P₁·P₂) = I(P₁) + I(P₂) for independent events (joint information of independent events = sum of individual information).

The only mathematical function satisfying all four postulates simultaneously is the logarithmic function: I(x) = log(1/P(x)). This is why entropy/information is always defined using logarithms, not any other function.

Hinglish

Yeh question aksar aata hai: "Information measure ke liye log function hi kyu use hota hai?" — Answer simple hai: Shannon ne 4 conditions (postulates) set ki jo ek "sensible" information measure follow karna chahiye, aur jab tum maths se check karo, sirf logarithm function hi un sab conditions ko satisfy karta hai (especially additivity property — independent events ka information add hona chahiye, multiply nahi, aur log(a·b)=log(a)+log(b) yehi karta hai).

2. Entropy High ⭐⭐⭐⭐⭐ (Most Important)

English

Entropy H(X) is the average (expected) information per symbol generated by a discrete memoryless source. It measures the average uncertainty of a random variable.

H(X) = − Σ P(xᵢ) · log₂ P(xᵢ)   [bits/symbol]    i = 1...n
Hinglish

Entropy = "average information" jo ek source produce karta hai per symbol. Agar source bahut predictable hai (jaise hamesha same letter), entropy kam hogi. Agar source bahut random hai (sab symbols equally likely), entropy maximum hogi. Isiliye entropy ko "average surprise" bhi kehte hain.

Properties of Entropy High

  1. 0 ≤ H(X) ≤ log₂(n), where n = number of symbols.
  2. H(X) = 0, when one symbol has probability 1 (no uncertainty — fully predictable).
  3. H(X) is maximum (= log₂ n) when all symbols are equiprobable (P = 1/n each) — maximum uncertainty.
  4. Entropy is a concave function of probability distribution.

Fig 2.1 — Binary Entropy Function H(p) = −p·log₂p − (1−p)·log₂(1−p). Peaks at p = 0.5

Example (very commonly asked numerical)

A source emits 4 symbols with probabilities: P(x₁)=0.5, P(x₂)=0.25, P(x₃)=0.125, P(x₄)=0.125. Find entropy.

Solution:
H(X) = −[0.5log₂0.5 + 0.25log₂0.25 + 0.125log₂0.125 + 0.125log₂0.125]
= −[0.5(−1) + 0.25(−2) + 0.125(−3) + 0.125(−3)]
= 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits/symbol

Proof: H(X) is Maximum when Symbols are Equiprobable High — common 5-mark proof question

To maximize H(X) = −ΣPᵢ log₂Pᵢ subject to constraint ΣPᵢ = 1, apply Lagrange multipliers:

L = −Σ Pᵢ log₂Pᵢ + λ(Σ Pᵢ − 1) ∂L/∂Pᵢ = −log₂Pᵢ − log₂e + λ = 0 ⟹ Pᵢ = constant for all i = 1/n

Substituting Pi = 1/n back gives Hmax(X) = log₂n. Hence entropy is maximum exactly when all symbols are equally likely — this is the equiprobable / uniform distribution case.

Joint Entropy & Marginal Entropy Medium ⭐⭐⭐

English

Joint Entropy H(X,Y) is the average uncertainty associated with a pair of random variables (X,Y) taken together:

H(X,Y) = − Σᵢ Σⱼ P(xᵢ,yⱼ) · log₂ P(xᵢ,yⱼ)

Marginal Entropy is simply H(X) or H(Y) computed individually from the marginal probability distributions P(xᵢ)=ΣⱼP(xᵢ,yⱼ) and P(yⱼ)=ΣᵢP(xᵢ,yⱼ).

Hinglish

Joint entropy = dono variables X aur Y ko ek saath consider karke total uncertainty. Marginal entropy = sirf X (ya sirf Y) ki uncertainty, dusre ko "ignore" karke (uski sab possibilities sum kar di).

Key relation: H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

Rate of Information Transmission Low-Medium ⭐

English

If a discrete source emits r symbols per second, the rate of information R (in bits/second) is:

R = r · H(X)    [bits/second]
Hinglish

Simple — entropy batati hai "per symbol" kitni info hai, aur agar tumhe pata hai ki source ek second mein kitne symbols bhejta hai (r), to dono multiply karke total info-rate (bits/sec) mil jaata hai.

3. Information Measures for Continuous Random Variables Medium ⭐⭐

English

For a continuous random variable X with probability density function f(x), the average information is called differential entropy:

h(X) = − ∫−∞+∞ f(x) · log₂ f(x) dx
Hinglish

Discrete entropy mein hum probabilities ka sum karte hain, continuous case mein (jaise voltage, temperature signals) probability ki jagah density function f(x) hota hai, aur sum ki jagah integral. Important difference: differential entropy negative bhi ho sakti hai (discrete entropy kabhi negative nahi hoti)!

Differential Entropy of Gaussian (Normal) Distribution Often Asked

For X ~ N(μ, σ²):

h(X) = ½ log₂(2πeσ²)

This is the maximum differential entropy among all continuous distributions with the same variance σ² — i.e., for a fixed power/variance constraint, the Gaussian source is the "most random" (max entropy) source.

Properties of Differential Entropy Medium

  1. h(X) can be negative, zero, or positive (unlike discrete entropy which is always ≥ 0).
  2. h(X + c) = h(X) for any constant c (translation/shifting does not change differential entropy).
  3. h(aX) = h(X) + log₂|a| (scaling changes differential entropy by log of the scale factor).
  4. Among all continuous distributions with a given variance σ², the Gaussian distribution has maximum differential entropy.

Joint & Conditional Differential Entropy Low ⭐

h(X,Y) = − ∬ f(x,y) · log₂ f(x,y) dx dy h(X|Y) = − ∬ f(x,y) · log₂ f(x|y) dx dy Mutual Information (continuous): I(X;Y) = h(X) − h(X|Y)
Hinglish

Bilkul discrete case jaisa hi pattern — sirf summation (Σ) ko integration (∫) se replace kar do, aur probability P ko density f(x) se. Concept same hai, sirf continuous variable ke liye adapted.

4. Source Coding Theorem (Shannon's First Theorem) High ⭐⭐⭐⭐

English

Shannon's Source Coding Theorem states that for a discrete memoryless source with entropy H(X), it is possible to construct a code with average codeword length Lavg such that:

H(X) ≤ Lavg < H(X) + 1

In other words: average code length can never be less than the source entropy — entropy is the fundamental lower bound on lossless compression.

Hinglish

Yani — tum kisi bhi source ke data ko itna compress nahi kar sakte ki average bits/symbol entropy se kam ho jaaye. Entropy ek "theoretical limit" hai compression ka. Jaise ZIP/Huffman coding isi limit ke jitna close pohochne ki koshish karte hain.

Coding Efficiency & Redundancy Numerical-friendly

η (Efficiency) = H(X) / Lavg     Redundancy = 1 − η

Higher efficiency (closer to 1, or 100%) means the code is closer to the theoretical entropy limit — better compression.

Example

A source has H(X) = 1.75 bits/symbol. A code is designed with Lavg = 1.875 bits/symbol. Find efficiency and redundancy.

Solution:
η = 1.75/1.875 = 0.933 = 93.3%
Redundancy = 1 − 0.933 = 0.067 (6.7%)

Codes, Code Length & Kraft Inequality Medium ⭐⭐

English

A code assigns a sequence of binary digits (codeword) to each source symbol. Key code types:

  • Fixed-length code: all codewords have equal length.
  • Variable-length code: codeword length varies (shorter for high-probability symbols).
  • Uniquely decodable code: no ambiguity — any coded sequence can be decoded in only one way.
  • Instantaneous (prefix) code: no codeword is a prefix of another codeword — can be decoded symbol-by-symbol without lookahead.

Kraft Inequality: A prefix (instantaneous) code with codeword lengths l₁, l₂,...,lₙ exists if and only if:

Σᵢ 2−lᵢ ≤ 1
Hinglish

Kraft inequality batati hai ki given lengths ke saath ek valid "instantaneous/prefix code" possible hai ya nahi — agar sab 2−lᵢ ka sum ≤1 hai, to aisa code ban sakta hai jisme koi codeword kisi doosre ka prefix na ho (taaki decode karte waqt confusion na ho).

Proof Sketch of Source Coding Theorem High ⭐⭐⭐ — 10-mark derivation

Lower bound (Lavg ≥ H(X)): By Gibbs' inequality, for any two probability distributions P and Q: −ΣPᵢlog₂Pᵢ ≤ −ΣPᵢlog₂Qᵢ. Choosing Qᵢ = 2−lᵢ/Σ2−lⱼ and using the Kraft inequality (Σ2−lᵢ≤1), it follows algebraically that:

Lavg = Σ Pᵢ lᵢ ≥ H(X)

Upper bound (Lavg < H(X)+1): Choose codeword length lᵢ = ⌈log₂(1/Pᵢ)⌉ (smallest integer ≥ log₂(1/Pᵢ)). This satisfies the Kraft inequality (so a valid prefix code exists), and gives:

log₂(1/Pᵢ) ≤ lᵢ < log₂(1/Pᵢ) + 1  ⟹  H(X) ≤ Lavg < H(X) + 1

Combining both bounds proves Shannon's Source Coding Theorem: entropy is the achievable lower limit of average code length, approachable within 1 bit by simple symbol-by-symbol coding (and exactly approachable using block/extension coding as block length → ∞).

5. Discrete Memoryless Channel (DMC) High ⭐⭐⭐

English

A Discrete Memoryless Channel is a channel whose output at any time depends only on the input at that same time instant (not on past inputs/outputs), and both input X and output Y take values from finite discrete alphabets. It is described by a transition probability matrix P(yⱼ|xᵢ).

Hinglish

"Memoryless" matlab — channel ka current output sirf current input pe depend karta hai, purane inputs/outputs ka kuch effect nahi (no memory of past). Ye ek mathematical model hai jo channel ki "noise behavior" ko probability matrix se represent karta hai.

Fig 2.2 — Binary Symmetric Channel (BSC): the simplest and most-asked DMC example. 'p' = crossover (error) probability

Channel Matrix / Transition Probability Matrix Medium

A DMC is fully described by its channel matrix, where rows = inputs, columns = outputs, each entry = P(yⱼ|xᵢ):

[P(Y|X)] = | P(y₁|x₁) P(y₂|x₁) | | P(y₁|x₂) P(y₂|x₂) |

Each row sums to 1 (since for a fixed input, output probabilities over all possibilities must total 1). For BSC: [[1−p, p],[p, 1−p]].

Types of Discrete Channels Medium ⭐⭐ — definition based

Channel TypePropertyChannel Matrix Feature
Lossless ChannelNo information is lost; H(X|Y)=0Only one non-zero entry per column
Deterministic ChannelEach input maps to exactly one output; H(Y|X)=0Only one non-zero entry (=1) per row
Noiseless ChannelBoth lossless and deterministic; I(X;Y)=H(X)=H(Y)Identity matrix (square, diagonal)
Binary Symmetric Channel (BSC)Symmetric error probability p in both directions[[1−p,p],[p,1−p]]
Hinglish

Lossless = output se input bilkul reverse-trace ho sakta hai (no info kho rahi). Deterministic = ek fixed input se hamesha same output aata hai (no randomness output side pe). Noiseless = best case, dono properties saath — channel perfectly clean hai.

Channel Capacity High ⭐⭐⭐⭐ — frequently asked with BSC numerical

English

Channel Capacity C is the maximum rate of reliable information transmission over a channel, defined as the maximum of mutual information over all possible input probability distributions P(x):

C = maxP(x) I(X;Y)   [bits/symbol or bits/channel use]

For a Binary Symmetric Channel with crossover probability p, capacity is maximized at P(0)=P(1)=0.5 and equals:

CBSC = 1 − H(p) = 1 + p·log₂p + (1−p)·log₂(1−p)
Hinglish

Channel capacity = channel ka "speed limit" — usse zyada rate pe reliably (error-free) data nahi bhej sakte (ye Shannon ka famous result hai, jise "Shannon Limit" bhi kehte hain). BSC ke liye capacity formula bahut common numerical hai — agar p=0 (no error), C=1 bit/symbol (perfect channel); agar p=0.5 (channel totally random), C=0 (channel useless).

Fig 2.4 — BSC Capacity vs crossover probability p. C=1 at p=0 or p=1 (no ambiguity), C=0 at p=0.5 (max confusion)

6. Mutual Information High ⭐⭐⭐⭐

English

Mutual Information I(X;Y) is the amount of information that one random variable (channel output Y) contains about another (channel input X). It measures the reduction in uncertainty about X after observing Y.

I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y)
Hinglish

Mutual information batata hai — receiver ne Y dekhne ke baad, X ke baare mein kitni uncertainty kam ho gayi. Agar channel "perfect" hai (no noise), to Y dekhke X 100% pata chal jaata hai → I(X;Y) = H(X) (maximum). Agar channel bahut noisy hai, I(X;Y) → 0 (Y se X ke baare mein kuch pata nahi chalta).

Properties of Mutual Information

  1. I(X;Y) ≥ 0 (always non-negative).
  2. I(X;Y) = I(Y;X) (symmetric).
  3. I(X;Y) = 0, if and only if X and Y are statistically independent.
  4. I(X;Y) ≤ min[H(X), H(Y)].

Proof: I(X;Y) ≥ 0 Medium ⭐⭐ — proof-based question

Using I(X;Y) = ΣΣ P(xᵢ,yⱼ) log₂[P(xᵢ,yⱼ)/(P(xᵢ)P(yⱼ))], apply Jensen's/Gibbs' inequality (log is concave, and treating P(xᵢ)P(yⱼ) as an alternate distribution Q over the same support):

−I(X;Y) = ΣΣ P(xᵢ,yⱼ) log₂[P(xᵢ)P(yⱼ)/P(xᵢ,yⱼ)] ≤ log₂[ΣΣ P(xᵢ)P(yⱼ)] (by Jensen's inequality, since log is concave) = log₂[1] = 0 ⟹ I(X;Y) ≥ 0 (equality holds iff X,Y are independent)

7. Conditional Entropy High ⭐⭐⭐

English

Conditional Entropy H(X|Y) is the average uncertainty remaining about X, after the output Y has been observed. It is also called "equivocation" — represents information lost in a noisy channel.

H(X|Y) = − Σᵢ Σⱼ P(xᵢ,yⱼ) · log₂ P(xᵢ|yⱼ)
Hinglish

H(X|Y) = "Y pata hone ke baad bhi X mein kitni confusion baaki hai". Isiliye ise equivocation bhi kehte hain — ye represent karta hai ki noise ki wajah se kitni info "lost" ho gayi transmission mein.

Fig 2.3 — Venn diagram relationship between Entropy, Conditional Entropy, Mutual Information & Joint Entropy

QuantityMeaningFormula
H(X)Avg info / uncertainty of source−ΣP(xᵢ)log₂P(xᵢ)
H(Y)Avg info / uncertainty of output−ΣP(yⱼ)log₂P(yⱼ)
H(X,Y)Joint entropy−ΣΣP(xᵢ,yⱼ)log₂P(xᵢ,yⱼ)
H(X|Y)Uncertainty in X after knowing Y (loss/equivocation)H(X,Y) − H(Y)
H(Y|X)Uncertainty in Y after knowing X (noise entropy)H(X,Y) − H(X)

Example (classic RTU-style)

For a BSC with P(0)=P(1)=0.5 and crossover probability p=0.1, find H(X), H(Y|X), and I(X;Y).

Solution:
H(X) = −(0.5log₂0.5+0.5log₂0.5) = 1 bit
H(p) = −p log₂p −(1−p)log₂(1−p) = −0.1log₂0.1 −0.9log₂0.9 = 0.469 bits
Since channel is symmetric, H(Y|X) = H(p) = 0.469 bits
I(X;Y) = H(X) − H(Y|X)... (using H(Y)=H(X)=1 by symmetry, and H(Y|X)=H(p))

Proof: H(X|Y) ≤ H(X) Medium ⭐⭐ — proof question

Since I(X;Y) = H(X) − H(X|Y) and we proved I(X;Y) ≥ 0 above, it directly follows that:

H(X|Y) = H(X) − I(X;Y) ≤ H(X)

This makes intuitive sense: knowing Y can never increase uncertainty about X on average — at worst (when X,Y independent), H(X|Y)=H(X) (no help), and otherwise it strictly reduces uncertainty.

Full Worked Numerical — Joint Probability Matrix High ⭐⭐⭐⭐⭐ — classic 10-mark question, asked almost every year

Example

Given the joint probability matrix P(X,Y):

y₁y₂P(xᵢ)
x₁0.250.250.50
x₂0.1250.3750.50
P(yⱼ)0.3750.6251.0

Find H(X), H(Y), H(X,Y), H(X|Y), H(Y|X), and I(X;Y).

Solution:

① H(X) = −(0.5log₂0.5 + 0.5log₂0.5) = 1 bit (marginal row sums used)

② H(Y) = −(0.375log₂0.375 + 0.625log₂0.625) = −(0.375×−1.415 + 0.625×−0.678) = 0.530+0.424 = 0.954 bits

③ H(X,Y) = −Σ all four joint terms:
= −[0.25log₂0.25 + 0.25log₂0.25 + 0.125log₂0.125 + 0.375log₂0.375]
= −[0.25(−2)+0.25(−2)+0.125(−3)+0.375(−1.415)]
= 0.5+0.5+0.375+0.531 = 1.906 bits

④ H(X|Y) = H(X,Y) − H(Y) = 1.906 − 0.954 = 0.952 bits

⑤ H(Y|X) = H(X,Y) − H(X) = 1.906 − 1 = 0.906 bits

⑥ I(X;Y) = H(X) − H(X|Y) = 1 − 0.952 = 0.048 bits  (cross-check: H(X)+H(Y)−H(X,Y) = 1+0.954−1.906 = 0.048 ✓)

💡 Exam tip: Always compute H(X,Y) directly from the joint matrix first — every other quantity (H(X|Y), H(Y|X), I(X;Y)) follows from it using the standard relations. This is the fastest, error-free order to solve such numericals.

❓ Unit 2 — Q&A (RTU Exam Pattern)

Q1. Define entropy. State and explain its properties. ★★★★★ Very Important, 5-7 Marks
Entropy H(X) = −ΣP(xᵢ)log₂P(xᵢ), average info/symbol. Properties: 0≤H(X)≤log₂n, =0 for certain event, max when equiprobable. (Asked almost every year)
Q2. State and prove the Source Coding Theorem (Shannon's First Theorem). ★★★★ 7 Marks
H(X) ≤ Lavg < H(X)+1. Explain that entropy is the lower bound for lossless average code length; discuss efficiency η = H(X)/Lavg and redundancy.
Q3. Differentiate between Mutual Information and Conditional Entropy. ★★★ 5 Marks
Mutual Info I(X;Y) = info gained about X via Y (common info, ≥0, symmetric). Conditional Entropy H(X|Y) = uncertainty remaining about X after knowing Y (info lost/equivocation). I(X;Y)=H(X)−H(X|Y).
Q4. What is a Discrete Memoryless Channel? Explain Binary Symmetric Channel (BSC) with diagram. ★★★★ 5-7 Marks
DMC: output depends only on present input, finite alphabets, no memory. BSC: 2-input 2-output channel with crossover probability p (Fig 2.2). Transition matrix: [[1−p, p],[p, 1−p]].
Q5. Numerical: A source has 4 symbols with probabilities 0.5, 0.25, 0.125, 0.125. Find entropy. ★★★★★ Almost guaranteed numerical
H(X) = 1.75 bits/symbol (full solution above in Example, Section 2). This exact-style numerical (powers of 2 probabilities) is the most repeated RTU question pattern.
Q6. Explain differential entropy for continuous random variables. Derive it for Gaussian distribution. ★★★ 5 Marks
h(X) = −∫f(x)log₂f(x)dx. For Gaussian: h(X) = ½log₂(2πeσ²). Mention it can be negative, unlike discrete entropy.
Q7. Derive the relation I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X). ★★★ 5 Marks
Start from H(X,Y)=H(X)+H(Y|X)=H(Y)+H(X|Y); rearrange and substitute into I(X;Y)=H(X)+H(Y)−H(X,Y) to get both forms. Use the Venn diagram (Fig 2.3) for visual proof.
Q8. Explain coding efficiency and redundancy with a numerical example. ★★ 3-5 Marks
η = H(X)/Lavg, Redundancy = 1−η. Numerical example given above (η=93.3%, redundancy=6.7%).
Q9. Why is the logarithmic function used to measure information? State the postulates. ★★★ 5 Marks
State 4 postulates (zero info for certain event, non-negativity, monotonic decrease with P, additivity for independent events) and explain that log is the unique function satisfying all four — see "Postulates for a Measure of Information" section above.
Q10. Prove that entropy is maximum when all symbols are equiprobable. ★★★★ 7 Marks — Lagrange multiplier proof
Use Lagrange multiplier method on L=−ΣPᵢlog₂Pᵢ+λ(ΣPᵢ−1); differentiate and set to zero to show Pᵢ=1/n for all i, giving Hmax=log₂n. Full derivation in "Proof: H(X) is Maximum..." section above.
Q11. Define Joint Entropy and Marginal Entropy. State the relation between them. ★★ 3-5 Marks
H(X,Y)=−ΣΣP(xᵢ,yⱼ)log₂P(xᵢ,yⱼ); marginal H(X)/H(Y) from row/column sums. Relation: H(X,Y)=H(X)+H(Y|X)=H(Y)+H(X|Y).
Q12. What is rate of information transmission? Give its formula. ★★ 2-3 Marks
R = r·H(X) bits/sec, where r = symbols emitted per second by the source, H(X) = entropy per symbol.
Q13. List and explain the properties of differential entropy. How does it differ from discrete entropy? ★★★ 5 Marks
h(X) can be negative; invariant to translation h(X+c)=h(X); h(aX)=h(X)+log₂|a|; Gaussian maximizes h(X) for given variance. Difference table given above (summation vs integration, sign, units).
Q14. Define instantaneous (prefix) code and state Kraft's inequality. ★★★ 5 Marks
Prefix code: no codeword is a prefix of another, decodable symbol-by-symbol. Kraft inequality: Σ2−lᵢ≤1 is necessary & sufficient condition for existence of such a code with lengths lᵢ.
Q15. Prove Shannon's Source Coding Theorem: H(X) ≤ Lavg < H(X)+1. ★★★★★ 10 Marks — long derivation, very important
Two-part proof using Gibbs' inequality (lower bound) and choosing lᵢ=⌈log₂(1/Pᵢ)⌉ (upper bound) — full step-by-step derivation in "Proof Sketch of Source Coding Theorem" section above.
Q16. Explain the different types of discrete channels (lossless, deterministic, noiseless) with their channel matrices. ★★★ 5 Marks
Lossless: one non-zero entry per column, H(X|Y)=0. Deterministic: one non-zero entry (=1) per row, H(Y|X)=0. Noiseless: both combined, identity matrix, I(X;Y)=H(X)=H(Y). Full table above.
Q17. Define channel capacity. Derive the channel capacity of a Binary Symmetric Channel. ★★★★★ 7-10 Marks — very important, numerical + theory combined
C = maxP(x) I(X;Y). For BSC, max occurs at P(0)=P(1)=0.5, giving C=1−H(p) where H(p)=−plog₂p−(1−p)log₂(1−p). Graph (Fig 2.4) shows C=1 at p=0/1, C=0 at p=0.5.
Q18. Numerical: For a BSC with p=0.2, find the channel capacity. ★★★★ 5 Marks numerical
H(0.2) = −0.2log₂0.2 −0.8log₂0.8 = 0.464+0.257 = 0.722 bits. C = 1−0.722 = 0.278 bits/symbol.
Q19. Prove that mutual information I(X;Y) is always non-negative. ★★★ 5 Marks proof
Apply Jensen's/Gibbs' inequality on −I(X;Y); since log is concave, −I(X;Y)≤log₂[ΣΣP(xᵢ)P(yⱼ)]=log₂1=0, hence I(X;Y)≥0. Full proof above.
Q20. Show that H(X|Y) ≤ H(X). What does this imply physically? ★★★ 5 Marks
Since I(X;Y)=H(X)−H(X|Y)≥0 (proved above), H(X|Y)≤H(X). Physical meaning: observing Y can never increase average uncertainty about X — side information never hurts.
