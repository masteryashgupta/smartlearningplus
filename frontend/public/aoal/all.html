Experiment 1: Quicksort Timing & Analysis

Aim: Sort a given set of elements using the Quicksort method and determine the time required to sort the elements. Repeat the experiment for different values of n (the number of elements in the list to be sorted) and plot a graph of the time taken versus n.

Source code

Compile with: gcc -O2 exp1_quicksort.c -o exp1 and run ./exp1 (or exp1 on Windows).

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int partition(int arr[], int low, int high) {

    int mid = low + (high - low) / 2;
    swap(&arr[mid], &arr[high]);
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    while (low < high) {
        int p = partition(arr, low, high);

        if (p - low < high - p) {
            quickSort(arr, low, p - 1);
            low = p + 1;
        } else {
            quickSort(arr, p + 1, high);
            high = p - 1;
        }
    }
}

int isSorted(int arr[], int n) {
    for (int i = 1; i < n; i++)
        if (arr[i - 1] > arr[i]) return 0;
    return 1;
}

int main(void) {
    int sizes[] = {10000, 20000, 40000, 60000, 80000, 100000, 200000, 400000, 600000, 800000, 1000000};
    int count = sizeof(sizes) / sizeof(sizes[0]);
    double times[sizeof(sizes) / sizeof(sizes[0])];

    srand((unsigned)time(NULL));

    printf("Experiment 1: Quicksort timing\n");
    printf("-------------------------------------\n");
    printf("%12s %18s %8s\n", "n", "Time (ms)", "Sorted");
    printf("-------------------------------------\n");

    for (int k = 0; k < count; k++) {
        int n = sizes[k];
        int *arr = (int *)malloc(n * sizeof(int));
        if (arr == NULL) {
            printf("Memory allocation failed for n = %d\n", n);
            return 1;
        }
        for (int i = 0; i < n; i++)
            arr[i] = rand();

        clock_t start = clock();
        quickSort(arr, 0, n - 1);
        clock_t end = clock();

        times[k] = ((double)(end - start) / CLOCKS_PER_SEC) * 1000.0;
        printf("%12d %18.3f %8s\n", n, times[k], isSorted(arr, n) ? "Yes" : "No");
        free(arr);
    }

    FILE *fp = fopen("exp1_data.txt", "w");
    if (fp) {
        for (int k = 0; k < count; k++)
            fprintf(fp, "%d %.3f\n", sizes[k], times[k]);
        fclose(fp);
        printf("\nData saved to exp1_data.txt (columns: n, time in ms)\n");
    }

    FILE *gp = fopen("exp1_plot.gp", "w");
    if (gp) {
        fprintf(gp, "set terminal png size 800,600\n");
        fprintf(gp, "set output 'exp1_graph.png'\n");
        fprintf(gp, "set title 'Quicksort: Time vs n'\n");
        fprintf(gp, "set xlabel 'n (number of elements)'\n");
        fprintf(gp, "set ylabel 'Time (ms)'\n");
        fprintf(gp, "set grid\n");
        fprintf(gp, "plot 'exp1_data.txt' using 1:2 with linespoints title 'Quicksort'\n");
        fclose(gp);
        if (system("gnuplot exp1_plot.gp") == 0)
            printf("Graph saved as exp1_graph.png\n");
        else
            printf("gnuplot not found. Plot exp1_data.txt in Excel/Python to get the graph.\n");
    }
    return 0;
}

Explanation & Complexity

  1. Divide and Conquer Strategy: Quicksort selects a pivot element (using median-of-three or middle element), partitions the array such that all elements smaller than pivot are on the left and larger on the right, then recursively sorts both subarrays.
  2. Optimization: This implementation eliminates tail recursion on the larger partition and always recurses on the smaller side first, guaranteeing logarithmic stack depth of at most O(log n).
  3. Time Complexity: Best Case: O(n log n), Average Case: O(n log n), Worst Case: O(n²) (mitigated by choosing mid pivot).
  4. Space Complexity: O(log n) auxiliary stack space (in-place sorting).

Viva questions

What is the divide-and-conquer strategy in Quicksort?

The problem is divided into two smaller subarrays around a chosen pivot element, the subarrays are sorted recursively, and no merge step is needed because elements are sorted in-place.

Why is the middle element chosen as the pivot here?

Choosing the middle element (or random/median) prevents the worst-case O(n²) behavior on already sorted or reverse-sorted input arrays.

How does tail recursion optimization help?

It limits the maximum call stack depth to O(log n) by iterating on the larger half instead of making a second recursive call.

Experiment 2: Parallel Merge Sort (OpenMP)

Aim: Implement Merge Sort algorithm to sort a given set of elements and determine the time required to sort the elements. Repeat the experiment for different values of n, the number of elements in the list to be sorted and plot a graph of the time taken versus n. The elements can be read from a file or can be generated using the random number generator. Also demonstrate speedup using OpenMP compiler directives for parallel execution.

Source code

Compile with OpenMP: gcc -O2 -fopenmp exp2_parallel_mergesort.c -o exp2 and run ./exp2 (or exp2 on Windows).

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#ifdef _OPENMP
#include <omp.h>
#endif

#define CUTOFF 10000

double now(void) {
#ifdef _OPENMP
    return omp_get_wtime();
#else
    return (double)clock() / CLOCKS_PER_SEC;
#endif
}

void merge(int arr[], int tmp[], int l, int m, int r) {
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r) {
        if (arr[i] <= arr[j]) tmp[k++] = arr[i++];
        else tmp[k++] = arr[j++];
    }
    while (i <= m) tmp[k++] = arr[i++];
    while (j <= r) tmp[k++] = arr[j++];
    memcpy(arr + l, tmp + l, (r - l + 1) * sizeof(int));
}

void mergeSortSeq(int arr[], int tmp[], int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSortSeq(arr, tmp, l, m);
    mergeSortSeq(arr, tmp, m + 1, r);
    merge(arr, tmp, l, m, r);
}

void mergeSortPar(int arr[], int tmp[], int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    if (r - l < CUTOFF) {
        mergeSortSeq(arr, tmp, l, m);
        mergeSortSeq(arr, tmp, m + 1, r);
    } else {
        #pragma omp task shared(arr, tmp)
        mergeSortPar(arr, tmp, l, m);
        #pragma omp task shared(arr, tmp)
        mergeSortPar(arr, tmp, m + 1, r);
        #pragma omp taskwait
    }
    merge(arr, tmp, l, m, r);
}

void parallelMergeSort(int arr[], int tmp[], int n) {
    #pragma omp parallel
    {
        #pragma omp single
        mergeSortPar(arr, tmp, 0, n - 1);
    }
}

int isSorted(int arr[], int n) {
    for (int i = 1; i < n; i++)
        if (arr[i - 1] > arr[i]) return 0;
    return 1;
}

int main(void) {
    int sizes[] = {10000, 50000, 100000, 500000, 1000000, 2000000, 4000000};
    int count = sizeof(sizes) / sizeof(sizes[0]);
    double tseq[sizeof(sizes) / sizeof(sizes[0])];
    double tpar[sizeof(sizes) / sizeof(sizes[0])];

    srand((unsigned)time(NULL));

#ifdef _OPENMP
    printf("OpenMP enabled, max threads = %d\n", omp_get_max_threads());
#else
    printf("OpenMP NOT enabled (compile with -fopenmp). Running serially.\n");
#endif
    printf("\nExperiment 2: Parallel Merge Sort timing\n");
    printf("---------------------------------------------------------------\n");
    printf("%10s %16s %16s %10s %8s\n", "n", "Sequential(ms)", "Parallel(ms)", "Speedup", "Sorted");
    printf("---------------------------------------------------------------\n");

    for (int k = 0; k < count; k++) {
        int n = sizes[k];
        int *a = (int *)malloc(n * sizeof(int));
        int *b = (int *)malloc(n * sizeof(int));
        int *tmp = (int *)malloc(n * sizeof(int));
        if (!a || !b || !tmp) {
            printf("Memory allocation failed for n = %d\n", n);
            return 1;
        }
        for (int i = 0; i < n; i++)
            a[i] = b[i] = rand();

        double t0 = now();
        mergeSortSeq(a, tmp, 0, n - 1);
        double t1 = now();
        parallelMergeSort(b, tmp, n);
        double t2 = now();

        tseq[k] = (t1 - t0) * 1000.0;
        tpar[k] = (t2 - t1) * 1000.0;
        printf("%10d %16.3f %16.3f %10.2f %8s\n", n, tseq[k], tpar[k],
               tpar[k] > 0 ? tseq[k] / tpar[k] : 0.0,
               (isSorted(a, n) && isSorted(b, n)) ? "Yes" : "No");

        free(a);
        free(b);
        free(tmp);
    }

    FILE *fp = fopen("exp2_data.txt", "w");
    if (fp) {
        for (int k = 0; k < count; k++)
            fprintf(fp, "%d %.3f %.3f\n", sizes[k], tseq[k], tpar[k]);
        fclose(fp);
        printf("\nData saved to exp2_data.txt (columns: n, sequential ms, parallel ms)\n");
    }

    FILE *gp = fopen("exp2_plot.gp", "w");
    if (gp) {
        fprintf(gp, "set terminal png size 800,600\n");
        fprintf(gp, "set output 'exp2_graph.png'\n");
        fprintf(gp, "set title 'Merge Sort: Time vs n'\n");
        fprintf(gp, "set xlabel 'n (number of elements)'\n");
        fprintf(gp, "set ylabel 'Time (ms)'\n");
        fprintf(gp, "set grid\n");
        fprintf(gp, "plot 'exp2_data.txt' using 1:2 with linespoints title 'Sequential', ");
        fprintf(gp, "'exp2_data.txt' using 1:3 with linespoints title 'Parallel'\n");
        fclose(gp);
        if (system("gnuplot exp2_plot.gp") == 0)
            printf("Graph saved as exp2_graph.png\n");
        else
            printf("gnuplot not found. Plot exp2_data.txt in Excel/Python to get the graph.\n");
    }
    return 0;
}

Explanation & Complexity

  1. Merge Sort Algorithm: Divides array in half, recursively sorts each half, and merges the two sorted halves into a temporary buffer using linear scans.
  2. Parallelization with OpenMP: The two recursive calls are spawned as asynchronous tasks using #pragma omp task. When subarray size falls below CUTOFF = 10000, it switches to sequential merge sort to avoid task scheduling overhead.
  3. Speedup: Speedup = T_sequential / T_parallel. For large input sizes ($n \ge 100,000$), parallel merge sort achieves significant multi-core speedup (typically $2 imes$ to $3.5 imes$ on modern multi-core CPUs).
  4. Time Complexity: Sequential: O(n log n). Parallel: O((n log n) / p) where $p$ is the number of processor cores.
  5. Space Complexity: O(n) auxiliary memory for the temporary merge buffer.

Viva questions

Why is a cutoff threshold (10,000) used for task parallelism?

Creating OpenMP tasks introduces small thread scheduling overheads. For small arrays, sequential execution is faster than task creation overhead.

What does #pragma omp taskwait do?

It ensures that both parallel sorting tasks complete before the main thread executes the merge function on the two sorted halves.

Is Merge Sort in-place? Is it stable?

Merge sort is stable (preserves original order of equal elements) but not in-place because it requires O(n) auxiliary memory for merging.

Experiment 3: Topological Ordering & Warshall's Transitive Closure

Aim: (a) Obtain the Topological ordering of vertices in a given digraph. (b) Compute the transitive closure of a given directed graph using Warshall's algorithm.

Source code

Compile with: gcc exp3_topological_warshall.c -o exp3 and run ./exp3 (or exp3 on Windows).

#include <stdio.h>

#define MAX 50

int n;
int adj[MAX][MAX];

void topologicalSort(void) {
    int indeg[MAX] = {0};
    int queue[MAX], front = 0, rear = 0;
    int order[MAX], cnt = 0;

    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (adj[i][j]) indeg[j]++;

    for (int i = 0; i < n; i++)
        if (indeg[i] == 0) queue[rear++] = i;

    while (front < rear) {
        int u = queue[front++];
        order[cnt++] = u;
        for (int v = 0; v < n; v++) {
            if (adj[u][v] && --indeg[v] == 0)
                queue[rear++] = v;
        }
    }

    if (cnt != n) {
        printf("\nThe graph contains a cycle. Topological ordering is not possible.\n");
        return;
    }
    printf("\nTopological ordering: ");
    for (int i = 0; i < n; i++)
        printf("%d%s", order[i], i < n - 1 ? " -> " : "\n");
}

void warshall(void) {
    int R[MAX][MAX];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            R[i][j] = adj[i][j];

    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                R[i][j] = R[i][j] || (R[i][k] && R[k][j]);

    printf("\nTransitive closure matrix:\n");
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++)
            printf("%d ", R[i][j]);
        printf("\n");
    }
}

int main(void) {
    printf("Experiment 3: Topological Ordering and Warshall's Transitive Closure\n");
    printf("Enter number of vertices (max %d): ", MAX);
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX) {
        printf("Invalid number of vertices.\n");
        return 1;
    }

    printf("Enter the %d x %d adjacency matrix (1 = edge, 0 = no edge):\n", n, n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (scanf("%d", &adj[i][j]) != 1) {
                printf("Invalid input.\n");
                return 1;
            }

    topologicalSort();
    warshall();
    return 0;
}

Explanation & Complexity

  1. Topological Sorting (Kahn's Algorithm): Computes the in-degree of all vertices. Vertices with in-degree 0 are placed in a queue. When removed, their outgoing edges are removed (decrementing destination in-degrees). If count of sorted vertices equals $n$, the ordering is valid; otherwise, a cycle exists.
  2. Warshall's Algorithm: Computes the reachability matrix (transitive closure) via Dynamic Programming. For each intermediate node $k$, vertex $i$ can reach vertex $j$ if R[i][j] = R[i][j] || (R[i][k] && R[k][j]).
  3. Time Complexity:
    • Topological Sort: O(V + E) using adjacency list / O(V²) using adjacency matrix.
    • Warshall's Algorithm: O(V³) due to 3 nested loops.
  4. Space Complexity: O(V²) for adjacency and reachability matrices.

Viva questions

Can topological sorting be performed on a graph with cycles?

No. Topological sorting is defined only for Directed Acyclic Graphs (DAGs). If a cycle is present, Kahn's algorithm reports that topological ordering is not possible.

What is transitive closure?

A matrix where entry (i, j) is 1 if there exists a directed path of any length from vertex i to vertex j, and 0 otherwise.

What is the recurrence relation in Warshall's algorithm?

R^(k)[i][j] = R^(k-1)[i][j] OR (R^(k-1)[i][k] AND R^(k-1)[k][j]), checking if path exists through intermediate node k.

Experiment 5: Dijkstra's Shortest Path Algorithm

Aim: From a given vertex in a weighted connected graph, find shortest paths to other vertices using Dijkstra's algorithm.

Source code

Compile with: gcc exp5_dijkstra.c -o exp5 and run ./exp5 (or exp5 on Windows).

#include <stdio.h>

#define MAX 50
#define INF 1000000000

int n;
int w[MAX][MAX];

void printPath(int parent[], int v) {
    if (parent[v] == -1) {
        printf("%d", v);
        return;
    }
    printPath(parent, parent[v]);
    printf(" -> %d", v);
}

void dijkstra(int src) {
    int dist[MAX], visited[MAX] = {0}, parent[MAX];

    for (int i = 0; i < n; i++) {
        dist[i] = INF;
        parent[i] = -1;
    }
    dist[src] = 0;

    for (int count = 0; count < n; count++) {
        int u = -1, min = INF;
        for (int i = 0; i < n; i++)
            if (!visited[i] && dist[i] < min) {
                min = dist[i];
                u = i;
            }
        if (u == -1) break;
        visited[u] = 1;

        for (int v = 0; v < n; v++) {
            if (w[u][v] > 0 && !visited[v] && dist[u] + w[u][v] < dist[v]) {
                dist[v] = dist[u] + w[u][v];
                parent[v] = u;
            }
        }
    }

    printf("\nShortest paths from vertex %d:\n", src);
    printf("%-8s %-10s %s\n", "Vertex", "Distance", "Path");
    for (int i = 0; i < n; i++) {
        printf("%-8d ", i);
        if (dist[i] == INF) {
            printf("%-10s %s\n", "INF", "No path");
        } else {
            printf("%-10d ", dist[i]);
            printPath(parent, i);
            printf("\n");
        }
    }
}

int main(void) {
    int src;
    printf("Experiment 5: Dijkstra's Shortest Path Algorithm\n");
    printf("Enter number of vertices (max %d): ", MAX);
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX) {
        printf("Invalid number of vertices.\n");
        return 1;
    }

    printf("Enter the %d x %d weight matrix (0 = no edge):\n", n, n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (scanf("%d", &w[i][j]) != 1 || w[i][j] < 0) {
                printf("Invalid input (weights must be non-negative).\n");
                return 1;
            }

    printf("Enter source vertex (0 to %d): ", n - 1);
    if (scanf("%d", &src) != 1 || src < 0 || src >= n) {
        printf("Invalid source vertex.\n");
        return 1;
    }

    dijkstra(src);
    return 0;
}

Explanation & Complexity

  1. Greedy Strategy: Maintains a set of vertices whose shortest distance from source is finalized. At each step, picks the unvisited vertex $u$ with minimum dist[u], marks it visited, and relaxes all adjacent edges (u, v).
  2. Edge Relaxation: If dist[u] + w[u][v] < dist[v], updates dist[v] = dist[u] + w[u][v] and tracks predecessor parent[v] = u for full path reconstruction.
  3. Constraint: Edge weights must be non-negative. For negative edge weights, Bellman-Ford algorithm must be used instead.
  4. Time Complexity: O(V²) using adjacency matrix (reducible to O(E log V) using a min-heap / priority queue).
  5. Space Complexity: O(V) for distance, visited, and parent arrays.

Viva questions

Why does Dijkstra's algorithm fail with negative edge weights?

Because Dijkstra greedily assumes that once a vertex is marked visited, its shortest distance cannot be further reduced. Negative edges violate this assumption.

How are the paths reconstructed in this program?

Using a parent array where parent[v] stores the predecessor of v along the shortest path, followed by recursive printing with printPath().

What is the difference between Prim's and Dijkstra's algorithms?

Prim's builds a Minimum Spanning Tree connecting all vertices with minimum total weight. Dijkstra finds the shortest path distance from a single source vertex to all other vertices.

Experiment 7: Graph Traversals (BFS and DFS)

Aim: (a) Print all the nodes reachable from a given starting node in a digraph using BFS method. (b) Check whether a given graph is connected or not using DFS method.

Source code

Compile with: gcc exp7_bfs_dfs.c -o exp7 and run ./exp7 (or exp7 on Windows).

#include <stdio.h>

#define MAX 50

int n;
int adj[MAX][MAX];
int visited[MAX];

int readGraph(void) {
    printf("Enter number of vertices (max %d): ", MAX);
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX) {
        printf("Invalid number of vertices.\n");
        return 0;
    }
    printf("Enter the %d x %d adjacency matrix (1 = edge, 0 = no edge):\n", n, n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (scanf("%d", &adj[i][j]) != 1) {
                printf("Invalid input.\n");
                return 0;
            }
    return 1;
}

void bfsReachable(void) {
    int start, queue[MAX], front = 0, rear = 0;

    if (!readGraph()) return;
    printf("Enter starting node (0 to %d): ", n - 1);
    if (scanf("%d", &start) != 1 || start < 0 || start >= n) {
        printf("Invalid starting node.\n");
        return;
    }

    for (int i = 0; i < n; i++) visited[i] = 0;
    visited[start] = 1;
    queue[rear++] = start;

    printf("\nNodes reachable from %d (BFS order): ", start);
    while (front < rear) {
        int u = queue[front++];
        printf("%d ", u);
        for (int v = 0; v < n; v++) {
            if (adj[u][v] && !visited[v]) {
                visited[v] = 1;
                queue[rear++] = v;
            }
        }
    }
    printf("\n");

    int unreachable = 0;
    for (int i = 0; i < n; i++)
        if (!visited[i]) {
            if (!unreachable) printf("Nodes NOT reachable: ");
            printf("%d ", i);
            unreachable = 1;
        }
    if (unreachable) printf("\n");
}

void dfs(int u) {
    visited[u] = 1;
    for (int v = 0; v < n; v++)
        if ((adj[u][v] || adj[v][u]) && !visited[v])
            dfs(v);
}

void dfsConnected(void) {
    if (!readGraph()) return;

    for (int i = 0; i < n; i++) visited[i] = 0;
    dfs(0);

    int connected = 1;
    for (int i = 0; i < n; i++)
        if (!visited[i]) {
            connected = 0;
            break;
        }

    if (connected)
        printf("\nThe graph is CONNECTED.\n");
    else
        printf("\nThe graph is NOT connected.\n");
}

int main(void) {
    int choice;
    printf("Experiment 7: BFS and DFS\n");
    printf("1. Print all nodes reachable from a start node in a digraph (BFS)\n");
    printf("2. Check whether a graph is connected (DFS)\n");
    printf("Enter your choice: ");
    if (scanf("%d", &choice) != 1) {
        printf("Invalid choice.\n");
        return 1;
    }

    switch (choice) {
        case 1: bfsReachable(); break;
        case 2: dfsConnected(); break;
        default: printf("Invalid choice.\n");
    }
    return 0;
}

Explanation & Complexity

  1. BFS (Breadth-First Search): Uses a FIFO Queue. Explores all neighbor vertices at the present depth level before moving on to vertices at the next depth level. Useful for finding all reachable nodes and shortest unweighted paths.
  2. DFS (Depth-First Search): Uses recursion / LIFO Stack. Explores as deep as possible along each branch before backtracking. If a single DFS traversal visits all $V$ vertices, the graph is connected.
  3. Time Complexity: Both BFS and DFS run in O(V²) using adjacency matrix representation (and O(V + E) using adjacency lists).
  4. Space Complexity: O(V) for the visited array, queue (BFS), and recursion call stack (DFS).

Viva questions

Which data structures are used by BFS and DFS?

BFS uses a Queue (FIFO) for level-by-level traversal. DFS uses a Stack (LIFO) or recursive function calls.

How does DFS determine if an undirected graph is connected?

Start DFS from vertex 0. After completion, check the visited array. If all vertices are visited (visited[i] == 1 for all i), the graph is connected.

What is the difference between BFS and DFS traversal trees?

BFS tree is shorter and bushier (breadth-first), finding shortest paths in unweighted graphs. DFS tree is deeper and narrower.

Experiment 10: N-Queens Problem using Backtracking

Aim: Implement N-Queens problem using Backtracking to place N queens on an N x N chessboard such that no two queens attack each other.

Source code

Compile with: gcc exp10_nqueens.c -o exp10 and run ./exp10 (or exp10 on Windows).

#define __USE_MINGW_ANSI_STDIO 1
#include <stdio.h>
#include <stdlib.h>

#define MAX 20
#define PRINT_LIMIT 10

int n;
int col[MAX];
long long solutions = 0;

int isSafe(int row, int c) {
    for (int r = 0; r < row; r++) {
        if (col[r] == c || abs(col[r] - c) == row - r)
            return 0;
    }
    return 1;
}

void printBoard(void) {
    printf("\nSolution %lld:\n", solutions);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++)
            printf("%c ", col[i] == j ? 'Q' : '.');
        printf("\n");
    }
}

void solve(int row) {
    if (row == n) {
        solutions++;
        if (solutions <= PRINT_LIMIT) printBoard();
        return;
    }
    for (int c = 0; c < n; c++) {
        if (isSafe(row, c)) {
            col[row] = c;
            solve(row + 1);
            col[row] = -1;
        }
    }
}

int main(void) {
    printf("Experiment 10: N-Queens Problem using Backtracking\n");
    printf("Enter the number of queens N (1 to %d): ", MAX);
    if (scanf("%d", &n) != 1 || n < 1 || n > MAX) {
        printf("Invalid value of N.\n");
        return 1;
    }

    for (int i = 0; i < MAX; i++) col[i] = -1;
    solve(0);

    if (solutions == 0)
        printf("\nNo solution exists for N = %d.\n", n);
    else {
        if (solutions > PRINT_LIMIT)
            printf("\n(Only the first %d solutions are displayed.)\n", PRINT_LIMIT);
        printf("\nTotal number of solutions for N = %d: %lld\n", n, solutions);
    }
    return 0;
}

Explanation & Complexity

  1. Backtracking Paradigm: Places queens one by one in different rows, starting from the first row. For each row, tries columns 0 to $N-1$. If placing a queen in column $c$ is safe, places it and recurses for the next row.
  2. Safety Condition: A position (row, c) is safe if no already placed queen shares the same column (col[r] == c) or the same diagonal (abs(col[r] - c) == row - r).
  3. Pruning: If no safe column is found in the current row, the algorithm immediately backtracks to the previous row and tries the next column, pruning vast branches of the search tree.
  4. Time Complexity: Worst-case O(N!), but significantly pruned in practice. For $N=4$ there are 2 solutions; for $N=8$ there are 92 solutions.
  5. Space Complexity: O(N) for the 1D array col[N] and the recursion stack.

Viva questions

Why is a 1D array col[N] sufficient instead of an N x N 2D array?

Since exactly one queen is placed per row, col[r] = c represents that the queen in row r is placed in column c.

How is diagonal attack checked mathematically?

Two queens at (r1, c1) and (r2, c2) share a diagonal if and only if |r1 - r2| == |c1 - c2|.

What is the difference between Backtracking and Brute Force?

Brute force evaluates all N^N possible queen configurations. Backtracking tests safety incrementally and abandons (prunes) an invalid partial state immediately.

Summary of algorithm design strategies

  1. Divide and Conquer: Breaks a problem into independent subproblems, solves them recursively, and combines the results (Quicksort, Merge Sort).
  2. Parallel Task Scheduling: Uses OpenMP compiler pragmas (#pragma omp task) to distribute subproblems concurrently across multi-core CPU threads.
  3. Greedy Strategy: Makes the locally optimal choice at each step without reconsidering prior decisions (Dijkstra's shortest path).
  4. Dynamic Programming: Solves overlapping subproblems iteratively by updating a table (Warshall's transitive closure).
  5. Graph Traversals: Systematically visits all vertices: BFS uses a FIFO queue level-by-level, while DFS explores deeply along branches using recursion/stack.
  6. Backtracking: Builds candidate solutions incrementally and abandons ("backtracks") immediately when constraints are violated (N-Queens).
