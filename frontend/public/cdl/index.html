🧠 Quick Viva Reference

What is a compiler?

A program that translates a whole source program written in a high-level language into machine code and reports errors.

What are the phases of a compiler?

Lexical analysis → Syntax analysis → Semantic analysis → Intermediate code generation → Code optimization → Code generation. Symbol table and error handler support all phases.

What is LEX?

A tool that generates a lexical analyzer (scanner) in C from regular-expression rules.

What is YACC?

Yet Another Compiler Compiler – generates a bottom-up LALR(1) parser in C from a context-free grammar.

How do LEX and YACC work together?

LEX reads characters and returns tokens; YACC calls yylex() to get tokens and validates them against the grammar.

What is a symbol table?

A data structure storing information (name, type, scope, address) about identifiers, used by all phases of compilation.

What is a^n b^n?

Strings with n a's followed by n b's (ab, aabb, aaabbb…). Cannot be recognized by a regular expression; needs a context-free grammar (stack).

How to compile a LEX program?

lex file.l → cc lex.yy.c -lfl → ./a.out

How to compile a YACC + LEX program?

yacc -d file.y → lex file.l → cc y.tab.c lex.yy.c → ./a.out
