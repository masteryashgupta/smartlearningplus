0/1 Knapsack (Dynamic Programming) kya hai?

Ye Exp-7 wale Greedy Knapsack jaisa hi problem hai — bag hai, capacity fix hai, items hain (weight aur profit ke saath), aur maximum profit chahiye. Lekin ek badi condition hai: is baar item ko TODA nahi ja sakta! Ya to pura item lo (1), ya bilkul mat lo (0) — isiliye naam hai "0/1 Knapsack".

Greedy method (jo Exp-7 mein use hui thi) yahan kaam nahi karta, kyunki "best ratio wala item pehle lo" wala tarika hamesha sabse achha answer nahi deta jab items todhe nahi ja sakte. Isliye yahan Dynamic Programming (DP) use karte hain, jisme hum saari possibilities ko systematically ek table mein store karke best answer dhundte hain.

DP ka idea: ek table banao jisme rows items hon aur columns capacity (0 se max capacity tak) ho. Har cell mein store karo "agar itne items available hon aur itni capacity ho, to maximum profit kitna milega". Har item ke liye 2 choices check karo: use lo, ya mat lo — jo bhi zyada profit de, wahi table mein daal do. Aakhir mein last cell mein final maximum profit mil jaata hai.


Chhota example:

4 items:
Item 1: weight=1, profit=1
Item 2: weight=3, profit=4
Item 3: weight=4, profit=5
Item 4: weight=5, profit=7

Bag capacity = 7

DP table banti hai jisme har item ke liye check hota hai:
- Agar is item ka weight capacity se zyada hai -> mat lo, pichle wala answer hi rakho
- Agar le sakte ho -> compare karo: "isko lekar jo profit milega" VS "na lekar jo profit tha", jo zyada ho wahi rakho

Is process ke baad best combination milta hai: Item 2 (weight=3, profit=4) + Item 3 (weight=4, profit=5)
Total weight = 3+4 = 7 (exactly capacity ke andar)
Total profit = 4+5 = 9

Maximum Profit = 9

(Note: Greedy method is example pe alag combination bhi de sakta tha kyunki ratio-based hota hai, lekin DP hamesha GUARANTEED best answer deta hai 0/1 case mein)


Speed ka mamla:

0/1 Knapsack DP ka time complexity O(n x W) hai, jahan n = items ki sankhya aur W = bag ki capacity. Ye Greedy se thoda slow ho sakta hai bade capacity ke liye, lekin ye hamesha SAHI (optimal) answer guarantee karta hai, jabki Greedy sirf Fractional case mein hi optimal hota hai.


Tera program kya karta hai:

1. Tujhse pucha jaata hai kitne items hain, aur har item ka weight aur profit.
2. Tujhse bag ki capacity puchi jaati hai.
3. Program ek DP table banata hai aur use bottom-up (chhote sub-problems se bade sub-problems tak) fill karta hai (upar wala process).
4. Table se wapas trace karke ye dekha jaata hai konse items actually liye gaye the, aur unhe "Taken" bata diya jaata hai.
5. Last mein maximum profit print hota hai.
6. Calculation mein kitna time laga, wo bhi dikhaya jaata hai.

Bas itna hi — har item ke liye "lo ya mat lo" dono options check karo table mein, jo zyada profit de wahi rakho, item ko toda nahi ja sakta.
