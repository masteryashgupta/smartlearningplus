1. Uncertainty & Information High ⭐⭐⭐

English

Uncertainty of an event is a measure of how unpredictable its occurrence is — the lower the probability of an event, the higher the uncertainty/surprise when it occurs.

Information conveyed by a message is inversely related to its probability of occurrence. If event x has probability P(x), the information content is:

I(x) = log₂( 1 / P(x) ) = − log₂ P(x)    [bits]
Hinglish

Soch — agar koi event hamesha hota hai (P=1), to usme koi "naya" info nahi (I=0). Lekin agar koi rare event hota hai (P chhota), to usme bahut "surprise" / information hoti hai. Jaise "Kal Sun nikla" (P≈1 → info≈0) vs "Aaj Jaipur mein snowfall hua" (P≈0 → info bahut high!).

Units of Information

Log BaseUnitUsed When
log₂bitBinary systems (most common, default in exams)
log₁₀Hartley / decitDecimal systems
logₑ (ln)natNatural log, used in continuous/differential entropy

Properties of Information Measure Medium

  1. I(x) = 0, when P(x) = 1 (certain event carries no information).
  2. I(x) ≥ 0, since 0 ≤ P(x) ≤ 1 (information is never negative).
  3. I(x₂) > I(x₁), if P(x₂) < P(x₁) (lower probability ⇒ more information).
  4. If x₁ and x₂ are independent: I(x₁,x₂) = I(x₁) + I(x₂) (additivity property).
Example

A binary source emits '0' with P=0.25 and '1' with P=0.75. Find information carried by each symbol.

Solution:
I(0) = −log₂(0.25) = log₂4 = 2 bits
I(1) = −log₂(0.75) = 0.415 bits
→ Rarer symbol '0' carries more information than frequent symbol '1'.

1B. Postulates for a Measure of Information (Why Logarithm?) Medium ⭐⭐ — "Why log?" theory question

English

Shannon defined information using a logarithmic function based on the following postulates (axioms) that any reasonable information measure I(P) must satisfy:

  1. Postulate 1: I(P) = 0 when P = 1 (a certain event gives zero information).
  2. Postulate 2: I(P) ≥ 0 for 0 ≤ P ≤ 1 (information is non-negative).
  3. Postulate 3: I(P₁) > I(P₂) if P₁ < P₂ (monotonically decreasing — rarer event ⇒ more information).
  4. Postulate 4 (Additivity): I(P₁·P₂) = I(P₁) + I(P₂) for independent events (joint information of independent events = sum of individual information).

The only mathematical function satisfying all four postulates simultaneously is the logarithmic function: I(x) = log(1/P(x)). This is why entropy/information is always defined using logarithms, not any other function.

Hinglish

Yeh question aksar aata hai: "Information measure ke liye log function hi kyu use hota hai?" — Answer simple hai: Shannon ne 4 conditions (postulates) set ki jo ek "sensible" information measure follow karna chahiye, aur jab tum maths se check karo, sirf logarithm function hi un sab conditions ko satisfy karta hai (especially additivity property — independent events ka information add hona chahiye, multiply nahi, aur log(a·b)=log(a)+log(b) yehi karta hai).

2. Entropy High ⭐⭐⭐⭐⭐ (Most Important)

English

Entropy H(X) is the average (expected) information per symbol generated by a discrete memoryless source. It measures the average uncertainty of a random variable.

H(X) = − Σ P(xᵢ) · log₂ P(xᵢ)   [bits/symbol]    i = 1...n
Hinglish

Entropy = "average information" jo ek source produce karta hai per symbol. Agar source bahut predictable hai (jaise hamesha same letter), entropy kam hogi. Agar source bahut random hai (sab symbols equally likely), entropy maximum hogi. Isiliye entropy ko "average surprise" bhi kehte hain.

Properties of Entropy High

  1. 0 ≤ H(X) ≤ log₂(n), where n = number of symbols.
  2. H(X) = 0, when one symbol has probability 1 (no uncertainty — fully predictable).
  3. H(X) is maximum (= log₂ n) when all symbols are equiprobable (P = 1/n each) — maximum uncertainty.
  4. Entropy is a concave function of probability distribution.

Fig 2.1 — Binary Entropy Function H(p) = −p·log₂p − (1−p)·log₂(1−p). Peaks at p = 0.5

Example (very commonly asked numerical)

A source emits 4 symbols with probabilities: P(x₁)=0.5, P(x₂)=0.25, P(x₃)=0.125, P(x₄)=0.125. Find entropy.

Solution:
H(X) = −[0.5log₂0.5 + 0.25log₂0.25 + 0.125log₂0.125 + 0.125log₂0.125]
= −[0.5(−1) + 0.25(−2) + 0.125(−3) + 0.125(−3)]
= 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits/symbol

Proof: H(X) is Maximum when Symbols are Equiprobable High — common 5-mark proof question

To maximize H(X) = −ΣPᵢ log₂Pᵢ subject to constraint ΣPᵢ = 1, apply Lagrange multipliers:

L = −Σ Pᵢ log₂Pᵢ + λ(Σ Pᵢ − 1) ∂L/∂Pᵢ = −log₂Pᵢ − log₂e + λ = 0 ⟹ Pᵢ = constant for all i = 1/n

Substituting Pi = 1/n back gives Hmax(X) = log₂n. Hence entropy is maximum exactly when all symbols are equally likely — this is the equiprobable / uniform distribution case.

Example (non power-of-2 probabilities)

A discrete memoryless source emits 3 symbols with P(x₁)=0.6, P(x₂)=0.3, P(x₃)=0.1. Find H(X) and compare with the maximum possible entropy for a 3-symbol source.

Solution:
Since these are not clean powers of ½, use log₂x = ln x / ln 2 (or log₁₀x / log₁₀2):
log₂0.6 = −0.737,   log₂0.3 = −1.737,   log₂0.1 = −3.322
H(X) = −[0.6(−0.737) + 0.3(−1.737) + 0.1(−3.322)]
= 0.442 + 0.521 + 0.332 = 1.295 bits/symbol
Hmax = log₂3 = 1.585 bits/symbol (equiprobable case, each P=1/3)

💡 Since H(X) = 1.295 < Hmax = 1.585, this confirms the source is not "maximally random" — it carries some redundancy because the symbols are not equiprobable (x₁ is much more likely than x₃).

Joint Entropy & Marginal Entropy Medium ⭐⭐⭐

English

Joint Entropy H(X,Y) is the average uncertainty associated with a pair of random variables (X,Y) taken together:

H(X,Y) = − Σᵢ Σⱼ P(xᵢ,yⱼ) · log₂ P(xᵢ,yⱼ)

Marginal Entropy is simply H(X) or H(Y) computed individually from the marginal probability distributions P(xᵢ)=ΣⱼP(xᵢ,yⱼ) and P(yⱼ)=ΣᵢP(xᵢ,yⱼ).

Hinglish

Joint entropy = dono variables X aur Y ko ek saath consider karke total uncertainty. Marginal entropy = sirf X (ya sirf Y) ki uncertainty, dusre ko "ignore" karke (uski sab possibilities sum kar di).

Key relation: H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

Rate of Information Transmission Low-Medium ⭐

English

If a discrete source emits r symbols per second, the rate of information R (in bits/second) is:

R = r · H(X)    [bits/second]
Hinglish

Simple — entropy batati hai "per symbol" kitni info hai, aur agar tumhe pata hai ki source ek second mein kitne symbols bhejta hai (r), to dono multiply karke total info-rate (bits/sec) mil jaata hai.

3. Information Measures for Continuous Random Variables Medium ⭐⭐

English

For a continuous random variable X with probability density function f(x), the average information is called differential entropy:

h(X) = − ∫−∞+∞ f(x) · log₂ f(x) dx
Hinglish

Discrete entropy mein hum probabilities ka sum karte hain, continuous case mein (jaise voltage, temperature signals) probability ki jagah density function f(x) hota hai, aur sum ki jagah integral. Important difference: differential entropy negative bhi ho sakti hai (discrete entropy kabhi negative nahi hoti)!

Differential Entropy of Gaussian (Normal) Distribution Often Asked

For X ~ N(μ, σ²):

h(X) = ½ log₂(2πeσ²)

This is the maximum differential entropy among all continuous distributions with the same variance σ² — i.e., for a fixed power/variance constraint, the Gaussian source is the "most random" (max entropy) source.

Example — Uniform Distribution

A continuous random variable X is uniformly distributed over the interval [0, 8], i.e. f(x) = 1/8 for 0≤x≤8. Find its differential entropy h(X).

Solution:
For a uniform distribution over [a,b], f(x) = 1/(b−a), so:
h(X) = −∫ab (1/(b−a))·log₂(1/(b−a)) dx = log₂(b−a)
Here (b−a) = 8, so h(X) = log₂8 = 3 bits

💡 General shortcut: for uniform X on [a,b], h(X) = log₂(b−a). If (b−a) < 1, h(X) becomes negative — a perfectly valid result for differential entropy (unlike discrete entropy, which can never be negative).

Properties of Differential Entropy Medium

  1. h(X) can be negative, zero, or positive (unlike discrete entropy which is always ≥ 0).
  2. h(X + c) = h(X) for any constant c (translation/shifting does not change differential entropy).
  3. h(aX) = h(X) + log₂|a| (scaling changes differential entropy by log of the scale factor).
  4. Among all continuous distributions with a given variance σ², the Gaussian distribution has maximum differential entropy.

Joint & Conditional Differential Entropy Low ⭐

h(X,Y) = − ∬ f(x,y) · log₂ f(x,y) dx dy h(X|Y) = − ∬ f(x,y) · log₂ f(x|y) dx dy Mutual Information (continuous): I(X;Y) = h(X) − h(X|Y)
Hinglish

Bilkul discrete case jaisa hi pattern — sirf summation (Σ) ko integration (∫) se replace kar do, aur probability P ko density f(x) se. Concept same hai, sirf continuous variable ke liye adapted.

4. Source Coding Theorem (Shannon's First Theorem) High ⭐⭐⭐⭐

English

Shannon's Source Coding Theorem states that for a discrete memoryless source with entropy H(X), it is possible to construct a code with average codeword length Lavg such that:

H(X) ≤ Lavg < H(X) + 1

In other words: average code length can never be less than the source entropy — entropy is the fundamental lower bound on lossless compression.

Hinglish

Yani — tum kisi bhi source ke data ko itna compress nahi kar sakte ki average bits/symbol entropy se kam ho jaaye. Entropy ek "theoretical limit" hai compression ka. Jaise ZIP/Huffman coding isi limit ke jitna close pohochne ki koshish karte hain.

Coding Efficiency & Redundancy Numerical-friendly

η (Efficiency) = H(X) / Lavg     Redundancy = 1 − η

Higher efficiency (closer to 1, or 100%) means the code is closer to the theoretical entropy limit — better compression.

Example

A source has H(X) = 1.75 bits/symbol. A code is designed with Lavg = 1.875 bits/symbol. Find efficiency and redundancy.

Solution:
η = 1.75/1.875 = 0.933 = 93.3%
Redundancy = 1 − 0.933 = 0.067 (6.7%)

Codes, Code Length & Kraft Inequality Medium ⭐⭐

English

A code assigns a sequence of binary digits (codeword) to each source symbol. Key code types:

  • Fixed-length code: all codewords have equal length.
  • Variable-length code: codeword length varies (shorter for high-probability symbols).
  • Uniquely decodable code: no ambiguity — any coded sequence can be decoded in only one way.
  • Instantaneous (prefix) code: no codeword is a prefix of another codeword — can be decoded symbol-by-symbol without lookahead.

Kraft Inequality: A prefix (instantaneous) code with codeword lengths l₁, l₂,...,lₙ exists if and only if:

Σᵢ 2−lᵢ ≤ 1
Hinglish

Kraft inequality batati hai ki given lengths ke saath ek valid "instantaneous/prefix code" possible hai ya nahi — agar sab 2−lᵢ ka sum ≤1 hai, to aisa code ban sakta hai jisme koi codeword kisi doosre ka prefix na ho (taaki decode karte waqt confusion na ho).

Huffman Coding — Constructing an Optimal Instantaneous Code High ⭐⭐⭐⭐ — practical construction, frequently asked

English

Huffman coding is a greedy algorithm that constructs an optimal (minimum Lavg) prefix code for a given set of symbol probabilities:

  1. List all symbols in decreasing order of probability.
  2. Combine the two lowest-probability symbols into a single node (sum of probabilities); assign one branch '0' and the other '1'.
  3. Repeat step 2 with the new reduced list until only one node (probability 1) remains.
  4. Read each symbol's codeword by tracing the tree from root to leaf.
Hinglish

Huffman coding ka simple logic: jo symbol sabse kam probable hai, use sabse lambi codeword milegi, aur jo sabse zyada probable hai use sabse chhoti codeword. Har step pe do sabse chhoti probabilities ko "merge" karte jao jab tak sirf ek bache — yehi tree banata hai jisse codewords milte hain.

Example (continuing the same 4-symbol source)

For the source with P(x₁)=0.5, P(x₂)=0.25, P(x₃)=0.125, P(x₄)=0.125 (H(X)=1.75 bits/symbol, from Section 2), construct a Huffman code and verify its efficiency.

Solution — building the tree:
Step 1: Combine x₃(0.125) & x₄(0.125) → node A (0.25)
Step 2: Combine A(0.25) & x₂(0.25) → node B (0.5)
Step 3: Combine B(0.5) & x₁(0.5) → root (1.0)

SymbolProbabilityCodewordLength lᵢ
x₁0.501
x₂0.25102
x₃0.1251103
x₄0.1251113

Lavg = Σ Pᵢlᵢ = 0.5(1)+0.25(2)+0.125(3)+0.125(3) = 0.5+0.5+0.375+0.375 = 1.75 bits/symbol
Since Lavg = H(X) exactly, efficiency η = 100% — this happens because all probabilities are exact negative powers of 2 (0.5=2⁻¹, 0.25=2⁻², 0.125=2⁻³), which is the ideal case for Huffman/Shannon-Fano coding.

💡 Check the prefix property: {0, 10, 110, 111} — no codeword is a prefix of another, so it is instantaneously (uniquely) decodable. Also verify Kraft's inequality: 2⁻¹+2⁻²+2⁻³+2⁻³ = 0.5+0.25+0.125+0.125 = 1 ≤ 1 ✓ (equality means the code is 100% efficient, no wasted code-space).

Proof Sketch of Source Coding Theorem High ⭐⭐⭐ — 10-mark derivation

Lower bound (Lavg ≥ H(X)): By Gibbs' inequality, for any two probability distributions P and Q: −ΣPᵢlog₂Pᵢ ≤ −ΣPᵢlog₂Qᵢ. Choosing Qᵢ = 2−lᵢ/Σ2−lⱼ and using the Kraft inequality (Σ2−lᵢ≤1), it follows algebraically that:

Lavg = Σ Pᵢ lᵢ ≥ H(X)

Upper bound (Lavg < H(X)+1): Choose codeword length lᵢ = ⌈log₂(1/Pᵢ)⌉ (smallest integer ≥ log₂(1/Pᵢ)). This satisfies the Kraft inequality (so a valid prefix code exists), and gives:

log₂(1/Pᵢ) ≤ lᵢ < log₂(1/Pᵢ) + 1  ⟹  H(X) ≤ Lavg < H(X) + 1

Combining both bounds proves Shannon's Source Coding Theorem: entropy is the achievable lower limit of average code length, approachable within 1 bit by simple symbol-by-symbol coding (and exactly approachable using block/extension coding as block length → ∞).

5. Discrete Memoryless Channel (DMC) High ⭐⭐⭐

English

A Discrete Memoryless Channel is a channel whose output at any time depends only on the input at that same time instant (not on past inputs/outputs), and both input X and output Y take values from finite discrete alphabets. It is described by a transition probability matrix P(yⱼ|xᵢ).

Hinglish

"Memoryless" matlab — channel ka current output sirf current input pe depend karta hai, purane inputs/outputs ka kuch effect nahi (no memory of past). Ye ek mathematical model hai jo channel ki "noise behavior" ko probability matrix se represent karta hai.

Fig 2.2 — Binary Symmetric Channel (BSC): the simplest and most-asked DMC example. 'p' = crossover (error) probability

Channel Matrix / Transition Probability Matrix Medium

A DMC is fully described by its channel matrix, where rows = inputs, columns = outputs, each entry = P(yⱼ|xᵢ):

[P(Y|X)] = | P(y₁|x₁) P(y₂|x₁) | | P(y₁|x₂) P(y₂|x₂) |

Each row sums to 1 (since for a fixed input, output probabilities over all possibilities must total 1). For BSC: [[1−p, p],[p, 1−p]].

Types of Discrete Channels Medium ⭐⭐ — definition based

Channel TypePropertyChannel Matrix Feature
Lossless ChannelNo information is lost; H(X|Y)=0Only one non-zero entry per column
Deterministic ChannelEach input maps to exactly one output; H(Y|X)=0Only one non-zero entry (=1) per row
Noiseless ChannelBoth lossless and deterministic; I(X;Y)=H(X)=H(Y)Identity matrix (square, diagonal)
Binary Symmetric Channel (BSC)Symmetric error probability p in both directions[[1−p,p],[p,1−p]]
Hinglish

Lossless = output se input bilkul reverse-trace ho sakta hai (no info kho rahi). Deterministic = ek fixed input se hamesha same output aata hai (no randomness output side pe). Noiseless = best case, dono properties saath — channel perfectly clean hai.

Example — Finding P(Y) and H(Y) from a Channel Matrix

A DMC has input probabilities P(x₁)=0.6, P(x₂)=0.4 and channel matrix [P(Y|X)] = [[0.9, 0.1],[0.2, 0.8]] (row = input, column = output). Find P(y₁), P(y₂) and H(Y).

Solution:
Output probabilities are found using total probability: P(yⱼ) = Σᵢ P(xᵢ)·P(yⱼ|xᵢ)
P(y₁) = P(x₁)P(y₁|x₁) + P(x₂)P(y₁|x₂) = 0.6(0.9) + 0.4(0.2) = 0.54 + 0.08 = 0.62
P(y₂) = P(x₁)P(y₂|x₁) + P(x₂)P(y₂|x₂) = 0.6(0.1) + 0.4(0.8) = 0.06 + 0.32 = 0.38
Check: P(y₁)+P(y₂) = 0.62+0.38 = 1 ✓
H(Y) = −[0.62log₂0.62 + 0.38log₂0.38] = −[0.62(−0.690)+0.38(−1.396)] = 0.428+0.530 = 0.958 bits

💡 Exam tip: write P(Y) as a row vector = [P(X)] × [Channel Matrix] (matrix multiplication) — this is the fastest way to get output probabilities for any DMC, not just a BSC.

Channel Capacity High ⭐⭐⭐⭐ — frequently asked with BSC numerical

English

Channel Capacity C is the maximum rate of reliable information transmission over a channel, defined as the maximum of mutual information over all possible input probability distributions P(x):

C = maxP(x) I(X;Y)   [bits/symbol or bits/channel use]

For a Binary Symmetric Channel with crossover probability p, capacity is maximized at P(0)=P(1)=0.5 and equals:

CBSC = 1 − H(p) = 1 + p·log₂p + (1−p)·log₂(1−p)
Hinglish

Channel capacity = channel ka "speed limit" — usse zyada rate pe reliably (error-free) data nahi bhej sakte (ye Shannon ka famous result hai, jise "Shannon Limit" bhi kehte hain). BSC ke liye capacity formula bahut common numerical hai — agar p=0 (no error), C=1 bit/symbol (perfect channel); agar p=0.5 (channel totally random), C=0 (channel useless).

Fig 2.4 — BSC Capacity vs crossover probability p. C=1 at p=0 or p=1 (no ambiguity), C=0 at p=0.5 (max confusion)

6. Mutual Information High ⭐⭐⭐⭐

English

Mutual Information I(X;Y) is the amount of information that one random variable (channel output Y) contains about another (channel input X). It measures the reduction in uncertainty about X after observing Y.

I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y)
Hinglish

Mutual information batata hai — receiver ne Y dekhne ke baad, X ke baare mein kitni uncertainty kam ho gayi. Agar channel "perfect" hai (no noise), to Y dekhke X 100% pata chal jaata hai → I(X;Y) = H(X) (maximum). Agar channel bahut noisy hai, I(X;Y) → 0 (Y se X ke baare mein kuch pata nahi chalta).

Properties of Mutual Information

  1. I(X;Y) ≥ 0 (always non-negative).
  2. I(X;Y) = I(Y;X) (symmetric).
  3. I(X;Y) = 0, if and only if X and Y are statistically independent.
  4. I(X;Y) ≤ min[H(X), H(Y)].

Proof: I(X;Y) ≥ 0 Medium ⭐⭐ — proof-based question

Using I(X;Y) = ΣΣ P(xᵢ,yⱼ) log₂[P(xᵢ,yⱼ)/(P(xᵢ)P(yⱼ))], apply Jensen's/Gibbs' inequality (log is concave, and treating P(xᵢ)P(yⱼ) as an alternate distribution Q over the same support):

−I(X;Y) = ΣΣ P(xᵢ,yⱼ) log₂[P(xᵢ)P(yⱼ)/P(xᵢ,yⱼ)] ≤ log₂[ΣΣ P(xᵢ)P(yⱼ)] (by Jensen's inequality, since log is concave) = log₂[1] = 0 ⟹ I(X;Y) ≥ 0 (equality holds iff X,Y are independent)
Example — Mutual Information for an Asymmetric Channel

Using the same channel from the earlier example — P(x₁)=0.6, P(x₂)=0.4, matrix [[0.9,0.1],[0.2,0.8]], with P(y₁)=0.62, P(y₂)=0.38, H(Y)=0.958 bits — find H(Y|X) and I(X;Y).

Solution:
H(Y|X) = Σᵢ P(xᵢ)·H(Y|X=xᵢ), where H(Y|X=xᵢ) is the entropy of row i of the channel matrix:
H(Y|x₁) = −[0.9log₂0.9+0.1log₂0.1] = 0.137+0.332 = 0.469 bits
H(Y|x₂) = −[0.2log₂0.2+0.8log₂0.8] = 0.464+0.257 = 0.722 bits
H(Y|X) = 0.6(0.469) + 0.4(0.722) = 0.281 + 0.289 = 0.570 bits
I(X;Y) = H(Y) − H(Y|X) = 0.958 − 0.570 = 0.388 bits

💡 Exam shortcut: H(Y|X) is a weighted average of the row entropies of the channel matrix, weighted by the input probabilities P(xᵢ) — this works for any DMC, not just symmetric ones like BSC.

7. Conditional Entropy High ⭐⭐⭐

English

Conditional Entropy H(X|Y) is the average uncertainty remaining about X, after the output Y has been observed. It is also called "equivocation" — represents information lost in a noisy channel.

H(X|Y) = − Σᵢ Σⱼ P(xᵢ,yⱼ) · log₂ P(xᵢ|yⱼ)
Hinglish

H(X|Y) = "Y pata hone ke baad bhi X mein kitni confusion baaki hai". Isiliye ise equivocation bhi kehte hain — ye represent karta hai ki noise ki wajah se kitni info "lost" ho gayi transmission mein.

Example (classic RTU-style)

For a BSC with P(0)=P(1)=0.5 and crossover probability p=0.1, find H(X), H(Y|X), and I(X;Y).

Solution:
H(X) = −(0.5log₂0.5+0.5log₂0.5) = 1 bit
H(p) = −p log₂p −(1−p)log₂(1−p) = −0.1log₂0.1 −0.9log₂0.9 = 0.1(3.32)+0.9(0.152) = 0.469 bits
Since the channel is symmetric and the input is equiprobable, the output is also equiprobable ⟹ H(Y) = 1 bit, and H(Y|X) = H(p) = 0.469 bits
I(X;Y) = H(Y) − H(Y|X) = 1 − 0.469 = 0.531 bits  (≈53% of the source information survives transmission through this noisy channel per symbol)

💡 This equals the channel capacity C = 1−H(0.1) computed earlier for the same p — that's because equiprobable input is exactly the capacity-achieving distribution for a BSC, so at P(0)=P(1)=0.5 the mutual information already equals C.

Proof: H(X|Y) ≤ H(X) Medium ⭐⭐ — proof question

Since I(X;Y) = H(X) − H(X|Y) and we proved I(X;Y) ≥ 0 above, it directly follows that:

H(X|Y) = H(X) − I(X;Y) ≤ H(X)

This makes intuitive sense: knowing Y can never increase uncertainty about X on average — at worst (when X,Y independent), H(X|Y)=H(X) (no help), and otherwise it strictly reduces uncertainty.

UNIT 2: Information Measurement, Entropy & Channels

1. Information & Entropy

  • Self Information: $I(x_i) = \log_2(1/p_i)$ bits
  • Entropy $H(X)$: $\sum p_i \log_2(1/p_i)$ (Max $\log_2 M$ at equiprobable)
  • Continuous Entropy: $h(X) = -\int f(x)\log_2 f(x)dx$

2. Joint & Conditional Entropy

  • Joint Entropy: $H(X,Y) = -\sum \sum P(x_i, y_j)\log_2 P(x_i, y_j)$
  • Conditional: $H(X|Y) = H(X,Y) - H(Y) \le H(X)$
  • Mutual Info: $I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$

3. Discrete Memoryless Channels

  • DMC: Channel matrix $[P(y_j|x_i)]$, memoryless property
  • BSC: Binary Symmetric Channel with crossover $p$ ($C = 1 - H(p)$)
  • BEC: Binary Erasure Channel with erasure prob $\epsilon$ ($C = 1 - \epsilon$)

❓ Unit 2 — Q&A (RTU Exam Pattern)

Q1. Define entropy. State and explain its properties. ★★★★★ Very Important, 5-7 Marks

Definition: Entropy H(X) is the average (expected) amount of information produced per symbol by a discrete memoryless source. It is given by H(X) = −Σ P(xᵢ)·log₂P(xᵢ) bits/symbol, where the sum runs over all n symbols of the source alphabet.

Properties:

  1. 0 ≤ H(X) ≤ log₂n — entropy is always bounded between zero and log₂n.
  2. H(X) = 0 only when one symbol has probability 1 (source is fully predictable, no uncertainty).
  3. H(X) is maximum (= log₂n) when all n symbols are equiprobable (P=1/n each) — this is the state of maximum uncertainty/randomness.
  4. Entropy is a concave function of the probability distribution.

This topic is asked almost every year, usually paired with a numerical (see Q5) or the maximum-entropy proof (see Q10).

Q2. State and prove the Source Coding Theorem (Shannon's First Theorem). ★★★★ 7 Marks

Statement: For a discrete memoryless source with entropy H(X), it is always possible to construct a uniquely decodable (prefix) code with average codeword length Lavg satisfying H(X) ≤ Lavg < H(X)+1.

Proof (two parts): The lower bound Lavg ≥ H(X) follows from Gibbs' inequality applied with Qᵢ=2⁻ˡⁱ/Σ2⁻ˡʲ together with Kraft's inequality. The upper bound follows by choosing lᵢ = ⌈log₂(1/Pᵢ)⌉, which satisfies Kraft's inequality and gives log₂(1/Pᵢ) ≤ lᵢ < log₂(1/Pᵢ)+1; averaging over all symbols yields H(X) ≤ Lavg < H(X)+1. (Full step-by-step derivation is in the "Proof Sketch of Source Coding Theorem" section above.)

Efficiency & redundancy: η = H(X)/Lavg (closer to 1 = better compression); Redundancy = 1−η. The theorem essentially says entropy is the fundamental limit of lossless compression — you can never compress below it on average.

Q3. Differentiate between Mutual Information and Conditional Entropy. ★★★ 5 Marks

Mutual Information I(X;Y): the amount of information one variable contains about another — i.e. how much the uncertainty about X reduces after observing Y. It is always ≥0, symmetric (I(X;Y)=I(Y;X)), and equals 0 only when X and Y are statistically independent. Formula: I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X)+H(Y)−H(X,Y).

Conditional Entropy H(X|Y): the average uncertainty that remains about X even after Y is known — also called "equivocation," since it represents information lost due to channel noise. Formula: H(X|Y) = −ΣΣP(xᵢ,yⱼ)log₂P(xᵢ|yⱼ) = H(X,Y)−H(Y).

Key relation linking both: I(X;Y) = H(X) − H(X|Y). So mutual information is literally "what you gain," and conditional entropy is "what's still missing" — together they add up to H(X), the total original uncertainty.

Q4. What is a Discrete Memoryless Channel? Explain Binary Symmetric Channel (BSC) with diagram. ★★★★ 5-7 Marks

DMC: A Discrete Memoryless Channel is a channel model where the output at any instant depends only on the input at that same instant (no dependence on past inputs/outputs), and both input X and output Y take values from finite discrete alphabets. It is fully characterized by its transition probability matrix P(yⱼ|xᵢ), where each row sums to 1.

Binary Symmetric Channel (BSC): the simplest and most commonly examined DMC — 2 inputs {0,1}, 2 outputs {0,1}, and a single crossover (error) probability p that applies symmetrically in both directions (see Fig 2.2). Its channel matrix is [[1−p, p],[p, 1−p]] — each input is correctly received with probability (1−p) and flipped with probability p.

BSC is the standard model for a noisy binary transmission link and forms the basis for almost every channel-capacity numerical in this unit (see Q17, Q18).

Q5. Numerical: A source has 4 symbols with probabilities 0.5, 0.25, 0.125, 0.125. Find entropy. ★★★★★ Almost guaranteed numerical

Solution:
H(X) = −[0.5log₂0.5 + 0.25log₂0.25 + 0.125log₂0.125 + 0.125log₂0.125]
= −[0.5(−1) + 0.25(−2) + 0.125(−3) + 0.125(−3)]
= 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits/symbol

This exact style of numerical — probabilities that are clean negative powers of 2 (½, ¼, ⅛, ⅛) — is the single most-repeated RTU question pattern for entropy, because the log₂ values come out as whole numbers, making it fast to solve without a calculator. The same 4 probabilities are reused later for the Huffman coding numerical (Q22), where you'll see Lavg comes out exactly equal to this entropy value.

Q6. Explain differential entropy for continuous random variables. Derive it for Gaussian distribution. ★★★ 5 Marks

Definition: For a continuous random variable X with probability density function f(x), differential entropy is h(X) = −∫f(x)·log₂f(x)dx, over the entire support of X. It is the continuous-variable analogue of discrete entropy, with the sum replaced by an integral and the pmf replaced by a pdf.

Gaussian derivation: for X ~ N(μ,σ²), substituting the Gaussian pdf into the differential entropy integral and simplifying (using E[(X−μ)²]=σ²) gives h(X) = ½log₂(2πeσ²). This is a standard result worth memorizing directly.

Important distinction: unlike discrete entropy, h(X) can be negative (e.g. for a uniform distribution narrower than 1 unit — see Q23), because it is not a true "information" measure in absolute terms, only a relative one. The Gaussian distribution has the special property of having the maximum differential entropy among all continuous distributions with a fixed variance σ².

Q7. Derive the relation I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X). ★★★ 5 Marks

Derivation: Start from the two equivalent expansions of joint entropy: H(X,Y) = H(X) + H(Y|X) and H(X,Y) = H(Y) + H(X|Y). Also recall the definition I(X;Y) = H(X) + H(Y) − H(X,Y) (from the Venn-diagram relation in Fig 2.3).

Substituting H(X,Y) = H(X)+H(Y|X) into the mutual-information definition: I(X;Y) = H(X)+H(Y)−[H(X)+H(Y|X)] = H(Y)−H(Y|X).
Similarly substituting H(X,Y) = H(Y)+H(X|Y): I(X;Y) = H(X)+H(Y)−[H(Y)+H(X|Y)] = H(X)−H(X|Y).

Both forms are proven identical, confirming mutual information's symmetry. Draw the Venn diagram (Fig 2.3) as visual support — the overlapping region between the H(X) and H(Y) circles is exactly I(X;Y), and each circle minus the overlap gives the corresponding conditional entropy.

Q8. Explain coding efficiency and redundancy with a numerical example. ★★ 3-5 Marks

Definitions: Coding efficiency η = H(X)/Lavg measures how close an actual code's average length is to the theoretical entropy limit (η ≤ 1 always, by the Source Coding Theorem). Redundancy = 1−η measures the "wasted" bits per symbol beyond what's theoretically necessary.

Numerical: A source has H(X) = 1.75 bits/symbol and a code is designed with Lavg = 1.875 bits/symbol.
η = 1.75/1.875 = 0.933 = 93.3%
Redundancy = 1 − 0.933 = 0.067 (6.7%)

Higher efficiency (closer to 100%) means the code design is close to optimal — a perfectly-designed Huffman code on powers-of-2 probabilities can even reach η=100% (see Q22).

Q9. Why is the logarithmic function used to measure information? State the postulates. ★★★ 5 Marks

Shannon required any sensible information measure I(P) to satisfy four postulates simultaneously:

  1. Postulate 1: I(P) = 0 when P = 1 (a certain event carries zero information).
  2. Postulate 2: I(P) ≥ 0 for 0 ≤ P ≤ 1 (information is never negative).
  3. Postulate 3: I(P₁) > I(P₂) if P₁ < P₂ (monotonically decreasing — rarer events carry more information).
  4. Postulate 4 (Additivity): I(P₁·P₂) = I(P₁) + I(P₂) for independent events — the joint information of two independent events equals the sum of their individual information.

The only function satisfying all four conditions at once is the logarithmic function, I(x) = log(1/P(x)) — because log(a·b) = log(a)+log(b) is precisely what makes additivity work for independent events, while no other elementary function has this property alongside the other three postulates. This is why entropy and information are always defined using logarithms.

Q10. Prove that entropy is maximum when all symbols are equiprobable. ★★★★ 7 Marks — Lagrange multiplier proof

Setup: Maximize H(X) = −ΣPᵢlog₂Pᵢ subject to the constraint ΣPᵢ = 1, using Lagrange multipliers.

Derivation: Form L = −ΣPᵢlog₂Pᵢ + λ(ΣPᵢ − 1). Differentiating with respect to each Pᵢ and setting to zero: ∂L/∂Pᵢ = −log₂Pᵢ − log₂e + λ = 0, which gives the same value of Pᵢ for every i — i.e. Pᵢ = constant = 1/n for all i = 1...n.

Conclusion: Substituting Pᵢ=1/n back into H(X) gives Hmax(X) = log₂n. Hence entropy reaches its maximum value exactly when the probability distribution is uniform (equiprobable) — this is the point of maximum uncertainty, since no symbol is favored over another.

Q11. Define Joint Entropy and Marginal Entropy. State the relation between them. ★★ 3-5 Marks

Joint Entropy H(X,Y): the average uncertainty associated with a pair of random variables (X,Y) taken together, considering their joint probability distribution: H(X,Y) = −ΣᵢΣⱼP(xᵢ,yⱼ)log₂P(xᵢ,yⱼ).

Marginal Entropy: simply H(X) or H(Y) computed individually, using the marginal probability distributions obtained by summing the joint matrix along rows (P(xᵢ)=ΣⱼP(xᵢ,yⱼ)) or columns (P(yⱼ)=ΣᵢP(xᵢ,yⱼ)).

Relation: H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y) — the joint uncertainty of both variables equals the uncertainty of one plus the remaining (conditional) uncertainty of the other given the first is known.

Q12. What is rate of information transmission? Give its formula. ★★ 2-3 Marks

If a discrete source emits r symbols per second, and each symbol carries an average of H(X) bits of information, then the rate of information transmission R (in bits/second) is: R = r · H(X).

This simply scales the "per-symbol" entropy up to a "per-second" rate, using the source's symbol-emission speed r. It becomes important later when comparing a source's actual information rate against a channel's capacity C, to check whether reliable transmission (R ≤ C) is achievable.

Q13. List and explain the properties of differential entropy. How does it differ from discrete entropy? ★★★ 5 Marks

Properties of differential entropy h(X):

  1. h(X) can be negative, zero, or positive — unlike discrete entropy which is always ≥ 0.
  2. h(X+c) = h(X) for any constant c — shifting/translating the distribution does not change its differential entropy.
  3. h(aX) = h(X) + log₂|a| — scaling the variable by a changes h(X) by log₂|a|.
  4. Among all continuous distributions with a fixed variance σ², the Gaussian distribution has the maximum differential entropy.

Difference from discrete entropy: discrete entropy uses a pmf and summation and is always non-negative with units of bits/symbol; differential entropy uses a pdf and integration, can be negative, and its value depends on the units/scale of X (not an absolute measure of information in the same sense as discrete entropy).

Q14. Define instantaneous (prefix) code and state Kraft's inequality. ★★★ 5 Marks

Instantaneous (prefix) code: a variable-length code in which no codeword is a prefix of any other codeword. This property allows the receiver to decode symbol-by-symbol as bits arrive, without needing to look ahead or wait for a separator.

Kraft's Inequality: a prefix code with codeword lengths l₁, l₂, ..., lₙ exists if and only if Σᵢ2⁻ˡⁱ ≤ 1. This is both a necessary and sufficient condition — given any set of lengths satisfying this inequality, a valid instantaneous code can always be constructed (and conversely, any instantaneous code's lengths must satisfy it).

When Σᵢ2⁻ˡⁱ = 1 exactly, the code uses all available code-space with no waste, which corresponds to 100% coding efficiency (see the Huffman example in Q22, where 2⁻¹+2⁻²+2⁻³+2⁻³ = 1).

Q15. Prove Shannon's Source Coding Theorem: H(X) ≤ Lavg < H(X)+1. ★★★★★ 10 Marks — long derivation, very important

Part 1 — Lower bound (Lavg ≥ H(X)): By Gibbs' inequality, for any two probability distributions P and Q: −ΣPᵢlog₂Pᵢ ≤ −ΣPᵢlog₂Qᵢ. Choosing Qᵢ = 2⁻ˡⁱ/Σ2⁻ˡʲ and applying Kraft's inequality (Σ2⁻ˡⁱ≤1), algebraic simplification shows Lavg = ΣPᵢlᵢ ≥ H(X).

Part 2 — Upper bound (Lavg < H(X)+1): Choose codeword length lᵢ = ⌈log₂(1/Pᵢ)⌉ (the smallest integer ≥ log₂(1/Pᵢ)). This choice always satisfies Kraft's inequality (so a valid prefix code exists for these lengths), and by definition of the ceiling function: log₂(1/Pᵢ) ≤ lᵢ < log₂(1/Pᵢ)+1. Taking the expectation (weighted average) over all symbols gives H(X) ≤ Lavg < H(X)+1.

Conclusion: Combining both bounds proves the theorem — entropy is the achievable lower limit of average code length, and it can always be approached within 1 bit per symbol using simple symbol-by-symbol coding, and exactly achieved (in the limit) using block/extension coding as block length → ∞.

Q16. Explain the different types of discrete channels (lossless, deterministic, noiseless) with their channel matrices. ★★★ 5 Marks

Lossless Channel: no information about the input is lost, so H(X|Y)=0 (the input can always be perfectly reconstructed from the output). Its channel matrix has exactly one non-zero entry per column.

Deterministic Channel: each input maps to exactly one specific output with certainty, so H(Y|X)=0 (no randomness on the output side). Its channel matrix has exactly one non-zero entry (equal to 1) per row.

Noiseless Channel: satisfies both properties simultaneously — it is both lossless and deterministic, giving I(X;Y)=H(X)=H(Y). Its channel matrix is a square identity matrix (1s on the diagonal, 0s elsewhere) — the "ideal" channel with zero information loss in either direction.

The BSC (Q4) is a special symmetric case that is generally neither lossless nor deterministic (unless p=0 or p=1), which is why it's the standard example for studying real, noisy channels.

Q17. Define channel capacity. Derive the channel capacity of a Binary Symmetric Channel. ★★★★★ 7-10 Marks — very important, numerical + theory combined

Definition: Channel capacity C is the maximum possible rate of reliable information transmission over a channel, defined as the maximum of mutual information I(X;Y) over all possible input probability distributions P(x): C = maxP(x) I(X;Y), measured in bits/symbol (or bits/channel use).

Derivation for BSC: For a BSC with crossover probability p, mutual information I(X;Y) = H(Y)−H(Y|X). Since H(Y|X)=H(p) regardless of the input distribution (a fixed property of the channel), maximizing I(X;Y) means maximizing H(Y), which is largest (=1 bit) precisely when the output is equiprobable — which happens when the input is equiprobable, P(0)=P(1)=0.5. This gives:

CBSC = 1 − H(p), where H(p) = −p·log₂p − (1−p)·log₂(1−p).

As shown in Fig 2.4: C=1 bit/symbol at p=0 or p=1 (channel is perfectly reliable, either straight-through or fully inverted), and C=0 at p=0.5 (channel output carries zero information about the input — completely useless). Try the interactive BSC Capacity Explorer simulation above to see this relationship live.

Q18. Numerical: For a BSC with p=0.2, find the channel capacity. ★★★★ 5 Marks numerical

Solution:
H(0.2) = −0.2log₂0.2 − 0.8log₂0.8 = 0.2(2.322) + 0.8(0.322) = 0.464 + 0.257 = 0.722 bits
C = 1 − H(0.2) = 1 − 0.722 = 0.278 bits/symbol

This means that despite 20% of bits being flipped by the channel, up to 0.278 bits of reliable information can still theoretically be transmitted per channel use, using an appropriately designed error-correcting code (Shannon's Channel Coding Theorem guarantees this is achievable, though it doesn't specify the exact code to use).

Q19. Prove that mutual information I(X;Y) is always non-negative. ★★★ 5 Marks proof

Proof: Starting from I(X;Y) = ΣΣP(xᵢ,yⱼ)log₂[P(xᵢ,yⱼ)/(P(xᵢ)P(yⱼ))], consider −I(X;Y) and apply Jensen's inequality (log is a concave function), treating P(xᵢ)P(yⱼ) as an alternate distribution over the same support as P(xᵢ,yⱼ):

−I(X;Y) = ΣΣP(xᵢ,yⱼ)log₂[P(xᵢ)P(yⱼ)/P(xᵢ,yⱼ)] ≤ log₂[ΣΣP(xᵢ)P(yⱼ)] = log₂[1] = 0

Therefore I(X;Y) ≥ 0, with equality holding if and only if X and Y are statistically independent (i.e. P(xᵢ,yⱼ)=P(xᵢ)P(yⱼ) for all i,j, making the log term zero everywhere). This confirms that observing one variable can never give "negative" information about another — at worst it gives zero (no help at all).

Q20. Show that H(X|Y) ≤ H(X). What does this imply physically? ★★★ 5 Marks

Proof: Since I(X;Y) = H(X) − H(X|Y), rearranging gives H(X|Y) = H(X) − I(X;Y). Because I(X;Y) ≥ 0 was already proven (Q19), it directly follows that H(X|Y) ≤ H(X).

Physical meaning: observing the channel output Y can never, on average, increase your uncertainty about the input X. At worst (when X and Y are independent, i.e. Y tells you nothing about X), H(X|Y)=H(X) — no help, but also no harm. In every other case, knowing Y strictly reduces your uncertainty about X. This is sometimes summarized as "side information never hurts."

Q21. Numerical (10 Marks — most important pattern): Given a joint probability matrix P(X,Y), compute H(X), H(Y), H(X,Y), H(X|Y), H(Y|X) and I(X;Y). ★★★★★ Guaranteed-type question

Sample matrix: x₁ row: P(x₁,y₁)=0.25, P(x₁,y₂)=0.25 (row sum P(x₁)=0.50); x₂ row: P(x₂,y₁)=0.125, P(x₂,y₂)=0.375 (row sum P(x₂)=0.50); column sums P(y₁)=0.375, P(y₂)=0.625.

Step-by-step solution (always follow this exact order):

  1. H(X) = −(0.5log₂0.5+0.5log₂0.5) = 1 bit (from row/marginal sums)
  2. H(Y) = −(0.375log₂0.375+0.625log₂0.625) = 0.530+0.424 = 0.954 bits
  3. H(X,Y) = −[0.25log₂0.25+0.25log₂0.25+0.125log₂0.125+0.375log₂0.375] = 0.5+0.5+0.375+0.531 = 1.906 bits (compute this directly from all four joint entries first)
  4. H(X|Y) = H(X,Y) − H(Y) = 1.906 − 0.954 = 0.952 bits
  5. H(Y|X) = H(X,Y) − H(X) = 1.906 − 1 = 0.906 bits
  6. I(X;Y) = H(X) − H(X|Y) = 1 − 0.952 = 0.048 bits (cross-check: H(X)+H(Y)−H(X,Y) = 1+0.954−1.906 = 0.048 ✓)

💡 Exam tip: always compute H(X,Y) directly from the joint matrix first — every other quantity follows from it using the standard relations, which is the fastest, most error-free order to solve this type of numerical for any matrix given in the exam.

Q22. Construct a Huffman code for a source with 4 symbols of probabilities 0.5, 0.25, 0.125, 0.125. Find Lavg and efficiency. ★★★★ 7 Marks — construction-based

Tree construction: Combine the two lowest-probability symbols repeatedly: Step 1 — combine x₃(0.125) & x₄(0.125) → node A(0.25). Step 2 — combine A(0.25) & x₂(0.25) → node B(0.5). Step 3 — combine B(0.5) & x₁(0.5) → root(1.0).

Resulting codewords: x₁="0" (length 1), x₂="10" (length 2), x₃="110" (length 3), x₄="111" (length 3).

Lavg = ΣPᵢlᵢ = 0.5(1)+0.25(2)+0.125(3)+0.125(3) = 0.5+0.5+0.375+0.375 = 1.75 bits/symbol, which equals H(X) exactly — so efficiency η = 100%. This happens because every probability here is an exact negative power of 2 (0.5=2⁻¹, 0.25=2⁻², 0.125=2⁻³), which is the ideal case for Huffman coding.

Verify: prefix property holds ({0,10,110,111} — no codeword is a prefix of another), and Kraft's inequality gives 2⁻¹+2⁻²+2⁻³+2⁻³ = 1 ≤ 1 (equality ⟹ no wasted code-space).

Q23. Find the differential entropy of a random variable uniformly distributed over [0, 8]. ★★★ 5 Marks numerical

Solution: For a uniform distribution over [a,b], f(x)=1/(b−a), so h(X) = −∫ab(1/(b−a))·log₂(1/(b−a))dx = log₂(b−a). Here (b−a)=8, so h(X) = log₂8 = 3 bits.

General shortcut: for uniform X on [a,b], h(X) = log₂(b−a) directly — no need to redo the integral each time. Note that if (b−a) < 1, h(X) becomes negative, which is a perfectly valid result for differential entropy (unlike discrete entropy, which is never negative — see Q13).

Q24. Numerical: Given P(x₁)=0.6, P(x₂)=0.4 and channel matrix [[0.9,0.1],[0.2,0.8]], find P(Y), H(Y), H(Y|X) and I(X;Y). ★★★★★ 10 Marks — asymmetric/non-BSC channel pattern

Step 1 — Output probabilities using P(yⱼ)=ΣᵢP(xᵢ)P(yⱼ|xᵢ), or equivalently [P(X)]×[Channel Matrix]:
P(y₁) = 0.6(0.9)+0.4(0.2) = 0.54+0.08 = 0.62
P(y₂) = 0.6(0.1)+0.4(0.8) = 0.06+0.32 = 0.38 (check: 0.62+0.38=1 ✓)

Step 2 — H(Y) = −[0.62log₂0.62+0.38log₂0.38] = 0.428+0.530 = 0.958 bits

Step 3 — H(Y|X), the weighted average of each row's entropy:
H(Y|x₁) = −[0.9log₂0.9+0.1log₂0.1] = 0.137+0.332 = 0.469 bits
H(Y|x₂) = −[0.2log₂0.2+0.8log₂0.8] = 0.464+0.257 = 0.722 bits
H(Y|X) = 0.6(0.469)+0.4(0.722) = 0.281+0.289 = 0.570 bits

Step 4 — I(X;Y) = H(Y) − H(Y|X) = 0.958 − 0.570 = 0.388 bits

💡 Exam shortcut: H(Y|X) is always a probability-weighted average of the row entropies of the channel matrix — this works for any DMC, symmetric or not, so it's more general than memorizing the BSC-only H(p) shortcut.
