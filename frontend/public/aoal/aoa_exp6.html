Experiment 6: Strassen's Matrix Multiplication

Aim: Compute two 2 by 2 matrix multiplication to find multiplication matrix using Strassen's Matrix Multiplication.

Source code

This is the program from the lab manual, unchanged. Compile it with gcc aoa_exp6.c -o exp6 and run ./exp6 (on Windows with MinGW, exp6).

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int main()
{
    int A[2][2], B[2][2], C[2][2];
    int M1, M2, M3, M4, M5, M6, M7;
    int i, j;
    clock_t start, end;
    double cpu_time_used;
    printf("Enter elements of 2x2 Matrix A:\n");
    for(i = 0; i < 2; i++)
    for(j = 0; j < 2; j++)
    scanf("%d", &A[i][j]);
    printf("Enter elements of 2x2 Matrix B:\n");
    for(i = 0; i < 2; i++)
    for(j = 0; j < 2; j++)
    scanf("%d", &B[i][j]);
    // Start timing
    start = clock();
    // Strassen's 7 multiplications
    M1 = (A[0][0] + A[1][1]) * (B[0][0] + B[1][1]);
    M2 = (A[1][0] + A[1][1]) * B[0][0];
    M3 = A[0][0] * (B[0][1] - B[1][1]);
    M4 = A[1][1] * (B[1][0] - B[0][0]);
    M5 = (A[0][0] + A[0][1]) * B[1][1];
    M6 = (A[1][0] - A[0][0]) * (B[0][0] + B[0][1]);
    M7 = (A[0][1] - A[1][1]) * (B[1][0] + B[1][1]);
    // Result matrix using M1..M7
    C[0][0] = M1 + M4 - M5 + M7;
    C[0][1] = M3 + M5;
    C[1][0] = M2 + M4;
    C[1][1] = M1 - M2 + M3 + M6;
    // End timing
    end = clock();
    cpu_time_used = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("\nMatrix A:\n");
    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        printf("%d ", A[i][j]);
        printf("\n");
    }
    printf("\nMatrix B:\n");
    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        printf("%d ", B[i][j]);
        printf("\n");
    }
    printf("\nResultant Matrix C (A x B) using Strassen's Method:\n");
    for(i = 0; i < 2; i++)
    {
        for(j = 0; j < 2; j++)
        printf("%d ", C[i][j]);
        printf("\n");
    }
    printf("\nTime Required = %f seconds\n", cpu_time_used);
    return 0;
}

Explanation (from the manual)

Concept

Given two 2×2 matrices A and B, the goal is to compute A×B. The conventional ("school") method needs 8 multiplications (2 multiplications per output cell, across 4 cells). Strassen devised a clever technique that needs only 7 multiplications — one fewer. For a tiny 2×2 case the saving is not noticeable, but for very large matrices (e.g. 1000×1000, applied recursively as used in AI/ML systems), this technique meaningfully reduces computation time.

The trick: combine elements of A and B into 7 "helper values" (M1 through M7), then obtain every cell of the result purely through addition/subtraction of these helper values — instead of multiplying separately for every output cell.

Worked Example

  A = [[1, 2], [3, 4]],  B = [[5, 6], [7, 8]]
  M1 = (A00+A11)×(B00+B11) = (1+4)×(5+8) = 5×13 = 65
  M2 = (A10+A11)×B00 = (3+4)×5 = 35
  M3 = A00×(B01−B11) = 1×(6−8) = −2
  M4 = A11×(B10−B00) = 4×(7−5) = 8
  M5 = (A00+A01)×B11 = (1+2)×8 = 24
  M6 = (A10−A00)×(B00+B01) = 2×11 = 22
  M7 = (A01−A11)×(B10+B11) = −2×15 = −30

  C00 = M1+M4−M5+M7 = 65+8−24−30 = 19
  C01 = M3+M5 = −2+24 = 22
  C10 = M2+M4 = 35+8 = 43
  C11 = M1−M2+M3+M6 = 65−35−2+22 = 50

  Result:  C  =  [[19,  22],  [43,  50]]  —  exactly  the  same  as  conventional  multiplication
  (1×5+2×7=19, and so on), just computed with one fewer multiplication.

Time Complexity

Conventional matrix multiplication takes O(n³) for large matrices. Strassen's method improves this to roughly O(n2.807). This difference is invisible on a tiny 2×2 matrix, but on very large matrices it saves real computation time.

What the Program Does

  1. The user enters all elements of matrices A and B (2×2 each, 4 numbers per matrix).
  2. The program computes the seven M-values described above.
  3. The final result matrix C is built from those values.
  4. A, B, and the result C are all printed.
  5. The time taken (in seconds) is displayed.

In short: compute 7 clever helper values (M1–M7), then combine them directly to get the result, without multiplying separately for each output cell.

Viva questions

What is Strassen’s Matrix Multiplication?

A divide-and-conquer method that multiplies two matrices using 7 multiplications instead of 8 for a 2 × 2 block.

What is its time complexity?

About O(n^2.807) (n to the power log₂7), better than O(n³) of the ordinary method.

Write the recurrence of Strassen’s algorithm.

T(n) = 7T(n/2) + O(n²).

What are the seven values M1 to M7?

M1 = (A00+A11)(B00+B11), M2 = (A10+A11)B00, M3 = A00(B01−B11), M4 = A11(B10−B00), M5 = (A00+A01)B11, M6 = (A10−A00)(B00+B01), M7 = (A01−A11)(B10+B11).

How is the result built from M1 to M7?

C00 = M1+M4−M5+M7, C01 = M3+M5, C10 = M2+M4, C11 = M1−M2+M3+M6.

Why is Strassen’s method not used for small matrices?

It does more additions and has extra overhead, so it only pays off for large matrices.

What if the matrix size is not a power of 2?

The matrices are padded with zeros up to the next power of 2.

Which design technique does it use?

Divide and conquer.
