Compiler Design Lab, 5CS4-22 (Turbo C++)

Experiment 3: Count total keywords in a file

Aim: Write a C program to count the total number of keywords in a file [taking file from user].

Source code

#include<stdio.h>
#include<conio.h>
#include<string.h>
#include<ctype.h>
#include<stdlib.h>

void main()
{
    char keyword[32][10] = {"auto","double","int","struct","break","else","long",
                            "switch","case","enum","register","typedef","char",
                            "extern","return","union","const","float","short",
                            "unsigned","continue","for","signed","void","default",
                            "goto","sizeof","volatile","do","if","static","while"};
    char fname[30], word[20];
    int c, i, j = 0, count = 0;
    FILE *fp;

    clrscr();
    printf("Enter file name: ");
    gets(fname);

    fp = fopen(fname, "r");
    if(fp == NULL)
    {
        printf("File not found");
        getch();
        exit(0);
    }

    while(1)
    {
        c = fgetc(fp);

        if(isalpha(c))
        {
            word[j++] = c;
        }
        else
        {
            if(j > 0)
            {
                word[j] = '\0';
                for(i = 0; i < 32; i++)
                {
                    if(strcmp(word, keyword[i]) == 0)
                    {
                        count++;
                        break;
                    }
                }
                j = 0;
            }
            if(c == EOF)
                break;
        }
    }

    fclose(fp);
    printf("Total keywords in file = %d", count);
    getch();
}

Before you run

Create test.txt in the same folder as your program (the folder shown in Turbo C++'s File > Open dialog) with this content:

int a; float b;
if(a>b) return 0;

Output

Enter file name: test.txt
Total keywords in file = 4

Explanation

  1. fopen(fname, "r") opens the file for reading. It returns NULL if the file does not exist, and the program then exits.
  2. fgetc(fp) reads one character at a time and returns EOF at the end of the file.
  3. While the characters are letters (isalpha), they are stored in word[]. Any other character (space, ;, (, newline) ends the word.
  4. When a word ends, '\0' is added and the word is compared with all 32 keywords using strcmp. A match increases count and break stops the search.
  5. j = 0 starts the next word. At EOF the loop stops and the total is printed.

Viva questions

Why is c declared as int and not char?

EOF is -1, which does not fit reliably in a char. fgetc returns an int, so the variable must be an int.

What does fopen return on failure?

NULL. Always check for it before reading.

What do the modes "r", "w" and "a" mean?

Read, write (overwrites the file) and append (adds at the end).

Why is break used inside the keyword loop?

Once a keyword matches there is no need to check the rest of the table.

What does isalpha do?

It returns true if the character is a letter (A to Z or a to z).

What is the time cost per word here?

Linear search, at most 32 comparisons per word. The manual uses a sorted table with binary search, about 5 comparisons.

How does binary search work?

On a sorted table, compare with the middle entry. If the word is smaller, search the left half, otherwise the right half, and repeat until found or the range is empty.

What is a limitation of this program?

A name like int2 is read as int and counted, because digits end the word. A real lexer treats int2 as one identifier.

Which compiler phase is this?

Lexical analysis: splitting text into words and classifying them.
