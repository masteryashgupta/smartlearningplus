Compiler Design Lab, 5CS4-22 (Turbo C++)

Experiment 4: Count total operators in a string

Aim: Write a program to count the total number of operators (+, -, *, /) in the input.

Source code: Version 1: reads a string from the keyboard

#include<stdio.h>
#include<conio.h>

void main()
{
    int count = 0, i;
    char string[100];

    clrscr();
    printf("Enter your string :");
    gets(string);

    for(i = 0; string[i] != '\0'; i++)
    {
        if(string[i]=='+' || string[i]=='-' || string[i]=='*' || string[i]=='/')
        {
            count++;
        }
    }

    printf("Total Number of operators is : %d ", count);
    getch();
}

The manual's aim says "file", but its code reads a string. Version 1 reads a string, like the manual's code. A file version (Version 2) is also given.

Output

Enter your string :a+b*c-d/e
Total Number of operators is : 4

Source code: Version 2 (reads from a file)

This matches the manual's aim ("taking file from user"). Create test.txt in the same folder with two lines: a = b + c * d; and x = y - z / 2;. The file is opened with fopen and read one character at a time with fgetc until EOF. The same operator check is used, and the = signs are not counted.

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>

void main()
{
    char fname[30];
    int c, count = 0;
    FILE *fp;

    clrscr();
    printf("Enter file name: ");
    gets(fname);

    fp = fopen(fname, "r");
    if(fp == NULL)
    {
        printf("File not found");
        getch();
        exit(0);
    }

    while((c = fgetc(fp)) != EOF)
    {
        if(c == '+' || c == '-' || c == '*' || c == '/')
            count++;
    }

    fclose(fp);
    printf("Number of operators in the file = %d", count);
    getch();
}

Output

Enter file name: test.txt
Number of operators in the file = 4

Explanation

  1. gets(string) reads the whole line, including spaces. scanf("%s") would stop at the first space and miss operators after it.
  2. The for loop visits each character until the string terminator '\0'.
  3. The condition uses || (or), so a match with any one of the four operators counts.
  4. count++ adds one for each operator found. The total is printed at the end.

Viva questions

What is an operator?

A symbol that performs an operation on operands, such as + or *.

What is the difference between = and ==?

= assigns a value. == compares two values.

What does || mean?

Logical OR: the condition is true if at least one side is true.

Why use gets and not scanf("%s")?

scanf("%s") stops reading at the first space, so the rest of the line is lost.

How is the end of a string marked?

By the null character '\0'.

How would you read from a file instead?

Open it with fopen, read with fgetc until EOF, and run the same if check on each character.

What are the limitations?

++ counts as two operators, a - in a negative number is counted, and operators like == or && are not recognised. A real lexer treats them as single tokens.

Which compiler phase does this relate to?

Lexical analysis: operators are one kind of token.
