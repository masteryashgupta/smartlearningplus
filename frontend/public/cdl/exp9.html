Compiler Design Lab, 5CS4-22

Experiment 9: LEX program to count vowels and consonants in a C file

Aim: Write a LEX program to count the number of vowels and consonants in a C file.

The manual's main prints vow and cons, but its variables are named vow_count and const_count, so it does not compile. This version is fixed and reads a file.

Run on Windows (Flex)

One-time setup

  1. Download WinFlexBison from GitHub: https://github.com/lexxmark/winflexbison/releases. Download the asset named win_flex_bison-2.5.25.zip (Flex 2.6.4). Do not download the "Source code" files.
  2. Extract the zip into C:\flex. It contains win_flex.exe and win_bison.exe.
  3. A C compiler is needed. Check with: gcc --version. If it is not recognised, install MinGW-w64 (for example through MSYS2).
  4. Save the downloaded .l files and any input files (test.txt, test.c) in C:\flex. Open Command Prompt in that folder (click the File Explorer address bar, type cmd, press Enter).

What each command does

StepCommandPurpose
Step 1win_flex --wincompat FILE.lFlex reads the rules and writes the C scanner lex.yy.c
Step 2gcc -w lex.yy.c -o NAMEgcc compiles lex.yy.c into NAME.exe (-w hides harmless warnings)
Step 3NAMEruns the program

Notes

  • Press Ctrl+Z, then Enter to end keyboard input.
  • Each run overwrites lex.yy.c, so run one program at a time.
  • The warning "fileno redefined" is harmless.
  • The input file for file versions must be in the same folder as the .exe.

Source code: Version 1: reads from a file

%{
#include<stdio.h>
int vow = 0, cons = 0;
%}

%%
[aeiouAEIOU]    { vow++; }
[a-zA-Z]        { cons++; }
.|\n            ;
%%

int yywrap() { return 1; }

int main()
{
    char fname[30];
    printf("Enter file name: ");
    scanf("%s", fname);
    yyin = fopen(fname, "r");
    if(yyin == NULL)
    {
        printf("File not found\n");
        return 1;
    }
    yylex();
    fclose(yyin);
    printf("No. of vowels     = %d\n", vow);
    printf("No. of consonants = %d\n", cons);
    return 0;
}

Output

Enter file name: test.c
No. of vowels     = 3
No. of consonants = 4

Source code: Version 2 (reads text typed at the keyboard)

Compile it the same way as above. There is no yyin or fopen, so LEX reads from the keyboard. Type your text, then press Ctrl+Z, then Enter to end the input and see the counts.

%{
#include<stdio.h>
int vow = 0, cons = 0;
%}

%%
[aeiouAEIOU]    { vow++; }
[a-zA-Z]        { cons++; }
.|\n            ;
%%

int yywrap() { return 1; }

int main()
{
    printf("Enter text (press Ctrl+Z, then Enter on a new line to finish):\n");
    yylex();
    printf("No. of vowels     = %d\n", vow);
    printf("No. of consonants = %d\n", cons);
    return 0;
}

Output

Enter text (press Ctrl+Z, then Enter on a new line to finish):
int main()
(press Ctrl+Z, then Enter)
No. of vowels     = 3
No. of consonants = 4

Explanation

  1. The program reads the file given by the user through yyin.
  2. [aeiouAEIOU] matches one vowel, so vow++ counts it.
  3. [a-zA-Z] matches any letter. A vowel matches both rules with the same length, and the earlier rule wins, so vowels never reach this rule. Only consonants are counted here.
  4. .|\n matches any other character (digits, symbols, spaces, newlines) and throws it away.
  5. After yylex() finishes, main prints the two counts. In int main() the vowels are i, a, i and the consonants are n, t, m, n.

Viva questions

What is a vowel and a consonant for the program?

Vowels are a, e, i, o, u in either case. Consonants are all other letters.

Why are vowels not counted as consonants?

Both rules match a vowel with the same length, and LEX uses the first rule listed.

What does .|\n match?

Any character: . is any character except newline, and \n adds the newline.

Why do we need a catch-all rule?

Without it, LEX copies unmatched input to the output (default action), which would clutter the result.

What does [a-zA-Z] mean?

Any one letter from a to z or A to Z.

Does this program skip comments and keywords?

No. Letters inside comments, strings and keywords are counted too. A real scanner would handle them as separate tokens.

What is yywrap()?

A function called at the end of the input. Returning 1 means stop.

Where are the counters declared?

In the definition section inside %{ %}, so they are global and available in the rules and in main.

What does the win_flex (lex) command do?

It reads the .l file and generates the C file lex.yy.c that contains the scanner function yylex().

What is lex.yy.c?

The C program generated by Flex from our rules. gcc compiles it into the executable.

Why is --wincompat used?

It makes the generated code compatible with Windows (it avoids the Unix-only unistd.h header).

Why do we press Ctrl+Z to end input on Windows?

Ctrl+Z sends the end-of-file signal in the Windows console. LEX stops reading when it sees end of file.
