Experiment 10: JSP grade calculator

Accept the marks of five subjects and display the student’s grade.

Before you start

  • Tomcat 9 must be extracted (for example C:\apache-tomcat-9.0.123). JSP files need no compiling: put them in a folder under webapps.
  • If Tomcat is already running from an earlier experiment, you do not need to start it again. It picks up new folders by itself.

Set the paths

Change both paths to match the lab PC. Find the JDK with where javac. Use the path that ends in \bin\javac.exe, without that ending, and ignore the Common Files\Oracle\Java\javapath line.

Command Prompt
set JAVA_HOME=C:\Program Files\Java\jdk-26
set TOMCAT=C:\apache-tomcat-9.0.123

Step 1: Create the app folder and files

Click Yes when Notepad asks to create each file. Check that neither file is saved as .txt.

Command Prompt
mkdir %TOMCAT%\webapps\Marks
notepad %TOMCAT%\webapps\Marks\marks.html
Command Prompt
notepad %TOMCAT%\webapps\Marks\marks.jsp

Step 2: Code

marks.html
<!DOCTYPE html>
<html>
<head>
<title>Student marks</title>
</head>
<body>
<center>
<h1>Student marks</h1>
<form action="marks.jsp" method="get">
    Enter Marks in Java : <input type="text" name="java"><br><br>
    Enter NMA Marks : <input type="text" name="NMA"><br><br>
    Enter MCAD Marks : <input type="text" name="MCAD"><br><br>
    Enter PPUD Marks : <input type="text" name="PPUD"><br><br>
    Enter Project Marks : <input type="text" name="pro"><br><br>
    <input type="submit" value="Get grade">
</form>
</center>
</body>
</html>
marks.jsp
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
<title>Grade</title>
</head>
<body>
<%
int java = Integer.parseInt(request.getParameter("java"));
int NMA = Integer.parseInt(request.getParameter("NMA"));
int MCAD = Integer.parseInt(request.getParameter("MCAD"));
int PPUD = Integer.parseInt(request.getParameter("PPUD"));
int Project = Integer.parseInt(request.getParameter("pro"));

int total = java + NMA + MCAD + PPUD + Project;
double avg = total / 5.0;

out.println("Total = " + total + "<br>");
out.println("Average = " + avg + "<br>");

if (avg >= 90) {
    out.println("Your grade is A");
} else if (avg >= 80) {
    out.println("Your grade is B");
} else if (avg >= 70) {
    out.println("Your grade is C");
} else if (avg >= 60) {
    out.println("Your grade is D");
} else {
    out.println("Your grade is E");
}
%>
</body>
</html>

Two small fixes from the manual: the average uses total / 5.0 (not total / 5, which drops the decimals), and A starts at 90 and above.

Start Tomcat

Skip this if Tomcat is already running. A new window opens; leave it open.

Command Prompt
%TOMCAT%\bin\startup.bat

Open the browser

Command Prompt
http://localhost:8080/Marks/marks.html

Enter five marks and click Get grade. Marks must be whole numbers, or parseInt throws an error.

Total = 410
Average = 82.0
Your grade is B

When you finish

Stop Tomcat from the same Command Prompt.

Command Prompt
%TOMCAT%\bin\shutdown.bat

Common errors

  • NumberFormatException: a field was empty or not a whole number.
  • 404: wrong folder name in the URL, or a file saved as .txt.
  • Grade looks wrong: check the field names in the form match getParameter() exactly (java, NMA, MCAD, PPUD, pro).

How it works

  • The form uses method="get", so the marks appear in the URL after the question mark.
  • request.getParameter() returns a String, so Integer.parseInt() converts it to a number.
  • The JSP adds the five marks, finds the average and picks the grade with an if-else ladder.
  • out.println() writes the result to the page.

Viva answers

  • Session object: HttpSession keeps a user’s data across requests, for example a login. Exception object: the Throwable available only in error pages (isErrorPage="true").
  • ServletContext vs PageContext: ServletContext (application) is shared by the whole web app. PageContext belongs to one page and gives access to all scopes.
  • JSTL: JSP Standard Tag Library, ready-made tags such as c:if and c:forEach so you avoid Java code in JSP.
  • Disable the session: <%@ page session="false" %>
  • Action tags: jsp:include, jsp:forward, jsp:param, jsp:useBean, jsp:setProperty, jsp:getProperty, jsp:plugin.
  • Three bean tags: jsp:useBean, jsp:setProperty, jsp:getProperty.
