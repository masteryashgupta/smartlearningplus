Compiler Design Lab, 5CS4-22 (YACC with LEX, runs on Linux)

Experiment 12: YACC program to check strings of the form a^n b^n c^m d^m

Aim: Write a YACC program to check the validity of strings such as abcd and aabbcd using the grammar a^n b^n c^m d^m, where n, m > 0.

The manual is inconsistent here. The syllabus asks for a^n b^n c^m d^m (n, m > 0), but its experiment page shows a^n b^n (n ≥ 0), which is the same as Exp 10. This page follows the syllabus. If your teacher wants the a^n b^n version, use the Exp 10 files.

How to compile and run

YACC and LEX do not run in Turbo C++. Use Linux or WSL. Install once: sudo apt install flex bison gcc. Save the two files below in the same folder (exp12.l and exp12.y), then run the commands in this order. YACC must run first because the LEX file includes y.tab.h.

yacc -d exp12.y
lex exp12.l
cc y.tab.c lex.yy.c
./a.out

Type a string and press Enter. The program prints the result and stops.

Source code

Lexer: exp12.l

%{
#include "y.tab.h"
%}

%%
[aA]    { return A; }
[bB]    { return B; }
[cC]    { return C; }
[dD]    { return D; }
\n      { return NL; }
.       { return yytext[0]; }
%%

int yywrap() { return 1; }

Parser: exp12.y

%{
#include<stdio.h>
#include<stdlib.h>
int yylex();
int yyerror(char *msg);
%}

%token A B C D NL

%%
stmt : X Y NL    { printf("valid string\n"); exit(0); }
     ;

X    : A X B
     | A B
     ;

Y    : C Y D
     | C D
     ;
%%

int yyerror(char *msg)
{
    printf("invalid string\n");
    exit(0);
}

int main()
{
    printf("enter the string\n");
    yyparse();
    return 0;
}

Output

enter the string
abcd
valid string

enter the string
aabbcd
valid string

enter the string
aabcd
invalid string

enter the string
ab
invalid string

Explanation

  1. The language has two independent halves. The first half, a^n b^n, is described by X : A X B | A B. The second half, c^m d^m, is described by Y : C Y D | C D.
  2. Because the base cases are A B and C D (not empty), n and m must be at least 1, as the syllabus requires.
  3. The start rule stmt : X Y NL needs an X part, then a Y part, then Enter. So abcd and aabbcd are valid, while aabcd (2 a's, 1 b) and ab (no c and d) are not.
  4. The LEX file returns a token for each of the letters a, b, c and d and for Enter, and passes anything else on to cause a syntax error.

Viva questions

What is the difference between this and Exp 10?

Exp 10 checks one pair of matching groups (a^n b^n). This checks two independent pairs (a^n b^n followed by c^m d^m) with n, m at least 1.

Why do we use two non-terminals X and Y?

The a-b count and the c-d count are independent, so each gets its own rule.

Why is the string aabcd invalid?

It has 2 a's but 1 b, so the first half does not match a^n b^n.

How is n > 0 enforced?

The base rules X : A B and Y : C D require at least one pair.

Is a^n b^n c^n a context-free language?

No. Matching three groups needs a context-sensitive grammar. Here the groups are matched in pairs, which a stack can do.

What is YACC?

Yet Another Compiler Compiler: a tool that generates a parser in C from a context-free grammar.

What is the structure of a YACC program?

Declarations (%{ %}, %token), grammar rules between %% markers, and user C code.

How do LEX and YACC work together?

LEX reads characters and returns tokens. YACC calls yylex() to get tokens and checks that they follow the grammar.

What is y.tab.h?

A header file made by yacc -d that holds the token numbers (like A, B), so LEX and YACC agree on them.

What does yyparse() do?

It starts parsing. It returns 0 if the input is accepted and non-zero if there is a syntax error.
