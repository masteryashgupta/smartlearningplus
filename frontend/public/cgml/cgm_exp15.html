Experiment 15: Bezier curve

Aim: To draw a Bezier curve.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

void main()
{
    int gd = DETECT, gm, err;
    int x[4], y[4], i, k;
    double t, u, a, b, c, d, bx, by;

    clrscr();
    printf("Enter the 4 control points (x y), one per line:\n");
    for(i = 0; i < 4; i++)
        scanf("%d%d", &x[i], &y[i]);

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    /* control polygon and control points */
    setcolor(DARKGRAY);
    for(i = 0; i < 3; i++)
        line(x[i], y[i], x[i + 1], y[i + 1]);
    setcolor(LIGHTGREEN);
    for(i = 0; i < 4; i++)
        circle(x[i], y[i], 4);

    /* the cubic Bezier curve */
    for(k = 0; k <= 1000; k++)
    {
        t = k / 1000.0;
        u = 1 - t;
        a = u * u * u;
        b = 3 * t * u * u;
        c = 3 * t * t * u;
        d = t * t * t;
        bx = a * x[0] + b * x[1] + c * x[2] + d * x[3];
        by = a * y[0] + b * y[1] + c * y[2] + d * y[3];
        putpixel((int)(bx + 0.5), (int)(by + 0.5), YELLOW);
    }

    outtextxy(10, 10, "Bezier curve (yellow), control points (green)");

    getch();
    closegraph();
}

The manual’s version uses double values and adds 0.001 to t in a loop. This version uses an integer counter, draws the control polygon and points too, and checks for graphics errors.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

Explanation

  1. Idea: A Bezier curve is shaped by control points. This program uses 4 points, P0, P1, P2 and P3, which gives a cubic curve. It starts at P0, ends at P3, and is pulled towards P1 and P2 without usually touching them.
  2. Formula: for t from 0 to 1, B(t) = (1-t)³P0 + 3t(1-t)²P1 + 3t²(1-t)P2 + t³P3. The four weights are the Bernstein polynomials, and they always add up to 1.
  3. In the code u = 1 - t, and a, b, c, d are the four weights. bx and by are the weighted sums of the x and y coordinates.
  4. The loop runs k from 0 to 1000 and sets t = k / 1000.0. Using an integer counter avoids the rounding error of adding 0.001 to a decimal value 1000 times. 1001 points are close enough together to look like a continuous curve.
  5. putpixel plots each point, rounded to the nearest pixel. The control polygon (grey lines) and control points (green circles) are drawn first so you can see how they shape the curve.
  6. Example: for the points (100,400), (150,100), (450,100), (500,400), at t = 0.5 the point is (P0 + 3P1 + 3P2 + P3) / 8 = (300, 175), which lies on the curve.

Viva questions

What is a Bezier curve?

A smooth curve defined by a set of control points, using a parameter t from 0 to 1. It is widely used in drawing programs, fonts and animation.

What are the types of Bezier curve?

By the number of control points: linear (2 points, a straight line), quadratic (3 points), cubic (4 points) and higher-order curves. A curve with n + 1 control points has degree n.

List the properties of a Bezier curve.

It passes through the first and last control points. The tangent at the ends points along the first and last segment of the control polygon. It always lies inside the convex hull of its control points. It is smooth and its shape changes smoothly when a control point is moved. The weights sum to 1.

What is a cubic Bezier curve?

A curve with 4 control points, with the formula B(t) = (1-t)³P0 + 3t(1-t)²P1 + 3t²(1-t)P2 + t³P3.

What is a quadratic Bezier curve?

A curve with 3 control points: B(t) = (1-t)²P0 + 2t(1-t)P1 + t²P2.

How can a closed Bezier curve be generated?

By making the last control point equal to the first one, so the curve ends where it started.

What are control points?

The points that define the shape of the curve. The curve does not have to pass through all of them, but it is pulled towards them.

What is a parametric curve?

A curve in which x and y are each given by a function of a parameter, here t, instead of by an equation connecting x and y.

What is a curve?

A continuous line that is not straight everywhere. In graphics it is drawn as many small points or very short line segments.

What are the types of curves?

Parametric curves (Bezier, B-spline, Hermite), implicit curves (such as the circle x² + y² = r²) and explicit curves (y = f(x)).

Why is it called a cubic curve?

Because the highest power of t in the formula is 3.
