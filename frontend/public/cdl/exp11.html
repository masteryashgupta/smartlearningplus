Experiment 11: YACC program to evaluate an arithmetic expression

Aim: Write a YACC program to evaluate an arithmetic expression involving the operators +, -, * and /.

The manual's code for this experiment has formatting errors (% left, broken %% markers) and uses one non-terminal T for everything. This version is cleaned up and adds unary minus and a division-by-zero check.

How to compile and run

YACC and LEX do not run in Turbo C++. Use Linux or WSL. Install once: sudo apt install flex bison gcc. Save the two files below in the same folder (exp11.l and exp11.y), then run the commands in this order. YACC must run first because the LEX file includes y.tab.h.

yacc -d exp11.y
lex exp11.l
cc y.tab.c lex.yy.c
./a.out

Type a string and press Enter. The program prints the result and stops.

Source code

Lexer: exp11.l

%{
#include "y.tab.h"
#include<stdlib.h>
%}

%%
[0-9]+    { yylval = atoi(yytext); return NUMBER; }
[ \t]     ;
\n        { return 0; }
.         { return yytext[0]; }
%%

int yywrap() { return 1; }

Parser: exp11.y

%{
#include<stdio.h>
#include<stdlib.h>
int yylex();
int yyerror(char *s);
%}

%token NUMBER
%left '+' '-'
%left '*' '/'
%right UMINUS

%%
S : E    { printf("Result = %d\n", $1); }
  ;

E : E '+' E             { $$ = $1 + $3; }
  | E '-' E             { $$ = $1 - $3; }
  | E '*' E             { $$ = $1 * $3; }
  | E '/' E             {
                            if($3 == 0)
                            {
                                printf("Division by zero\n");
                                exit(1);
                            }
                            $$ = $1 / $3;
                        }
  | '-' E %prec UMINUS  { $$ = -$2; }
  | '(' E ')'           { $$ = $2; }
  | NUMBER              { $$ = $1; }
  ;
%%

int yyerror(char *s)
{
    printf("Expression is invalid\n");
    return 0;
}

int main()
{
    printf("Enter the expression\n");
    yyparse();
    return 0;
}

Output

Result = 7

Enter the expression

Enter the expression

Result = 14

Enter the expression
2+*3
Expression is invalid

Explanation

  1. The LEX file turns a run of digits into a NUMBER token and stores its value in yylval (using atoi). Spaces are skipped, Enter returns 0 (end of input), and every other character, like + or (, is returned as itself.
  2. The grammar says an expression E is E + E, E - E, E * E, E / E, a negated expression, an expression in brackets, or a number.
  3. Each rule has an action. $1, $2, $3 are the values of the parts on the right, and $$ is the value of the whole rule. So $$ = $1 + $3 adds the left and right values.
  4. A grammar like E : E + E | E * E is ambiguous. The lines %left '+' '-' and %left '*' '/' fix this. Later lines have higher precedence, so * and / bind tighter than + and -, and %left makes operators of the same level group from the left.
  5. %right UMINUS with %prec UMINUS gives unary minus the highest precedence, so -5+2 means (-5)+2.
  6. The rule S : E prints the final value. Division by zero is checked before dividing.

Viva questions

What do $$, $1 and $3 mean?

$$ is the value of the left side of the rule. $1, $2, $3 are the values of the first, second and third symbols on the right.

What is yylval?

A variable used to pass the value of a token (like the number 25) from LEX to YACC.

What do %left and %right do?

They set the associativity of operators and, by their order, their precedence. Later lines have higher precedence.

What is an ambiguous grammar?

One where some input has more than one parse tree, like 2+3*4 in E : E+E | E*E. Precedence declarations resolve it.

What is %prec used for?

It gives a rule the precedence of a given token. Here it gives unary minus the precedence of UMINUS.

What is a shift-reduce conflict?

The parser cannot decide whether to read the next token (shift) or apply a rule (reduce). Precedence rules settle most of these.

Why does the LEX file return 0 for a newline?

Token 0 tells YACC the input has ended, so parsing stops at the end of the line.

Which result does 2+3*4 give and why?

14, because * has higher precedence than +, so 3*4 is evaluated first.

What is YACC?

Yet Another Compiler Compiler: a tool that generates a parser in C from a context-free grammar.

What is the structure of a YACC program?

Declarations (%{ %}, %token), grammar rules between %% markers, and user C code.

How do LEX and YACC work together?

LEX reads characters and returns tokens. YACC calls yylex() to get tokens and checks that they follow the grammar.

What is y.tab.h?

A header file made by yacc -d that holds the token numbers (like A, B), so LEX and YACC agree on them.
