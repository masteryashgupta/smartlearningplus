Compiler Design Lab, 5CS4-22 (Turbo C++)

Experiment 6: Symbol table: insert, delete and display

Aim: Write a C program to insert, delete and display the entries in a symbol table.

Source code

#include<stdio.h>
#include<conio.h>
#include<string.h>

struct SymbTab
{
    char label[10];
    char symbol[10];
    int addr;
};

struct SymbTab table[20];
int size = 0;

int Search(char lab[])
{
    int i;
    for(i = 0; i < size; i++)
    {
        if(strcmp(table[i].label, lab) == 0)
            return i;
    }
    return -1;
}

void Insert()
{
    char l[10];
    printf("\nEnter the label: ");
    scanf("%s", l);

    if(Search(l) != -1)
    {
        printf("Label already exists, duplicate can't be inserted\n");
        return;
    }
    if(size == 20)
    {
        printf("Table is full\n");
        return;
    }

    strcpy(table[size].label, l);
    printf("Enter the symbol: ");
    scanf("%s", table[size].symbol);
    printf("Enter the address: ");
    scanf("%d", &table[size].addr);
    size++;
    printf("Label inserted\n");
}

void Display()
{
    int i;
    printf("\nLABEL\tSYMBOL\tADDRESS\n");
    for(i = 0; i < size; i++)
    {
        printf("%s\t%s\t%d\n", table[i].label, table[i].symbol, table[i].addr);
    }
}

void Delete()
{
    char l[10];
    int pos, i;
    printf("\nEnter the label to be deleted: ");
    scanf("%s", l);

    pos = Search(l);
    if(pos == -1)
    {
        printf("Label not found\n");
        return;
    }

    for(i = pos; i < size - 1; i++)
        table[i] = table[i + 1];
    size--;

    printf("After deletion:\n");
    Display();
}

void main()
{
    int op;
    char la[10];

    clrscr();
    do
    {
        printf("\n\tSYMBOL TABLE IMPLEMENTATION\n");
        printf("\n\t1.INSERT\n\t2.DISPLAY\n\t3.DELETE\n\t4.SEARCH\n\t5.END\n");
        printf("\n\tEnter your option: ");
        scanf("%d", &op);

        switch(op)
        {
            case 1: Insert(); break;
            case 2: Display(); break;
            case 3: Delete(); break;
            case 4:
                printf("\nEnter the label to be searched: ");
                scanf("%s", la);
                if(Search(la) != -1)
                    printf("The label is present in the symbol table\n");
                else
                    printf("The label is not present in the symbol table\n");
                break;
            case 5: break;
            default: printf("Wrong choice\n");
        }
    } while(op != 5);

    getch();
}

The manual builds the table as a linked list. This version uses an array of structures to keep it shorter. It has the same menu and operations (the manual also has a Modify option).

Explanation

  1. A symbol table stores information about every name in a program. Each row here has a label (name), a symbol (type) and an addr (address).
  2. table[20] is an array of structures that holds the rows, and size counts how many rows are in use.
  3. Search compares labels with strcmp and returns the row index, or -1 if the label is missing.
  4. Insert first calls Search to reject duplicates, then fills table[size] and increases size.
  5. Display prints rows 0 to size-1.
  6. Delete finds the row, shifts every later row up by one (table[i] = table[i+1]), and decreases size.
  7. main shows a menu in a do-while loop with a switch, and repeats until option 5.

Viva questions

What is a symbol table?

A data structure the compiler uses to store information about identifiers, such as name, type, address and scope.

Which phases use the symbol table?

All of them: lexical, syntax and semantic analysis, and code generation.

Which operations does a symbol table need?

Insert, search (lookup), delete and display (and modify).

Why check for duplicates before inserting?

A name should be declared only once in a scope.

Array vs linked list for a symbol table?

An array has a fixed size and needs shifting on delete. A linked list grows as needed and deletion only changes pointers. The manual uses a linked list.

How else can a symbol table be built?

With a hash table, which gives very fast lookup, or a binary search tree.

What is a structure?

A user-defined type that groups different variables under one name.

Why is the function called Delete and not delete?

delete is a reserved keyword in C++, and Turbo C++ compiles .CPP files as C++.

What does the break in a switch case do?

It stops execution from falling through into the next case.
