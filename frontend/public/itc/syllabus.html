5CS3-01 · Information Theory & Coding · B.Tech CSE · III Year – V Sem

6 UNITS · 28 HRS Credit: 2 · 2L+0T+0P Max Marks: 100 (IA:30 · ETE:70)

📋 Official RTU Syllabus — ITC (5CS3-01)

Rajasthan Technical University, Kota
Unit Contents Hours Guide Link
1 Introduction: Objective, scope and outcome of the course. 01 Open →
2 Introduction to Information Theory: Uncertainty, Information and Entropy, Information measures for continuous random variables, source coding theorem. Discrete Memoryless channels, Mutual information, Conditional entropy. 05 Open →
3 Source Coding Schemes for Data Compaction: Prefix code, Huffman code, Shannon-Fano code & Lempel-Ziv coding, channel capacity. Channel coding theorem. Shannon limit. 05 Open →
4 Linear Block Code: Introduction to error correcting codes, coding & decoding of linear block code, minimum distance consideration, conversion of non-systematic form of matrices into systematic form. 05 Open →
5 Cyclic Code: Code Algebra, Basic properties of Galois fields (GF), polynomial operations over Galois fields, generating cyclic code by generating polynomial, parity check polynomial. Encoder & decoder for cyclic codes. 06 Open →
6 Convolutional Code: Convolutional encoders of different rates. Code Tree, Trellis and state diagram. Maximum likelihood decoding of convolutional code: The Viterbi Algorithm. Free distance of a convolutional code. 06 Open →
