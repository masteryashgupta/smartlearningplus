Experiment 11: Longest Common Subsequence using Dynamic Programming

Aim: Implement Longest Common Subsequence problem using Dynamic Programming.

Source code

This is the program from the lab manual, unchanged. Compile it with gcc aoa_exp11.c -o exp11 and run ./exp11 (on Windows with MinGW, exp11).

#include <stdio.h>
#include <string.h>
#include <time.h>
int max(int a, int b)
{
    return (a > b) ? a : b;
}
int main()
{
    char X[100], Y[100];
    int m, n, i, j;
    clock_t start, end;
    double cpu_time_used;
    printf("Enter first string: ");
    scanf("%s", X);
    printf("Enter second string: ");
    scanf("%s", Y);
    m = strlen(X);
    n = strlen(Y);
    int dp[m + 1][n + 1];
    // Start timing
    start = clock();
    // Build DP table bottom-up
    for(i = 0; i <= m; i++)
    {
        for(j = 0; j <= n; j++)
        {
            if(i == 0 || j == 0)
            dp[i][j] = 0;
            else if(X[i - 1] == Y[j - 1])
            dp[i][j] = dp[i - 1][j - 1] + 1;
            else
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    // Trace back to build the LCS string
    int index = dp[m][n];
    char lcs[index + 1];
    lcs[index] = '\0';
    i = m;
    j = n;
    while(i > 0 && j > 0)
    {
        if(X[i - 1] == Y[j - 1])
        {
            lcs[index - 1] = X[i - 1];
            i--;
            j--;
            index--;
        }
        else if(dp[i - 1][j] > dp[i][j - 1])
        i--;
        else
        j--;
    }
    // End timing
    end = clock();
    cpu_time_used = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("\nLength of Longest Common Subsequence = %d\n", dp[m][n]);
    printf("Longest Common Subsequence = %s\n", lcs);
    printf("\nTime Required = %f seconds\n", cpu_time_used);
    return 0;
}

Explanation (from the manual)

Concept

Given two strings, e.g. "AGGTAB" and "GXTXAYB" , the goal is to find the longest common subsequence between them.

A "subsequence" means: keeping the letters of a string in the same relative order, but allowed to skip some letters in between (the order itself must not change). For example, a subsequence of "AGGTAB" could be "GTB" (some letters skipped, but order preserved).

A "common subsequence" is one that appears in both strings. We want the longest such subsequence.

This is solved using Dynamic Programming: build a table comparing every character pair from both strings.

If the current characters of both strings are the same → this character becomes part of the LCS, so add 1 to the previous diagonal answer. If they are different → check both possibilities (skip a character from one string, or from the other) and keep whichever gives the longer result.

Worked Example

  String X = "AGGTAB"
  String Y = "GXTXAYB"

  The DP table is filled character by character, and matching characters are collected in
  order: G, T, A, B.

  So LCS = "GTAB" (length = 4).

  Checking: "GTAB" appears in the same order in both strings —
  X = A-G-G-T-A-B (G, T, A, B appear in this order)
  Y = G-X-T-X-A-Y-B (G, T, A, B appear in this order too, skipping X, X, Y)

Time Complexity

LCS has a time complexity of O(m × n), where m and n are the lengths of the two strings. Every character pair is checked exactly once in the table, which makes this approach far more efficient than brute force (generating and comparing every possible subsequence, which would be extremely slow).

What the Program Does

  1. The user enters two strings.
  2. The program builds a DP table comparing characters of both strings (the match/no-match process above).
  3. The LCS length is read off the table, and the table is traced back to reconstruct the actual LCS string.
  4. Both the length and the actual LCS string are printed.
  5. The time taken (in seconds) is displayed.

In short: compare characters of both strings, extend the LCS on a match, and pick the best possibility from the table on a mismatch.

Viva questions

What is the Longest Common Subsequence?

The longest sequence that appears in both strings in the same order, but not necessarily next to each other.

Subsequence vs substring?

A substring is contiguous. A subsequence only keeps the order and can skip characters.

Write the recurrence for LCS.

If X[i] = Y[j]: L[i][j] = L[i-1][j-1] + 1. Otherwise L[i][j] = max(L[i-1][j], L[i][j-1]). The first row and column are 0.

What is the time and space complexity?

O(m × n) for both, for strings of lengths m and n.

How is the LCS string printed?

By moving back through the table from L[m][n]: a matching character is added and the move is diagonal, otherwise the move goes to the larger neighbour.

Is the LCS unique?

Not always. There can be several subsequences with the same maximum length.

What is the LCS of AGGTAB and GXTXAYB?

GTAB, of length 4.

Where is LCS used?

In file comparison (diff), DNA sequence comparison and version control.
