Phases of a compiler

A compiler translates source code into machine code in stages. The output of each phase is the input of the next.

  1. Lexical analysis: reads characters and groups them into tokens (keywords, identifiers, operators). Exp 2 to 9 belong here.
  2. Syntax analysis: checks tokens against the grammar and builds a parse tree. Exp 10 to 13 belong here.
  3. Semantic analysis: checks meaning, such as type matching and declared variables.
  4. Intermediate code generation: produces machine-independent code such as three-address code.
  5. Code optimization: makes the intermediate code faster or smaller.
  6. Code generation: produces the target machine code.

The symbol table (Exp 6) and the error handler are used by every phase.

Viva questions

What is a compiler?

A program that translates a whole source program written in a high-level language into machine code (or another target language) and reports errors.

Compiler vs interpreter?

A compiler translates the whole program first and then runs the result. An interpreter translates and runs one statement at a time. Compiled programs usually run faster.

Name the phases of a compiler.

Lexical analysis, syntax analysis, semantic analysis, intermediate code generation, code optimization and code generation.

What are front end and back end?

The front end (lexical, syntax, semantic analysis, intermediate code) depends on the source language. The back end (optimization, code generation) depends on the target machine.

What is a token, a lexeme and a pattern?

A lexeme is the actual text, like count. A token is its category, like identifier. A pattern is the rule that describes the lexemes of a token.

What is the role of the symbol table?

It stores information about names (type, address, scope) and is used by all phases.

What are LEX and YACC?

LEX generates a lexical analyzer from regular expressions. YACC generates a parser from a grammar.

What is the difference between LL and LR parsers?

LL parsers are top-down: they read left to right and build a leftmost derivation. LR parsers are bottom-up: they read left to right and build a rightmost derivation in reverse. LR handles more grammars.

What is a cross compiler?

A compiler that runs on one machine but produces code for a different machine.

Experiment 2: Identify whether a string is a keyword

Aim: To identify whether a given string is a keyword or not.

Source code

#include<stdio.h>
#include<conio.h>
#include<string.h>

void main()
{
    char keyword[32][10] = {"auto","double","int","struct","break","else","long",
                            "switch","case","enum","register","typedef","char",
                            "extern","return","union","const","float","short",
                            "unsigned","continue","for","signed","void","default",
                            "goto","sizeof","volatile","do","if","static","while"};
    char string[10];
    int flag = 0, i;

    clrscr();
    printf("enter any string:");
    gets(string);

    for(i = 0; i < 32; i++)
    {
        if(strcmp(string, keyword[i]) == 0)
        {
            flag = 1;
        }
    }

    if(flag == 1)
        printf("%s is a keyword", string);
    else
        printf("%s is not a keyword", string);

    getch();
}

  2. Press Alt+F9 to compile and Ctrl+F9 to run.

Explanation

  1. keyword[32][10] is a 2D array holding the 32 C keywords, each up to 9 letters plus '\0'.
  2. gets(string) reads the word typed by the user.
  3. The for loop compares the input with every keyword using strcmp, which returns 0 when two strings are equal.
  4. On a match, flag is set to 1. The flag remembers that a match was found.
  5. After the loop, the program prints whether the word is a keyword, based on flag.

Viva questions

What is a keyword?

A reserved word with a fixed meaning in the language, like int or while. It cannot be used as a variable name.

Keyword vs identifier?

Keywords are reserved by the language. Identifiers are names chosen by the programmer for variables, functions and so on.

How many keywords are in C?

32 in standard C89/C90, the set used in this program.

What does strcmp return?

0 if the strings are equal, a negative value if the first is smaller, and a positive value if the first is larger.

Why can't we compare strings with ==?

For arrays, == compares memory addresses, not the characters. strcmp compares the characters.

What is the use of the flag variable?

It records whether a match was found while the loop runs, so the result can be printed after the loop.

Why is gets() unsafe?

It does not check the size of the array, so a long input overflows the buffer. It was removed from C11. Here the array holds only 9 characters.

Which compiler phase does this program belong to?

Lexical analysis, which classifies words as keywords or identifiers.

How can the search be made faster?

Sort the keyword table and use binary search (Exp 3 does this), or use a hash table.

Experiment 3: Count total keywords in a file

Aim: Write a C program to count the total number of keywords in a file [taking file from user].

Source code: Version 1: reads from a file

#include<stdio.h>
#include<conio.h>
#include<string.h>
#include<ctype.h>
#include<stdlib.h>

void main()
{
    char keyword[32][10] = {"auto","double","int","struct","break","else","long",
                            "switch","case","enum","register","typedef","char",
                            "extern","return","union","const","float","short",
                            "unsigned","continue","for","signed","void","default",
                            "goto","sizeof","volatile","do","if","static","while"};
    char fname[30], word[20];
    int c, i, j = 0, count = 0;
    FILE *fp;

    clrscr();
    printf("Enter file name: ");
    gets(fname);

    fp = fopen(fname, "r");
    if(fp == NULL)
    {
        printf("File not found");
        getch();
        exit(0);
    }

    while(1)
    {
        c = fgetc(fp);

        if(isalpha(c))
        {
            word[j++] = c;
        }
        else
        {
            if(j > 0)
            {
                word[j] = '\0';
                for(i = 0; i < 32; i++)
                {
                    if(strcmp(word, keyword[i]) == 0)
                    {
                        count++;
                        break;
                    }
                }
                j = 0;
            }
            if(c == EOF)
                break;
        }
    }

    fclose(fp);
    printf("Total keywords in file = %d", count);
    getch();
}

Source code: Version 2 (reads text typed by the user)

Use this if no file is needed. It reads one line with gets and goes through it letter by letter, building each word the same way as the file version. The keywords found here are int, float and return.

#include<stdio.h>
#include<conio.h>
#include<string.h>
#include<ctype.h>

void main()
{
    char keyword[32][10] = {"auto","double","int","struct","break","else","long",
                            "switch","case","enum","register","typedef","char",
                            "extern","return","union","const","float","short",
                            "unsigned","continue","for","signed","void","default",
                            "goto","sizeof","volatile","do","if","static","while"};
    char text[200], word[20];
    int i, j = 0, k, count = 0;

    clrscr();
    printf("Enter a line of text: ");
    gets(text);

    for(i = 0; ; i++)
    {
        if(isalpha(text[i]))
        {
            word[j++] = text[i];
        }
        else
        {
            if(j > 0)
            {
                word[j] = '\0';
                for(k = 0; k < 32; k++)
                {
                    if(strcmp(word, keyword[k]) == 0)
                    {
                        count++;
                        break;
                    }
                }
                j = 0;
            }
            if(text[i] == '\0')
                break;
        }
    }

    printf("Total keywords = %d", count);
    getch();
}

Output

Enter a line of text: int a; float b; return 0;
Total keywords = 3

Explanation

  1. fopen(fname, "r") opens the file for reading. It returns NULL if the file does not exist, and the program then exits.
  2. fgetc(fp) reads one character at a time and returns EOF at the end of the file.
  3. While the characters are letters (isalpha), they are stored in word[]. Any other character (space, ;, (, newline) ends the word.
  4. When a word ends, '\0' is added and the word is compared with all 32 keywords using strcmp. A match increases count and break stops the search.
  5. j = 0 starts the next word. At EOF the loop stops and the total is printed.

Viva questions

Why is c declared as int and not char?

EOF is -1, which does not fit reliably in a char. fgetc returns an int, so the variable must be an int.

What does fopen return on failure?

NULL. Always check for it before reading.

What do the modes "r", "w" and "a" mean?

Read, write (overwrites the file) and append (adds at the end).

Why is break used inside the keyword loop?

Once a keyword matches there is no need to check the rest of the table.

What does isalpha do?

It returns true if the character is a letter (A to Z or a to z).

What is the time cost per word here?

Linear search, at most 32 comparisons per word. The manual uses a sorted table with binary search, about 5 comparisons.

How does binary search work?

On a sorted table, compare with the middle entry. If the word is smaller, search the left half, otherwise the right half, and repeat until found or the range is empty.

What is a limitation of this program?

A name like int2 is read as int and counted, because digits end the word. A real lexer treats int2 as one identifier.

Which compiler phase is this?

Lexical analysis: splitting text into words and classifying them.

Experiment 4: Count total operators in a string

Aim: Write a program to count the total number of operators (+, -, *, /) in the input.

This matches the manual's aim ("taking file from user"). Create test.txt in the same folder with two lines: a = b + c * d; and x = y - z / 2;. The file is opened with fopen and read one character at a time with fgetc until EOF. The same operator check is used, and the = signs are not counted.

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>

void main()
{
    char fname[30];
    int c, count = 0;
    FILE *fp;

    clrscr();
    printf("Enter file name: ");
    gets(fname);

    fp = fopen(fname, "r");
    if(fp == NULL)
    {
        printf("File not found");
        getch();
        exit(0);
    }

    while((c = fgetc(fp)) != EOF)
    {
        if(c == '+' || c == '-' || c == '*' || c == '/')
            count++;
    }

    fclose(fp);
    printf("Number of operators in the file = %d", count);
    getch();
}

Output

Number of operators in the file = 4

Explanation

  1. gets(string) reads the whole line, including spaces. scanf("%s") would stop at the first space and miss operators after it.
  2. The for loop visits each character until the string terminator '\0'.
  3. The condition uses || (or), so a match with any one of the four operators counts.
  4. count++ adds one for each operator found. The total is printed at the end.

Viva questions

What is an operator?

A symbol that performs an operation on operands, such as + or *.

What is the difference between = and ==?

= assigns a value. == compares two values.

What does || mean?

Logical OR: the condition is true if at least one side is true.

Why use gets and not scanf("%s")?

scanf("%s") stops reading at the first space, so the rest of the line is lost.

How is the end of a string marked?

By the null character '\0'.

How would you read from a file instead?

Open it with fopen, read with fgetc until EOF, and run the same if check on each character.

What are the limitations?

++ counts as two operators, a - in a negative number is counted, and operators like == or && are not recognised. A real lexer treats them as single tokens.

Which compiler phase does this relate to?

Lexical analysis: operators are one kind of token.

Experiment 5: Count occurrences of each character

Aim: Write a C program to count the total occurrence of each character (letter) in the input.

Source code: Version 1: reads a string from the keyboard

#include<stdio.h>
#include<conio.h>
#include<ctype.h>

void main()
{
    char string[100];
    int count[26] = {0};
    int c = 0;

    clrscr();
    printf("Enter a string\n");
    gets(string);

    while(string[c] != '\0')
    {
        if(isalpha(string[c]))
        {
            count[tolower(string[c]) - 'a']++;
        }
        c++;
    }

    for(c = 0; c < 26; c++)
    {
        if(count[c] > 0)
            printf("%c occurs %d times in the string.\n", c + 'a', count[c]);
    }
    getch();
}

Explanation

  1. count[26] has one counter for each letter: count[0] for a, count[1] for b, and so on. All start at 0.
  2. gets reads the line. The while loop walks through it until '\0'.
  3. isalpha skips spaces, digits and symbols. tolower makes H and h count together.
  4. The key line is count[tolower(string[c]) - 'a']++. Letters are ASCII numbers ('a' is 97), so subtracting 'a' gives the letter's position: a=0, b=1 ... z=25. That counter is increased by one.
  5. To print, c + 'a' converts the index back to a letter, and only letters with a count above 0 are shown.

Viva questions

Why is subtracting 'a' needed?

It turns a letter into an array index from 0 to 25. Without it the index would be 97 or more.

What is ASCII?

A code that gives every character a number, for example 'a' = 97 and 'A' = 65.

What does int count[26] = {0} do?

It creates 26 integers and sets all of them to 0.

Why use an array and not 26 variables?

One index calculation replaces 26 separate if checks.

How would you count every character, not just letters?

Use int count[256] and count[string[c]]++.

What does tolower do?

It converts an uppercase letter to lowercase and leaves other characters unchanged.

What is the time complexity?

O(n) for n characters, since the string is scanned once.

Which compiler phase does this relate to?

Lexical analysis: it reads the input character by character.

Experiment 6: Symbol table: insert, delete and display

Aim: Write a C program to insert, delete and display the entries in a symbol table.

Source code

#include<stdio.h>
#include<conio.h>
#include<string.h>

struct SymbTab
{
    char label[10];
    char symbol[10];
    int addr;
};

struct SymbTab table[20];
int size = 0;

int Search(char lab[])
{
    int i;
    for(i = 0; i < size; i++)
    {
        if(strcmp(table[i].label, lab) == 0)
            return i;
    }
    return -1;
}

void Insert()
{
    char l[10];
    printf("\nEnter the label: ");
    scanf("%s", l);

    if(Search(l) != -1)
    {
        printf("Label already exists, duplicate can't be inserted\n");
        return;
    }
    if(size == 20)
    {
        printf("Table is full\n");
        return;
    }

    strcpy(table[size].label, l);
    printf("Enter the symbol: ");
    scanf("%s", table[size].symbol);
    printf("Enter the address: ");
    scanf("%d", &table[size].addr);
    size++;
    printf("Label inserted\n");
}

void Display()
{
    int i;
    printf("\nLABEL\tSYMBOL\tADDRESS\n");
    for(i = 0; i < size; i++)
    {
        printf("%s\t%s\t%d\n", table[i].label, table[i].symbol, table[i].addr);
    }
}

void Delete()
{
    char l[10];
    int pos, i;
    printf("\nEnter the label to be deleted: ");
    scanf("%s", l);

    pos = Search(l);
    if(pos == -1)
    {
        printf("Label not found\n");
        return;
    }

    for(i = pos; i < size - 1; i++)
        table[i] = table[i + 1];
    size--;

    printf("After deletion:\n");
    Display();
}

void main()
{
    int op;
    char la[10];

    clrscr();
    do
    {
        printf("\n\tSYMBOL TABLE IMPLEMENTATION\n");
        printf("\n\t1.INSERT\n\t2.DISPLAY\n\t3.DELETE\n\t4.SEARCH\n\t5.END\n");
        printf("\n\tEnter your option: ");
        scanf("%d", &op);

        switch(op)
        {
            case 1: Insert(); break;
            case 2: Display(); break;
            case 3: Delete(); break;
            case 4:
                printf("\nEnter the label to be searched: ");
                scanf("%s", la);
                if(Search(la) != -1)
                    printf("The label is present in the symbol table\n");
                else
                    printf("The label is not present in the symbol table\n");
                break;
            case 5: break;
            default: printf("Wrong choice\n");
        }
    } while(op != 5);

    getch();
}

Explanation

  1. A symbol table stores information about every name in a program. Each row here has a label (name), a symbol (type) and an addr (address).
  2. table[20] is an array of structures that holds the rows, and size counts how many rows are in use.
  3. Search compares labels with strcmp and returns the row index, or -1 if the label is missing.
  4. Insert first calls Search to reject duplicates, then fills table[size] and increases size.
  5. Display prints rows 0 to size-1.
  6. Delete finds the row, shifts every later row up by one (table[i] = table[i+1]), and decreases size.
  7. main shows a menu in a do-while loop with a switch, and repeats until option 5.

Viva questions

What is a symbol table?

A data structure the compiler uses to store information about identifiers, such as name, type, address and scope.

Which phases use the symbol table?

All of them: lexical, syntax and semantic analysis, and code generation.

Which operations does a symbol table need?

Insert, search (lookup), delete and display (and modify).

Why check for duplicates before inserting?

A name should be declared only once in a scope.

Array vs linked list for a symbol table?

An array has a fixed size and needs shifting on delete. A linked list grows as needed and deletion only changes pointers. The manual uses a linked list.

How else can a symbol table be built?

With a hash table, which gives very fast lookup, or a binary search tree.

What is a structure?

A user-defined type that groups different variables under one name.

Why is the function called Delete and not delete?

delete is a reserved keyword in C++, and Turbo C++ compiles .CPP files as C++.

What does the break in a switch case do?

It stops execution from falling through into the next case.

Viva questions

What is the language a^n b^n?

Strings with n a's followed by exactly n b's, for example ab, aabb, aaabbb.

Is aaab accepted? Why not?

No. It has 3 a's but only 1 b, so the counts are not equal.

Why can a regular expression not recognize a^n b^n?

A finite automaton cannot count an unlimited n. A context-free grammar (a stack) can.

What does the empty alternative in S do?

It lets S match nothing, which ends the recursion and also makes the empty string valid (n = 0).

What is a context-free grammar?

A set of rules where the left side is a single non-terminal, such as S : A S B.

What are terminals and non-terminals here?

Terminals are the tokens A, B and NL. Non-terminals are S and stmt.

What is YACC?

Yet Another Compiler Compiler: a tool that generates a parser in C from a context-free grammar.

What is the structure of a YACC program?

Declarations (%{ %}, %token), grammar rules between %% markers, and user C code.

How do LEX and YACC work together?

LEX reads characters and returns tokens. YACC calls yylex() to get tokens and checks that they follow the grammar.

What is y.tab.h?

A header file made by win_bison -y -d that holds the token numbers (like A, B), so LEX and YACC agree on them.

What does yyparse() do?

It starts parsing. It returns 0 if the input is accepted and non-zero if there is a syntax error.

What is yyerror()?

The function YACC calls when it finds a syntax error. We define it to print a message.

What kind of parser does YACC build?

A bottom-up LALR(1) parser.

What does the win_bison -y -d command do?

It reads the YACC grammar file (.y) and generates the parser source y.tab.c and header y.tab.h with token definitions.

Why must win_bison run before win_flex?

The LEX file includes y.tab.h to access the token numbers defined by YACC, so the header must exist first.

What does win_flex --wincompat do?

It generates the C scanner lex.yy.c from the .l file while avoiding Unix-only headers like unistd.h for Windows compatibility.

  | E '*' E             { $$ = $1 * $3; }
  | E '/' E             {
                            if($3 == 0)
                            {
                                printf("Division by zero\n");
                                exit(1);
                            }
                            $$ = $1 / $3;
                        }
  | '-' E %prec UMINUS  { $$ = -$2; }
  | '(' E ')'           { $$ = $2; }
  | NUMBER              { $$ = $1; }
  ;
%%

{
    printf("Expression is invalid\n");
    return 0;
}

{
    printf("Enter the expression\n");

Explanation

  1. The LEX file turns a run of digits into a NUMBER token and stores its value in yylval (using atoi). Spaces are skipped, Enter returns 0 (end of input), and every other character, like + or (, is returned as itself.
  2. The grammar says an expression E is E + E, E - E, E * E, E / E, a negated expression, an expression in brackets, or a number.
  3. Each rule has an action. $1, $2, $3 are the values of the parts on the right, and $$ is the value of the whole rule. So $$ = $1 + $3 adds the left and right values.
  4. A grammar like E : E + E | E * E is ambiguous. The lines %left '+' '-' and %left '*' '/' fix this. Later lines have higher precedence, so * and / bind tighter than + and -, and %left makes operators of the same level group from the left.
  5. %right UMINUS with %prec UMINUS gives unary minus the highest precedence, so -5+2 means (-5)+2.
  6. The rule S : E prints the final value. Division by zero is checked before dividing.

Viva questions

What do $$, $1 and $3 mean?

$$ is the value of the left side of the rule. $1, $2, $3 are the values of the first, second and third symbols on the right.

What is yylval?

A variable used to pass the value of a token (like the number 25) from LEX to YACC.

What do %left and %right do?

They set the associativity of operators and, by their order, their precedence. Later lines have higher precedence.

What is an ambiguous grammar?

One where some input has more than one parse tree, like 2+3*4 in E : E+E | E*E. Precedence declarations resolve it.

What is %prec used for?

It gives a rule the precedence of a given token. Here it gives unary minus the precedence of UMINUS.

What is a shift-reduce conflict?

The parser cannot decide whether to read the next token (shift) or apply a rule (reduce). Precedence rules settle most of these.

Why does the LEX file return 0 for a newline?

Token 0 tells YACC the input has ended, so parsing stops at the end of the line.

Which result does 2+3*4 give and why?

14, because * has higher precedence than +, so 3*4 is evaluated first.

What is YACC?

Yet Another Compiler Compiler: a tool that generates a parser in C from a context-free grammar.

What is the structure of a YACC program?

Declarations (%{ %}, %token), grammar rules between %% markers, and user C code.

How do LEX and YACC work together?

LEX reads characters and returns tokens. YACC calls yylex() to get tokens and checks that they follow the grammar.

What is y.tab.h?

A header file made by win_bison -y -d that holds the token numbers (like A, B), so LEX and YACC agree on them.

What does the win_bison -y -d command do?

It reads the YACC grammar file (.y) and generates the parser source y.tab.c and header y.tab.h with token definitions.

Why must win_bison run before win_flex?

The LEX file includes y.tab.h to access the token numbers defined by YACC, so the header must exist first.

What does win_flex --wincompat do?

It generates the C scanner lex.yy.c from the .l file while avoiding Unix-only headers like unistd.h for Windows compatibility.

Aim: Write a C program to find the First of any grammar.

Source code

char prod[20][10];
int first[26][128], follow[26][128];

int n, nn = 0, changed;

void add(int s[][128], char A, int ch)
{
    if(!s[A - 'A'][ch])
    {
        s[A - 'A'][ch] = 1;
        changed = 1;
    }
}

void addset(int s[][128], char A, int t[][128], char B, int noeps)
{
    int ch;
    for(ch = 0; ch < 128; ch++)
        if(t[B - 'A'][ch] && !(noeps && ch == '#'))
            add(s, A, ch);
}

void findfirst()
{
    int p, k, alleps;
    char A, X;
    do
    {
        changed = 0;
        for(p = 0; p < n; p++)
        {
            A = prod[p][0];
            alleps = 1;
            for(k = 2; prod[p][k] != '\0'; k++)
            {
                X = prod[p][k];
                if(!isupper(X))
                {
                    add(first, A, X);
                    alleps = 0;
                    break;
                }
                addset(first, A, first, X, 1);
                if(!first[X - 'A']['#'])
                {
                    alleps = 0;
                    break;
                }
            }
            if(alleps)
                add(first, A, '#');
        }
    } while(changed);
}

void findfollow()
{
    int p, k, j, nullable;
    char B, Y;
    add(follow, prod[0][0], '$');
    do
    {
        changed = 0;
        for(p = 0; p < n; p++)
            for(k = 2; prod[p][k] != '\0'; k++)
            {
                B = prod[p][k];
                if(!isupper(B))
                    continue;
                nullable = 1;
                for(j = k + 1; prod[p][j] != '\0'; j++)
                {
                    Y = prod[p][j];
                    if(!isupper(Y))
                    {
                        add(follow, B, Y);
                        nullable = 0;
                        break;
                    }
                    addset(follow, B, first, Y, 1);
                    if(!first[Y - 'A']['#'])
                    {
                        nullable = 0;
                        break;
                    }
                }
                if(nullable)
                    addset(follow, B, follow, prod[p][0], 0);
            }
    } while(changed);
}

            printf("%c", ch);

}

Explanation

  1. The grammar is read into prod[], one string per production, like "E=TR". The right side starts at index 2, after the =.
  2. first[A][ch] is 1 if the symbol ch is in First(A). There is one row for each capital letter and one column for each ASCII character.
  3. First: for each production A=X1 X2 ..., look at X1. If it is a terminal (or #), add it to First(A) and stop. If it is a non-terminal, add everything in its First set except #. If its First set contains # (it can vanish), continue with X2. If every symbol can vanish, add # to First(A).
  4. Follow: add $ to Follow of the start symbol. For each non-terminal B in a production, look at the symbols after it. A terminal is added to Follow(B). A non-terminal contributes its First set except #. If everything after B can vanish, or B is last, add Follow of the left-hand side to Follow(B).
  5. Both are computed in a loop that repeats until no set changes (changed stays 0). This also works for left-recursive grammars, where a simple recursive function would loop forever.
  6. show prints each set, and the sets are printed for each non-terminal in the order it first appears on a left-hand side.

Viva questions

What is the First set?

First(A) is the set of terminals that can appear at the start of a string derived from A. It includes # (epsilon) if A can derive the empty string.

What is the Follow set?

Follow(A) is the set of terminals that can appear immediately after A in some sentential form. It never contains epsilon.

Why does the start symbol get $ in its Follow set?

$ marks the end of the input, and the start symbol can be followed by the end of input.

State the rules for computing First.

If X is a terminal, First(X) = {X}. If X derives epsilon, add epsilon. For A = X1 X2 ..., add First(X1) without epsilon, and if X1 derives epsilon also First(X2), and so on.

State the rules for computing Follow.

1) Put $ in Follow of the start symbol. 2) For A = aBb, add First(b) without epsilon to Follow(B). 3) If b is empty or can derive epsilon, add Follow(A) to Follow(B).

Where are First and Follow used?

To build the predictive (LL(1)) parsing table, and in error recovery.

What does the symbol # mean in this program?

Epsilon, the empty string.

Why do we repeat the loop until nothing changes?

A set may depend on another set that is not complete yet. Repeating until no set grows (a fixed point) gives the final sets.

What is a left-recursive grammar and why is it a problem?

One with a rule like A = Aa. Top-down parsers loop forever on it, so the left recursion must be removed first. The grammar in this experiment already has it removed.

What is the LL(1) condition?

For each non-terminal, the First sets of its alternatives must be disjoint, and if one alternative can derive epsilon, its First set must not overlap Follow(A).
