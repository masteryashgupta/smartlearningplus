Experiment 7: Fractional Knapsack (Greedy Method)

Aim: Implement Knapsack problem using Greedy Method.

Source code

This is the program from the lab manual, unchanged. Compile it with gcc aoa_exp7.c -o exp7 and run ./exp7 (on Windows with MinGW, exp7).

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
struct Item
{
    int weight;
    int profit;
    double ratio;
};
// Function to sort items based on profit/weight ratio (descending)
void sortItems(struct Item items[], int n)
{
    int i, j;
    struct Item temp;
    for(i = 0; i < n - 1; i++)
    {
        for(j = 0; j < n - i - 1; j++)
        {
            if(items[j].ratio < items[j + 1].ratio)
            {
                temp = items[j];
                items[j] = items[j + 1];
                items[j + 1] = temp;
            }
        }
    }
}
int main()
{
    int n, i;
    int capacity;
    clock_t start, end;
    double cpu_time_used;
    printf("Enter number of items: ");
    scanf("%d", &n);
    struct Item items[n];
    printf("Enter weight and profit of each item:\n");
    for(i = 0; i < n; i++)
    {
        printf("Item %d weight: ", i + 1);
        scanf("%d", &items[i].weight);
        printf("Item %d profit: ", i + 1);
        scanf("%d", &items[i].profit);
        items[i].ratio = (double)items[i].profit / items[i].weight;
    }
    printf("Enter knapsack capacity: ");
    scanf("%d", &capacity);
    // Start timing
    start = clock();
    // Sort items by profit/weight ratio (Greedy choice)
    sortItems(items, n);
    double totalProfit = 0.0;
    int remainingCapacity = capacity;
    printf("\nItems selected (Greedy - by profit/weight ratio):\n");
    for(i = 0; i < n && remainingCapacity > 0; i++)
    {
        if(items[i].weight <= remainingCapacity)
        {
            // Take the whole item
            remainingCapacity -= items[i].weight;
            totalProfit += items[i].profit;
            printf("Item (W=%d, P=%d) -> Fully taken\n", items[i].weight, items[i].profit);
        }
        else
        {
            // Take fraction of the item
            double fraction = (double)remainingCapacity / items[i].weight;
            totalProfit += items[i].profit * fraction;
            printf("Item (W=%d, P=%d) -> Fraction taken = %.2f\n", items[i].weight, items[i].profit, fraction);
            remainingCapacity = 0;
        }
    }
    // End timing
    end = clock();
    cpu_time_used = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("\nMaximum Profit (Greedy Knapsack) = %.2f\n", totalProfit);
    printf("\nTime Required = %f seconds\n", cpu_time_used);
    return 0;
}

Explanation (from the manual)

Concept

A bag has a fixed weight capacity (e.g. 50 kg), and there are several items, each with its own weight and profit (value). The goal is to fill the bag with items so that total profit is as large as possible, without exceeding the weight limit.

The Greedy idea is simple: always pick the item with the best "value for its weight" first. Compute a ratio for every item — profit ÷ weight. The item with the highest ratio is the "best deal", so take it first (completely). Then take the item with the next-best ratio, and so on, until the bag is full.

A special feature of this method: items can be broken into fractions! If the last item doesn't fit completely, take only as much of it as fits — which is why this is also called the Fractional Knapsack.

Worked Example

  3 items:
  Item 1: weight=10, profit=60 → ratio = 60/10 = 6.0
  Item 2: weight=20, profit=100 → ratio = 100/20 = 5.0
  Item 3: weight=30, profit=120 → ratio = 120/30 = 4.0
  Bag capacity = 50

  Take the best-ratio item first (Item 1, ratio=6.0): weight used=10, capacity left=40,
  profit gained=60.
  Next  best  (Item  2,  ratio=5.0):  weight  used=20,  capacity  left=20,  profit  gained=100
  (total=160).
  Next best (Item 3, ratio=4.0), but only 20 capacity remains and the item weighs 30: take
  only a fraction — 20/30 = 0.67. Profit gained = 120×0.67 = 80 (total=240).
  The bag is now full, and the total maximum profit = 240.

Time Complexity

Most of the time is spent sorting the items by ratio, which takes O(n log n). Filling the bag afterwards is a single O(n) pass. So the total time is O(n log n) — a fairly fast approach.

What the Program Does

  1. The user enters how many items there are, along with each item's weight and profit.
  2. The user enters the bag's capacity.
  3. The program computes each item's profit/weight ratio and sorts items best-ratio-first.
  4. Items are then placed into the bag one at a time — items that fit completely are marked "Fully taken", and the item that doesn't fully fit has its fraction marked "Fraction taken".
  5. The maximum total profit is printed at the end.
  6. The time taken (in seconds) is displayed.

In short: take the best value-for-weight item first, and if needed, take just a piece of the final item to fill the remaining capacity.

Viva questions

What is the Fractional Knapsack problem?

Given items with weights and profits and a bag of limited capacity, choose items, taking fractions if needed, to get the maximum total profit.

Which strategy does the program use?

The greedy method: sort items by profit/weight ratio, highest first, and fill the bag in that order.

What is the difference between fractional and 0/1 Knapsack?

In the fractional problem an item can be split. In the 0/1 problem an item is taken completely or not at all.

What is the time complexity?

O(n log n), because of the sorting step. The filling step is O(n).

Is the greedy method optimal here?

Yes. For the fractional knapsack, taking the best ratio first always gives the maximum profit.

Work out the sample: items (10, 60), (20, 100), (30, 120), capacity 50.

Ratios are 6, 5, 4. Take items 1 and 2 fully (weight 30, profit 160) and 20/30 of item 3 (profit 80). Total profit 240.

What is the greedy method?

An approach that makes the locally best choice at every step, hoping to reach the global optimum.

Why does the greedy method fail for 0/1 Knapsack?

Because items cannot be split, the best-ratio choice can leave unused capacity, so a different combination may give more profit.
