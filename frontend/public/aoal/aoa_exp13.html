Experiment 13: N-Queen's Problem using Backtracking

Aim: Implement N Queen's problem using Back Tracking.

Source code

This is the program from the lab manual, unchanged. Compile it with gcc aoa_exp13.c -o exp13 and run ./exp13 (on Windows with MinGW, exp13).

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int board[20];
int n;
int solutionCount = 0;
// Check if it is safe to place a queen at board[row] = col
int isSafe(int row, int col)
{
    int i;
    for(i = 0; i < row; i++)
    {
        if(board[i] == col || abs(board[i] - col) == abs(i - row))
        return 0;
    }
    return 1;
}
// Print one solution
void printSolution()
{
    int i, j;
    solutionCount++;
    printf("\nSolution %d:\n", solutionCount);
    for(i = 0; i < n; i++)
    {
        for(j = 0; j < n; j++)
        {
            if(board[i] == j)
            printf("Q ");
            else
            printf(". ");
        }
        printf("\n");
    }
}
// Solve using backtracking
void solveNQueen(int row)
{
    if(row == n)
    {
        printSolution();
        return;
    }
    int col;
    for(col = 0; col < n; col++)
    {
        if(isSafe(row, col))
        {
            board[row] = col;
            solveNQueen(row + 1);
            // Backtrack (implicit, next iteration overwrites board[row])
        }
    }
}
int main()
{
    clock_t start, end;
    double cpu_time_used;
    printf("Enter number of queens (N): ");
    scanf("%d", &n);
    // Start timing
    start = clock();
    solveNQueen(0);
    // End timing
    end = clock();
    cpu_time_used = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("\nTotal solutions for %d-Queens = %d\n", n, solutionCount);
    printf("\nTime Required = %f seconds\n", cpu_time_used);
    return 0;
}

Explanation (from the manual)

Concept

Given an N×N chessboard (e.g. 4×4), the goal is to place N queens on it so that no two queens attack each other. In chess, a queen can move in any direction — along the same row/column, or diagonally. So the condition is: no two queens may share the same row, the same column, or the same diagonal.

This is solved using Backtracking — a try-and-undo approach:

  1. Try placing a queen in some safe column of the current row.
  2. If that position is safe, move to the next row and try placing a queen there too.
  3. If no column in a row turns out to be safe, backtrack — remove the queen from the previous row and try a different column there instead.
  4. Repeat until all N queens are placed safely (a solution is found), or every possibility has been exhausted.

More than one solution can exist for a given N — the program finds and displays all valid solutions.

Worked Example

  For N=4, a 4×4 board has exactly 2 ways to place 4 queens so that none of them attack each
  other:

  Solution 1:
  . Q . .
  . . . Q
  Q . . .
  . . Q .

  Solution 2:
  . . Q .
  Q . . .
  . . . Q
  . Q . .

  Total solutions for 4-Queens = 2. (Checking both solutions confirms no two queens share a
  row, column, or diagonal.)

Time Complexity

The worst-case time complexity of the N-Queens problem is roughly O(N!), since a great many combinations may need to be tried. Backtracking speeds this up significantly, because as soon as a position is found to be "unsafe", that entire branch is abandoned immediately (without exploring it further) — saving a lot of unnecessary work.

What the Program Does

  1. The user is asked how many queens to place (N).
  2. The program tries placing queens row by row, checking safety at each step (the process above).
  3. Every complete valid solution found is printed as a board (Q = queen, . = empty square).
  4. This process continues until all possible solutions have been found.
  5. The total number of solutions is printed at the end.
  6. The time taken (in seconds) is displayed.

In short: place a queen in each row one at a time; if you get stuck (no safe column left), backtrack to the previous row's queen and try a different column, until a solution is found.

Viva questions

What is the N-Queens problem?

Place N queens on an N × N chessboard so that no two queens attack each other.

What is backtracking?

Building a solution step by step and going back (undoing the last choice) as soon as a choice cannot lead to a solution.

When is it safe to place a queen?

When no other queen is in the same column or on the same diagonal. One queen per row is already ensured by the program.

What does the isSafe function check?

It compares the new position with the queens already placed in earlier rows for the same column and for both diagonals.

How many solutions are there for 4 and 8 queens?

2 solutions for N = 4 and 92 for N = 8.

Is there a solution for N = 2 or N = 3?

No.

What is the time complexity?

About O(N!) in the worst case, though pruning reduces the work a lot in practice.

How are the queens stored?

In an array board[row] = col, so each row holds the column of its queen.
