Computer Graphics & Multimedia Lab, 5CS4-21 (Turbo C++)

Experiment 2: Plot a pixel in different colours

Aim: To plot a point (pixel) on the screen in different colours using graphics functions.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

void main()
{
    int gd = DETECT, gm, err;
    int c, x, y;
    char msg[40];

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    /* the pixels from the manual */
    putpixel(85, 35, GREEN);
    putpixel(30, 40, RED);
    putpixel(115, 50, YELLOW);
    putpixel(135, 50, CYAN);
    putpixel(45, 60, BLUE);
    putpixel(20, 100, WHITE);
    putpixel(200, 100, LIGHTBLUE);
    putpixel(150, 100, LIGHTGREEN);
    putpixel(200, 50, YELLOW);
    putpixel(120, 70, RED);

    /* a strip of pixels in every colour from 1 to 15 */
    for(c = 1; c <= 15; c++)
    {
        for(x = 0; x < 30; x++)
        {
            for(y = 0; y < 10; y++)
            {
                putpixel(100 + c * 30 + x, 200 + y, c);
            }
        }
    }

    outtextxy(100, 180, "Pixels in colours 1 to 15");

    /* read a pixel back with getpixel */
    c = getpixel(85, 35);
    sprintf(msg, "Colour of pixel (85,35) = %d", c);
    outtextxy(100, 300, msg);

    getch();
    closegraph();
}

The manual's Exp 2 plots only ten single pixels, which are hard to see, and has no viva questions. This version adds a visible colour strip, getpixel, and viva questions.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

Output

A graphics window opens. Ten small coloured dots appear near the top left, and below them a row of 15 coloured blocks (colours 1 to 15).
Text shown: Pixels in colours 1 to 15
Text shown: Colour of pixel (85,35) = 2
Press any key to close it.

Explanation

  1. putpixel(x, y, color) lights one pixel at column x and row y. (0, 0) is the top-left corner, x grows to the right and y grows downwards.
  2. The colour is a name like GREEN or a number from 0 to 15. BLACK is 0, BLUE 1, GREEN 2, CYAN 3, RED 4 and WHITE 15.
  3. A single pixel is tiny, so the program also plots a block of 30 x 10 pixels for each colour from 1 to 15. Colour 0 (black) would not show on the black background.
  4. getpixel(x, y) reads the colour of a pixel. Reading (85, 35) returns 2, which is GREEN.
  5. sprintf builds the message text in msg, and outtextxy prints it on the graphics screen. printf does not work well in graphics mode.

Viva questions

What is a pixel?

The smallest point on the screen that can be set to a colour. The screen is a grid of pixels.

What is the syntax of putpixel?

putpixel(int x, int y, int color).

What does getpixel do?

It returns the colour value of the pixel at (x, y).

How many colours can be used in this mode?

16 colours, numbered 0 (BLACK) to 15 (WHITE), in the usual 640 x 480 VGA mode.

What is the screen resolution?

The number of pixels across and down. The usual VGA mode here is 640 x 480. getmaxx() and getmaxy() return 639 and 479.

Where is the origin (0, 0)?

At the top-left corner of the screen. y increases downwards.

Why do we use getch() before closegraph()?

To keep the picture on the screen until a key is pressed. Without it the window closes at once.

What is a frame buffer?

The memory that holds the colour of every pixel. Plotting a pixel changes its value in the buffer, and the display shows the buffer.
