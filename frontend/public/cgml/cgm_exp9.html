Experiment 9: Boundary fill algorithm

Aim: To implement the boundary fill algorithm for filling a rectangle with a given colour.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

extern unsigned _stklen = 40000U;

void boundaryfill4(int x, int y, int fillcol, int bordercol)
{
    int cur;
    cur = getpixel(x, y);
    if(cur != bordercol && cur != fillcol)
    {
        putpixel(x, y, fillcol);
        boundaryfill4(x + 1, y, fillcol, bordercol);
        boundaryfill4(x - 1, y, fillcol, bordercol);
        boundaryfill4(x, y + 1, fillcol, bordercol);
        boundaryfill4(x, y - 1, fillcol, bordercol);
    }
}

void main()
{
    int gd = DETECT, gm, err;
    int col;

    clrscr();
    printf("Enter fill colour (1 to 14): ");
    scanf("%d", &col);
    if(col < 1 || col > 14)
    {
        printf("Colour must be between 1 and 14");
        getch();
        exit(0);
    }

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    setcolor(WHITE);
    rectangle(100, 100, 160, 140);

    boundaryfill4(130, 120, col, WHITE);

    getch();
    closegraph();
}

The manual's Exp 9 uses the new graphics.h library for modern compilers and does not run under Turbo C. This version is written for Turbo C++.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

The fill is recursive. Turbo C gives only a 4 KB stack by default, which overflows on thousands of pixels, so the program raises it with extern unsigned _stklen = 40000U;. Keep the rectangle small as shown.

Output

Enter fill colour (1 to 14): 2
(a graphics window opens, a white rectangle is drawn, and its inside is filled with green, colour 2)
Press any key to close it.

Explanation

  1. Idea: Start from a seed pixel inside the shape and keep painting the neighbouring pixels until the boundary colour is reached. The inside may have any colour, but the border must be a single colour.
  2. boundaryfill4 reads the colour of the pixel. If it is not the boundary colour and not already the fill colour, it paints it and calls itself for the right, left, down and up neighbours (4-connected).
  3. The test cur != fillcol stops the program from visiting a pixel again and going on forever.
  4. In main the rectangle is drawn in white, and white is passed as the boundary colour. The fill starts at (130, 120), which is inside the rectangle.
  5. The fill colour is limited to 1 to 14, because 15 is the white boundary and 0 is the background.
  6. Difference from flood fill: flood fill replaces one old interior colour, while boundary fill stops at a boundary colour.

Viva questions

What is a fill algorithm?

A method for colouring all the pixels inside a closed region of the screen.

What are the approaches for filling?

Scan-line fill and seed fill (boundary fill and flood fill).

What is the boundary fill algorithm?

A seed fill that starts inside a region and paints pixels until it reaches pixels of the boundary colour.

What are the steps of the boundary fill algorithm?

1) Choose a seed pixel inside the region. 2) If the pixel is neither the boundary colour nor the fill colour, paint it. 3) Repeat for its 4 (or 8) neighbours. 4) Stop when every path ends at the boundary.

What is a seed pixel?

The starting pixel inside the region from where the filling begins.

What is the 4-connected approach?

Each pixel is connected to its left, right, top and bottom neighbours.

What is the 8-connected approach?

Each pixel is connected to the four neighbours and also the four diagonal neighbours.

What is the difference between the 4-connected and 8-connected approaches?

8-connected fill reaches diagonal pixels and can fill complex shapes, but it can leak through a boundary that is connected only diagonally. 4-connected cannot leak that way.

What are the merits of the boundary fill algorithm?

It is simple, and the inside of the region can contain several colours because only the boundary colour matters.

What are the demerits of the boundary fill algorithm?

The whole boundary must be a single colour, a gap in the boundary makes the colour leak out, and recursion can overflow the stack on large regions.
