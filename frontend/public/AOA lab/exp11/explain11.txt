Longest Common Subsequence (LCS) kya hai?

Socho tere paas do strings hain, jaise "AGGTAB" aur "GXTXAYB". Tujhe unme se sabse lambi "common subsequence" dhundni hai.

"Subsequence" ka matlab hai — string ke letters ko usi order mein rakhte hue, beech-beech ke kuch letters skip kar dena (lekin order badalna nahi hai). Jaise "AGGTAB" ki ek subsequence ho sakti hai "GTB" (G,T,B letters skip karke liye, lekin order same rakha).

"Common Subsequence" ka matlab hai — aisi subsequence jo DONO strings mein present ho. Aur humein sabse LAMBI (longest) waali chahiye.

Ye problem bhi Dynamic Programming se solve hoti hai — hum ek table banate hain jisme dono strings ke har character-pair ko compare karte hain:
- Agar dono strings ka current character SAME hai -> to ye character LCS ka hissa banega, aur pichle answer mein +1 kar do.
- Agar DIFFERENT hai -> to dono possibilities check karo (ek character chhod ke dekho, dusra character chhod ke dekho), jo bhi zyada lamba answer de wahi rakho.


Chhota example:

String X = "AGGTAB"
String Y = "GXTXAYB"

DP table character by character fill hota hai, aur jab bhi match milta hai wahan se LCS letters collect hote hain.

Match hone waale characters (order mein): G, T, A, B

To LCS = "GTAB"  (length = 4)

Check karke dekho: "GTAB" dono strings mein order maintain karte hue milta hai:
X = A-G-G-T-A-B  (G,T,A,B is order mein hain)
Y = G-X-T-X-A-Y-B (G,T,A,B yahan bhi isi order mein hain, beech mein X,X,Y skip)


Speed ka mamla:

LCS ka time complexity O(m x n) hai, jahan m aur n dono strings ki lengths hain. Har character-pair ko ek baar table mein check karna padta hai, isliye ye kaafi efficient approach hai brute-force (saari subsequences banake check karna, jo bahut slow hota) ke comparison mein.


Tera program kya karta hai:

1. Tujhse do strings enter karwayi jaati hain.
2. Program ek DP table banata hai jisme dono strings ke characters compare hote hain (upar wala match/no-match process).
3. Table se LCS ki length nikal li jaati hai, aur wapas trace karke actual LCS string bhi bana li jaati hai.
4. Length aur actual LCS string dono print hote hain.
5. Calculation mein kitna time laga, wo bhi dikhaya jaata hai.

Bas itna hi — dono strings ke characters compare karo, match milne pe LCS mein jodo, na milne pe best possibility choose karo table ke through.
