COMPILER DESIGN LAB - ALL COMMANDS (GCC, FLEX, LEX, YACC)
Lines starting with # are notes. Type only the command lines.


==================================================
PART 1: INSTALL GCC ON WINDOWS (MSYS2)
==================================================

# Step 1: Download the installer from https://www.msys2.org and install to C:\msys64
# Step 2: Open "MSYS2 UCRT64" from the Start menu and run:

pacman -S mingw-w64-ucrt-x86_64-gcc

# Step 3: Add this folder to PATH (Environment Variables > Path > Edit > New):

C:\msys64\ucrt64\bin

# Step 4: Close all Command Prompt windows, open a new one, and check:

gcc --version


==================================================
PART 2: DOWNLOAD FLEX AND BISON ON WINDOWS (GitHub)
==================================================

# Step 1: Open https://github.com/lexxmark/winflexbison/releases
# Step 2: Download the file named win_flex_bison-2.5.25.zip
#         (do NOT download the "Source code" files)
# Step 3: Extract the zip into C:\flex
#         It contains win_flex.exe and win_bison.exe
# Step 4: Save all your .l and .y files and input files (test.txt, test.c) in C:\flex
# Step 5: Open Command Prompt in that folder
#         (click the File Explorer address bar, type cmd, press Enter)
# Step 6: Check that the tools work:

win_flex --version
win_bison --version

PART 3: RUN A NORMAL C PROGRAM WITH GCC
==================================================

# Replace hello with your file name

gcc hello.c -o hello
hello

# Note: Turbo C++ programs (Exp 2 to 6) use conio.h, clrscr() and getch().


==================================================
PART 3B: MINIMAL CHANGE TO RUN TURBO C++ PROGRAMS (Exp 2 to 6) WITH GCC
==================================================

# Add these two lines right after the #include lines. Change nothing else.

#include<stdlib.h>
#define clrscr() system("cls")

# getch() works as it is, because MinGW's conio.h has it.
# Warnings about void main() and gets() can be ignored.
# Save the file as .c (NOT .cpp), or void main() becomes an error.

gcc exp2.c -o exp2
exp2

# If you get an error that gets is not declared, compile with:

gcc -std=gnu99 exp2.c -o exp2

# On Linux/WSL, conio.h does not exist: delete the conio.h include and the getch() lines instead.

==================================================
PART 5: RUN YACC PROGRAMS (Exp 10, 11, 12) ON WINDOWS
==================================================

# IMPORTANT: bison must run FIRST, because the .l file includes y.tab.h
# Pattern: win_bison -y -d FILE.y -> win_flex --wincompat FILE.l -> gcc -w y.tab.c lex.yy.c -o NAME -> NAME
# (This Windows version is adapted from the Linux commands on the website.)

# ---- Exp 10: a^n b^n ----
win_bison -y -d exp10.y
win_flex --wincompat exp10.l
gcc -w y.tab.c lex.yy.c -o exp10
exp10

# ---- Exp 11: Arithmetic expression ----
win_bison -y -d exp11.y
win_flex --wincompat exp11.l
gcc -w y.tab.c lex.yy.c -o exp11
exp11

# ---- Exp 12: a^n b^n c^m d^m ----
win_bison -y -d exp12.y
win_flex --wincompat exp12.l
gcc -w y.tab.c lex.yy.c -o exp12
exp12


==================================================
PART 6: LINUX / WSL VERSION (as given on the website)
==================================================

# Install once:

sudo apt install flex bison gcc

# Run LEX program (example):

lex exp8.l
cc lex.yy.c
./a.out

# Run YACC program (Exp 10, 11, 12) - yacc must run first:

yacc -d exp10.y
lex exp10.l
cc y.tab.c lex.yy.c
./a.out

# For Exp 11, use exp11.y / exp11.l. For Exp 12, use exp12.y / exp12.l.


==================================================
QUICK FIXES
==================================================

# "gcc is not recognised"        -> PATH entry is wrong. Recheck C:\msys64\ucrt64\bin and reopen Command Prompt.
# "win_flex is not recognised"   -> Run the command from C:\flex or add C:\flex to PATH.
# "y.tab.h not found"            -> Run win_bison -y -d first, before win_flex.
# Warning "fileno redefined"     -> Harmless, ignore it.
# Input file not found           -> Keep test.txt / test.c in the same folder as the .exe.
