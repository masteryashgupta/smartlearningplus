Strassen's Matrix Multiplication kya hai?

Socho tere paas do 2x2 matrices hain:
A = [1 2]        B = [5 6]
    [3 4]            [7 8]

Tujhe A x B (matrix multiplication) nikalna hai.

Normal (school wale) tarike se 2x2 matrix multiply karne mein 8 multiplications lagti hain (har cell ke liye 2 multiply, 4 cells). Strassen naam ke scientist ne ek clever trick nikaali jisse sirf 7 multiplications mein hi kaam ho jaata hai — 1 multiplication kam! Chhote matrix ke liye ye farak zyada mahsoos nahi hota, lekin bade matrices (jaise 1000x1000) ke liye ye technique multiplication ka time kaafi kam kar deti hai.

Trick ye hai: A aur B ke elements ko combine karke 7 alag "helper values" (M1 se M7 tak) banate hain, aur fir sirf inhi 7 values ko add/subtract karke final result nikal lete hain — normal multiplication ki tarah har cell ke liye alag se multiply nahi karna padta.


Chhota example:

A = [1 2]        B = [5 6]
    [3 4]            [7 8]

7 helper values (M1 se M7):
M1 = (A00+A11) x (B00+B11) = (1+4) x (5+8) = 5 x 13 = 65
M2 = (A10+A11) x B00       = (3+4) x 5     = 7 x 5  = 35
M3 = A00 x (B01-B11)       = 1 x (6-8)     = 1 x -2 = -2
M4 = A11 x (B10-B00)       = 4 x (7-5)     = 4 x 2  = 8
M5 = (A00+A01) x B11       = (1+2) x 8     = 3 x 8  = 24
M6 = (A10-A00) x (B00+B01) = (3-1) x (5+6) = 2 x 11 = 22
M7 = (A01-A11) x (B10+B11) = (2-4) x (7+8) = -2 x 15 = -30

Ab final result matrix C banao inhi values se:
C00 = M1+M4-M5+M7 = 65+8-24-30 = 19
C01 = M3+M5       = -2+24      = 22
C10 = M2+M4       = 35+8       = 43
C11 = M1-M2+M3+M6 = 65-35-2+22 = 50

Result: C = [19 22]
            [43 50]

Ye bilkul wahi answer hai jo normal multiplication se aata (1x5+2x7=19, 1x6+2x8=22, waghera) — bas raasta alag tha, multiplications kam lagi.


Speed ka mamla:

Normal matrix multiplication O(n^3) time leta hai bade matrices ke liye. Strassen ka method thoda better hai (O(n^2.807)) — ye farak chhote 2x2 matrix mein dikhega nahi (waise bhi utna hi fast lagega), lekin bahut bade matrices (jaise AI/ML mein use hone wale) ke liye ye technique real mein time bachati hai.


Tera program kya karta hai:

1. Tujhse dono matrices A aur B ke elements enter karwaye jaate hain (2x2, total 4-4 numbers).
2. Program upar wali 7 M-values calculate karta hai.
3. Un values se final result matrix C banata hai.
4. A, B, aur result C teeno print kar deta hai.
5. Calculation mein kitna time laga (seconds mein), wo bhi dikhaya jaata hai.

Bas itna hi — 7 clever helper values banao (M1-M7), unhe combine karke seedha result nikaal lo, bina har cell ke liye alag se multiply kiye.
