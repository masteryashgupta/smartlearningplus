01. Introduction to 2D Transformations HIGH
What is a geometric transformation and why do we need it?
Definition

A 2D Transformation is a mathematical operation that changes the position, orientation, size, or shape of a graphical object (point, line, or polygon) by altering its coordinates according to a defined rule, usually expressed as a matrix.

🇮🇳 Hinglish Explanation
Transformation ka matlab hai ek object ki position, size ya orientation ko change karna without redrawing it from scratch. Jaise ek photo ko zoom karna (scaling), ghumana (rotation) ya move karna (translation) — sab kuch coordinate ke upar matrix multiply karke hota hai. Yahi computer graphics ka core concept hai.

Basic Types of Transformations

TransformationEffectReal World Example
TranslationMoves object — shifts positionDragging an icon on screen
RotationRotates object about a pointRotating a steering wheel
ScalingChanges size of objectZoom in/out of an image
ReflectionMirror image about an axisMirror reflection
ShearingSlants the shapeItalic text effect
Why Matrix Form?

All these transformations can be represented as matrix multiplication of the form P' = P·T, which allows transformations to be combined (composited) easily by simply multiplying matrices together — instead of applying each transformation step by step.

02. Translation HIGH

Definition

Translation is the transformation that repositions an object along a straight-line path from one location to another, by adding translation distances tₓ and t_y to the original coordinates.

🇮🇳 Hinglish
Translation matlab object ko bina ghumaye ya size badle bas ek jagah se doosri jagah shift karna. Point (x,y) ko tx aur ty add karke naya point (x',y') milta hai.
x' = x + tₓ
y' = y + t_y

In Matrix Form: P' = P + T    where T = [tₓ, t_y]

Fig 1: Translation of a Triangle

Example

Point P(2,3) translated by tₓ=5, t_y=1 → P'(2+5, 3+1) = P'(7,4)

03. Rotation HIGH

Definition

Rotation repositions an object along a circular path in the xy-plane, about a pivot point, through a specified rotation angle θ (counter-clockwise positive).

🇮🇳 Hinglish
Rotation mein object ek fixed point (pivot) ke around ghumta hai by angle θ. Agar pivot origin ho, toh formula simple hota hai using sin/cos.

Rotation about Origin

x' = x·cosθ − y·sinθ
y' = x·sinθ + y·cosθ

Derivation (Important for 10-Mark)

  1. Let point P(x,y) be at distance r from origin, at angle φ → x = r·cosφ, y = r·sinφ
  2. After rotating by θ, new angle = φ+θ → x' = r·cos(φ+θ), y' = r·sin(φ+θ)
  3. Expand using trig identities: cos(φ+θ)=cosφcosθ−sinφsinθ, sin(φ+θ)=sinφcosθ+cosφsinθ
  4. Substitute r·cosφ=x, r·sinφ=y → x' = x·cosθ − y·sinθ,   y' = x·sinθ + y·cosθ

Rotation about an Arbitrary Pivot Point (xp, yp)

x' = xp + (x−xp)cosθ − (y−yp)sinθ
y' = yp + (x−xp)sinθ + (y−yp)cosθ
⚠ Important Note

For pivot rotation: Translate pivot to origin → Rotate → Translate back. This 3-step combination is a classic RTU exam question (composite transformation).

Fig 2: Rotation of Point P by angle θ about Origin

Example

Rotate point P(1,0) by θ=90° about origin:
x' = 1·cos90 − 0·sin90 = 0  |  y' = 1·sin90 + 0·cos90 = 1 → P'(0,1) ✓ (matches intuition)

04. Scaling HIGH

Definition

Scaling alters the size of an object by multiplying the coordinate values (x,y) by scaling factors Sₓ and S_y along the x and y directions respectively.

x' = x · Sₓ
y' = y · S_y
🇮🇳 Hinglish
Scaling se object ka size badhta ya ghatata hai. Agar Sx=Sy ho toh uniform scaling (same shape, only size change), agar Sx≠Sy ho toh differential scaling (shape distort ho jata hai).
ConditionTypeEffect
Sₓ = S_y > 1Uniform EnlargementObject enlarges proportionally
Sₓ = S_y < 1Uniform ReductionObject shrinks proportionally
Sₓ ≠ S_yDifferential ScalingShape distorted (stretched/squeezed)
Sₓ = S_y = 1IdentityNo change
⚠ Important Note

Scaling about origin moves the object's position too (unless centroid is at origin). To scale about a fixed point (xf,yf): Translate fixed point to origin → Scale → Translate back.

x' = xf + (x−xf)·Sₓ
y' = yf + (y−yf)·S_y
Example

Point P(2,3) scaled with Sₓ=2, S_y=3 about origin → P'(4,9)

05. Matrix Representation & Homogeneous Coordinates HIGH

Definition

Homogeneous Coordinates represent a 2D point (x,y) as a 3-tuple (x,y,1), allowing translation — which is normally an addition operation — to be expressed as matrix multiplication, just like rotation and scaling. This unifies all transformations into a single 3×3 matrix form.

🇮🇳 Hinglish
Problem yeh thi ki translation addition hota hai jabki rotation/scaling multiplication. Inko ek saath combine (composite) karna mushkil tha. Solution: har point mein ek extra coordinate "1" add karo (x,y,1) — ab translation bhi matrix multiplication ban jaata hai. Isse saari transformations ek single 3x3 matrix se ho jaati hain!

Standard Homogeneous Transformation Matrices

Translation: T(tx,ty) =
⎡ 1  0  tx ⎤
⎢ 0  1  ty ⎥
⎣ 0  0  1  ⎦

Rotation: R(θ) =
⎡ cosθ  −sinθ  0 ⎤
⎢ sinθ   cosθ  0 ⎥
⎣ 0      0     1 ⎦

Scaling: S(sx,sy) =
⎡ sx  0   0 ⎤
⎢ 0   sy  0 ⎥
⎣ 0   0   1 ⎦

A point in homogeneous form: P = [x  y  1]ᵗ   and transformation applied as: P' = M · P

Example

Translate P(3,4) by (tx=2, ty=5) using matrix form:

P' = ⎡1 0 2⎤ ⎡3⎤   ⎡3+2⎤   ⎡5⎤
    ⎢0 1 5⎥ ⎢4⎥ = ⎢4+5⎥ = ⎢9⎥
    ⎣0 0 1⎦ ⎣1⎦   ⎣1⎦    ⎣1⎦

Result: P'(5,9)

06. Composite Transformations HIGH

Definition

Composite Transformation is a sequence of two or more transformations combined into one single transformation by multiplying their individual matrices, producing one resultant matrix that is applied once to the object.

🇮🇳 Hinglish
Jab multiple transformations ek saath apply karni ho (jaise rotate then translate), toh har baar alag se calculation karne ke jagah, saari matrices ko multiply karke ek single "composite matrix" bana lo. Order matters — matrix multiplication commutative nahi hoti!
⚠ Important — Order Matters!

T₁·T₂ ≠ T₂·T₁ in general. Always apply transformations in the order specified by the problem. Matrices are multiplied in reverse order of application when using column-vector convention: P' = Tₙ·...·T₂·T₁·P

Classic Example: Rotation about Arbitrary Pivot Point (xp, yp)

  1. Step 1: Translate pivot point to origin → T(−xp, −yp)
  2. Step 2: Rotate about origin by θ → R(θ)
  3. Step 3: Translate back to original pivot position → T(xp, yp)
  4. Composite Matrix: M = T(xp,yp) · R(θ) · T(−xp,−yp)

Fig 3: Composite Transformation Pipeline — Rotation about Pivot

Worked Example

Rotate triangle by 90° about pivot point (2,2). Take vertex P(4,2):

Step 1: Translate: (4−2, 2−2) = (2,0)

Step 2: Rotate 90°: x'=2·cos90−0·sin90=0, y'=2·sin90+0·cos90=2 → (0,2)

Step 3: Translate back: (0+2, 2+2) = (2,4)

Reflection produces a mirror image of an object with respect to an axis of reflection (a line), by rotating the object 180° about that reflection axis.

08. Shearing MEDIUM

Definition

Shearing is a transformation that distorts the shape of an object such that the transformed shape appears as if the object were composed of internal layers slid over one another — used to produce slant or skew effects.

🇮🇳 Hinglish
Shearing se object slant ho jaata hai — jaise italic text. X-shear mein x-coordinate y ke proportion mein shift hota hai, y-shear mein opposite.
Shear TypeFormulaMatrix
X-Shear (Shx)x' = x + Shx·y,   y' = y[1,Shx,0; 0,1,0; 0,0,1]
Y-Shear (Shy)x' = x,   y' = y + Shy·x[1,0,0; Shy,1,0; 0,0,1]
Example

Shear unit square with Shx=2 along x-direction. Point (0,1): x'=0+2·1=2, y'=1 → (2,1) — square becomes a parallelogram.

09. Viewing Pipeline & Coordinate Systems HIGH

Definition

The 2D Viewing Pipeline is the sequence of coordinate transformations that converts a scene defined in world coordinates into a displayed image on a physical output device, passing through window, normalized, and viewport/device coordinate systems.

🇮🇳 Hinglish
Viewing pipeline ek series of steps hai jo world coordinates (jahan object define hua) ko screen coordinates (jahan dikhna hai) mein convert karta hai. Beech mein clipping bhi hoti hai jo window ke bahar ki cheezein hata deti hai.

10. Window-to-Viewport Transformation HIGH

Definition

The Window-to-Viewport Transformation is the mapping that converts a point's position in the world-coordinate window into a corresponding position in the viewport on the display device, preserving the relative position of the point within both rectangles.

🇮🇳 Hinglish
Window world coordinates mein hai, viewport screen coordinates mein. Hume window ke point ko proportionally viewport mein map karna hai — jaise ek photo ko crop karke screen ke specific area mein fit karna.
Given Window: (xwmin,ywmin) to (xwmax,ywmax)
Given Viewport: (xvmin,yvmin) to (xvmax,yvmax)

Scale factors:
Sx = (xvmax−xvmin) / (xwmax−xwmin)
Sy = (yvmax−yvmin) / (ywmax−ywmin)

xv = xvmin + (xw − xwmin) · Sx
yv = yvmin + (yw − ywmin) · Sy
  1. Translate window to origin: (xw − xwmin), (yw − ywmin)
  2. Scale to viewport size using Sx, Sy
  3. Translate to viewport position: add xvmin, yvmin
Example

Window: (0,0) to (10,10). Viewport: (0,0) to (400,300). Map point (5,5):

Sx = 400/10 = 40, Sy = 300/10 = 30

xv = 0 + (5−0)·40 = 200,   yv = 0 + (5−0)·30 = 150 → (200,150)

11. Clipping — Concepts & Point Clipping HIGH

Definition

Clipping is the process of identifying and saving only the portion of a picture that lies within a specified region (clip window), and discarding everything outside it, so that only visible parts are processed/displayed.

🇮🇳 Hinglish
Clipping ka matlab hai screen ke bahar wala extra content cut karna. Jo window ke bahar hai usse hata do, jo andar hai usse rakho — taki rendering fast ho aur sirf visible part process ho.

Point Clipping

A point P(x,y) is inside the clip window if it satisfies all four conditions:

xwmin ≤ x ≤ xwmax    AND    ywmin ≤ y ≤ ywmax

If any condition fails → point is clipped (rejected).

Types of Clipping

TypeDescription
Point ClippingCheck if a single point is within window
Line ClippingDetermine and keep only the visible segment of a line
Polygon ClippingClip a closed boundary, possibly producing a new vertex list
Curve/Text ClippingClip curves or character outlines against window

12. Cohen–Sutherland Line Clipping Algorithm HIGH

Definition

The Cohen-Sutherland Algorithm is a line-clipping technique that uses a 4-bit region code (outcode) assigned to each line endpoint, based on its position relative to the clip window's boundaries, to quickly accept, reject, or further process lines.

🇮🇳 Hinglish
Yeh algorithm screen ko 9 regions mein divide karta hai (window + 8 outside regions). Har point ko 4-bit code (Top,Bottom,Right,Left) milta hai. Codes ki AND/OR operation se pata chalta hai line ko trivially accept/reject karna hai ya intersection calculate karni hai.

Region Codes (TBRL)

Fig 6: 9-Region Outcodes (bits: Top,Bottom,Right,Left)

Bit 1 (Left): x < xmin → set to 1
Bit 2 (Right): x > xmax → set to 1
Bit 3 (Bottom): y < ymin → set to 1
Bit 4 (Top): y > ymax → set to 1

Algorithm Steps

  1. Compute outcode for both endpoints P1, P2
  2. Trivial Accept: if (code1 OR code2) == 0000 → both points inside → draw line as-is
  3. Trivial Reject: if (code1 AND code2) ≠ 0000 → both points share an outside region → discard line entirely
  4. Otherwise: pick an endpoint with non-zero code, find intersection with the corresponding boundary using line equation, replace that endpoint with intersection point
  5. Recompute outcode for the new point and repeat from step 2 until accepted or rejected
Tip

Use parametric line equations to find intersection: for boundary x=xmin → y = y1 + (y2−y1)·(xmin−x1)/(x2−x1). Similarly for other boundaries.

Worked Example

Window: (10,10) to (50,50). Line from P1(5,40) to P2(30,60):

P1 outcode: x=5<10 → Left=1; others 0 → 0001

P2 outcode: y=60>50 → Top=1; others 0 → 1000

AND = 0000 → not trivial reject. OR ≠ 0000 → not trivial accept.

Clip against Left boundary (x=10) for P1: y = 40+(60−40)·(10−5)/(30−5) = 40+20·0.2=44 → new P1(10,44)

Clip against Top boundary (y=50) for P2: x = 5+(30−5)·(50−40)/(60−40)= 5+25·0.5=17.5 → new P2(17.5,50)

Final visible segment: (10,44) to (17.5,50)

13. Liang–Barsky Line Clipping Algorithm HIGH

Definition

The Liang-Barsky Algorithm is a parametric line-clipping method that represents the line as P(u) = P1 + u·(P2−P1), 0≤u≤1, and computes the range of parameter u for which the line lies inside the clip window, using a set of inequalities — making it computationally faster than Cohen-Sutherland.

🇮🇳 Hinglish
Yeh algorithm line ko parametric form mein represent karta hai aur har boundary ke liye u ki valid range nikalta hai. Final visible segment uska intersection hota hai jahan saari ranges overlap karti hain. Yeh Cohen-Sutherland se fast hai kyunki repeated intersection calculation nahi hoti.
Line: x = x1 + u·Δx,   y = y1 + u·Δy,   where Δx=x2−x1, Δy=y2−y1, 0≤u≤1

Boundary conditions (parametric form):   u·pk ≤ qk   for k = 1,2,3,4
p1=−Δx, q1=x1−xmin  (Left)  |  p2=Δx, q2=xmax−x1  (Right)
p3=−Δy, q3=y1−ymin  (Bottom)  |  p4=Δy, q4=ymax−y1  (Top)

Algorithm Steps

  1. Calculate Δx, Δy and the four pk, qk values
  2. For each k: if pk = 0 and qk < 0 → line parallel and outside → reject entirely
  3. If pk ≠ 0: compute r = qk/pk. If pk < 0 → update u1 = max(u1, r) (entering); if pk > 0 → update u2 = min(u2, r) (leaving)
  4. If at any point u1 > u2 → line is completely outside → reject
  5. Final visible line: from u1 to u2 using x=x1+u·Δx, y=y1+u·Δy
FeatureCohen-SutherlandLiang-Barsky
ApproachRegion codes (outcodes)Parametric equations
SpeedSlower (multiple intersection calcs)Faster (single pass)
Clipping BoundaryRectangular onlyRectangular only
Intersection CalculationRepeated per boundaryOnce using parameter u
Example

Window (10,10)-(50,50). Line P1(15,15) to P2(60,60): Δx=45, Δy=45

p1=-45,q1=5 → r=−0.111 (pk<0→u1) | p2=45,q2=35 → r=0.778(pk>0→u2)

p3=-45,q3=5 → r=−0.111(pk<0→u1) | p4=45,q4=35 → r=0.778(pk>0→u2)

u1 = max(0,−0.111,−0.111) = 0,   u2 = min(1,0.778,0.778) = 0.778

Visible segment from u=0 to u=0.778 → P1'(15,15) to P2'(15+45·0.778, 15+45·0.778) = (50,50)

14. NLN (Nicholl-Lee-Nicholl) Line Clipping MEDIUM

Definition

The NLN Algorithm creates more regions around the clip window than Cohen-Sutherland (depending on the position of endpoint P1), and uses these regions along with visibility of edges/diagonals from P1 to determine clip boundaries — avoiding redundant intersection calculations and multiple clipping passes.

🇮🇳 Hinglish
NLN algorithm Cohen-Sutherland aur Liang-Barsky se zyada efficient hai kyunki yeh sirf ek hi intersection calculation karta hai per line, multiple regions banakar (P1 ki position ke according) aur P2 kahan padta hai usse directly clip line decide ho jaati hai.

Key Idea

  • Position of P1 relative to window is checked first (9 possible positions, same as Cohen-Sutherland regions)
  • Window edges and diagonals through P1 divide the plane into multiple sub-regions
  • Depending on which sub-region P2 lies in, the correct clip edge is selected directly — no trial-and-error as in Cohen-Sutherland
  • Only ONE intersection calculation needed (compared to possibly several in C-S)
AlgorithmIntersection CalculationsComplexity
Cohen-SutherlandMultiple (iterative)Simple to implement
Liang-BarskyOne per boundary (4 total)Moderate
NLNMinimum (often just 1)Complex (more case analysis)
Exam Tip

NLN is mostly asked as a theory/short-note question (5 marks) — detailed numerical problems are rare in RTU papers. Focus on Cohen-Sutherland and Liang-Barsky numericals for 10-mark questions.

15. Polygon Clipping — Sutherland-Hodgman Algorithm HIGH

Definition

Polygon Clipping clips a closed polygon boundary against a clip window, producing a new (possibly different-vertex-count) polygon. The Sutherland-Hodgman algorithm clips the polygon successively against each edge of the (convex) clip window, one edge at a time.

🇮🇳 Hinglish
Polygon clipping mein line clipping se zyada complexity hoti hai kyunki naye vertices generate ho sakte hain. Sutherland-Hodgman algorithm polygon ko clip window ke har edge ke against ek-ek baar clip karta hai — output of one edge becomes input for the next edge.

Algorithm Steps (For Each Clip Edge)

  1. For each edge of the clip window (left, right, bottom, top), process all polygon edges one at a time
  2. For each polygon edge (S → P): classify both S and P as inside or outside the current clip boundary
  3. If both inside → output P
  4. If S inside, P outside → output intersection point only
  5. If S outside, P inside → output intersection point AND P
  6. If both outside → output nothing
  7. The output vertex list becomes the input for clipping against the next window edge
CaseSPOutput
1InsideInsideP
2InsideOutsideIntersection point
3OutsideInsideIntersection point, P
4OutsideOutsideNothing

Fig 7: Polygon Clipping using Sutherland-Hodgman

⚠ Important Note

Sutherland-Hodgman works correctly only for convex clip windows. The subject polygon can be convex or concave, but for concave clip windows the algorithm may produce extraneous edges (needs Weiler-Atherton algorithm instead, which is beyond this unit).

Concept Example

Clipping a pentagon against a rectangular window: process edges of the pentagon against left boundary first (generating an intermediate vertex list), then that list is clipped against right boundary, then top, then bottom — each pass possibly adding intersection vertices and removing outside vertices.

Q1 · 10 MARKS
10 MARKS
Derive the transformation matrix for rotation of a point about an arbitrary pivot point. Explain with a suitable example.

Concept: Rotation about an arbitrary point (xp,yp) requires composite transformation since the basic rotation formula works only about origin.

Steps (Derivation):

  1. Translate pivot (xp,yp) to origin: T(−xp,−yp)
  2. Rotate about origin by θ: R(θ)
  3. Translate back to (xp,yp): T(xp,yp)
Composite Matrix M = T(xp,yp) · R(θ) · T(−xp,−yp)

Final equations:
x' = xp + (x−xp)cosθ − (y−yp)sinθ
y' = yp + (x−xp)sinθ + (y−yp)cosθ

Example: Rotate P(4,2) by 90° about pivot (2,2):

x' = 2+(4−2)cos90−(2−2)sin90 = 2+0−0 = 2

y' = 2+(4−2)sin90+(2−2)cos90 = 2+2+0 = 4 → P'(2,4)

Q2 · 10 MARKS
10 MARKS
Explain the Cohen-Sutherland line clipping algorithm in detail. Apply it to clip a line from P1(40,15) to P2(75,45) against a window with corners (20,10) and (60,40).

Theory: Region codes (4-bit outcodes: Top,Bottom,Right,Left) divide the plane into 9 regions. Trivial accept (both codes=0000), trivial reject (AND≠0000), else clip iteratively against boundaries.

Numerical: Window: xmin=20,xmax=60,ymin=10,ymax=40

P1(40,15): inside all → code 0000

P2(75,45): x=75>60→Right=1; y=45>40→Top=1 → code 1010

AND(0000,1010)=0000 → not reject. OR≠0000 → not trivial accept.

Clip P2 against Top (y=40): x = 40+(75−40)·(40−15)/(45−15) = 40+35·0.833=69.17 → still >60

Now clip against Right (x=60): y = 15+(45−15)·(60−40)/(75−40)=15+30·0.571=32.14 → new P2'(60,32.14)

Recheck P2'(60,32.14): inside window → code 0000

Final visible line: P1(40,15) to P2'(60,32.14)

Q4 · 10 MARKS
10 MARKS
Explain the Sutherland-Hodgman polygon clipping algorithm with all four edge cases and a suitable diagram.

Theory: Polygon is clipped successively against each of the 4 window edges (left, right, bottom, top). For each edge, every polygon edge (S→P) is checked using 4 cases:

CaseSPAction
1InInOutput P
2InOutOutput intersection
3OutInOutput intersection & P
4OutOutOutput nothing

The output vertex list of clipping against one edge becomes the input list for the next edge. After processing all 4 edges, the final list is the clipped polygon. Algorithm works correctly for convex clip regions.

Q6 · 5 MARKS
5 MARKS
What are homogeneous coordinates? Why are they used in 2D transformations?

Homogeneous coordinates represent a 2D point (x,y) as (x,y,1) — a 3-element vector. They are used because translation is an additive operation while rotation/scaling are multiplicative; representing all of them as 3×3 matrices allows uniform matrix multiplication for every transformation, making it possible to combine multiple transformations into a single composite matrix.

Write short note on Shearing transformation with its types.

Shearing slants the shape of an object. Two types:

X-Shear: x'=x+Shx·y, y'=y — shifts x-coordinates proportional to y

Y-Shear: x'=x, y'=y+Shy·x — shifts y-coordinates proportional to x

Used for effects like italic text or skewing shapes for animation.

5 MARKS
What is point clipping? State the conditions for a point to be inside a rectangular clip window.

Point clipping checks whether a point lies inside or outside a given clip window. A point P(x,y) is inside the window (xmin,ymin)-(xmax,ymax) if:

xmin ≤ x ≤ xmax  AND  ymin ≤ y ≤ ymax

If any inequality fails, the point lies outside and is clipped (rejected/not displayed).

5 MARKS
Write a short note on the NLN (Nicholl-Lee-Nicholl) line clipping algorithm.

NLN improves on Cohen-Sutherland and Liang-Barsky by minimizing intersection calculations. It first determines the position of P1 (one of 9 regions, similar to Cohen-Sutherland). Based on this, it constructs additional regions using window edges and diagonals through P1. The region in which P2 lies directly determines which clip boundary to use — needing typically only one intersection calculation, making it more efficient, though more complex to implement due to extensive case analysis.

10 MARKS
Explain the complete 2D viewing pipeline with a neat diagram, mentioning all the coordinate systems involved.

The 2D viewing pipeline transforms a scene from world coordinates to device coordinates in these stages:

  1. World Coordinates: Scene/objects defined in real-world units
  2. Window Selection: A rectangular region of world coordinates chosen for display
  3. Clipping: Remove portions of objects outside the window
  4. Window-to-Viewport Mapping: Map window coordinates to normalized/viewport coordinates using scale and translate
  5. Viewport: Region on output device where content appears
  6. Device/Screen Coordinates: Final pixel positions for display

This pipeline allows the same scene to be viewed at different zoom levels/positions (window) and displayed at different parts of the screen (viewport) — fundamental for multi-window applications.
