Computer Graphics & Multimedia Lab, 5CS4-21 (Turbo C++)

Experiment 12: Animation: moving helicopter and moving fan

Aim: To draw a moving helicopter and a moving fan.

The manual’s helicopter and fan programs are long and use fixed BGI paths. These are shorter, check for graphics errors, and can be stopped with any key.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

These are animations. Each one runs until you press a key. The delay() function comes from dos.h and is available in Turbo C++. Smaller delay values give a faster animation.

Source code

1. Moving helicopter

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<math.h>
#include<dos.h>
#include<graphics.h>

void heli(int x, int y, int color, int frame)
{
    setcolor(color);
    ellipse(x, y, 0, 360, 40, 20);            /* body */
    arc(x - 15, y, 20, 160, 15);              /* cockpit window */
    line(x + 35, y - 8, x + 100, y - 12);     /* tail, upper edge */
    line(x + 38, y + 2, x + 100, y - 6);      /* tail, lower edge */
    line(x + 100, y - 12, x + 100, y - 6);    /* tail end */
    line(x, y - 20, x, y - 30);               /* mast */
    line(x - 35, y + 30, x + 35, y + 30);     /* skid */
    line(x - 15, y + 19, x - 20, y + 30);     /* skid strut */
    line(x + 15, y + 19, x + 20, y + 30);     /* skid strut */

    if(frame % 2 == 0)
    {
        line(x - 60, y - 30, x + 60, y - 30);         /* main rotor */
        line(x + 100, y - 24, x + 100, y + 6);        /* tail rotor */
    }
    else
    {
        line(x - 45, y - 33, x + 45, y - 27);
        line(x + 94, y - 22, x + 106, y + 4);
    }
}

void main()
{
    int gd = DETECT, gm, err;
    int x, y, frame = 0;

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    for(x = 20; x < 500 && !kbhit(); x += 4)
    {
        y = 150 + (int)(20 * sin(x / 25.0));
        heli(x, y, WHITE, frame);
        delay(40);
        heli(x, y, BLACK, frame);
        frame++;
    }

    y = 150 + (int)(20 * sin(x / 25.0));
    heli(x, y, WHITE, frame);

    getch();
    closegraph();
}

Output

A graphics window opens. A white helicopter flies from the left towards the right, bobbing up and down, with its rotor blades changing position at every step.
Press any key to stop it early. It also stops by itself near the right side of the screen. Press a key to close.

2. Moving fan

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<dos.h>
#include<graphics.h>

void blades(int cx, int cy, int r, int ang, int color)
{
    int i, st, en;
    setcolor(color);
    setfillstyle(SOLID_FILL, color);
    for(i = 0; i < 3; i++)
    {
        st = (ang + i * 120) % 360;
        en = st + 35;
        if(en <= 360)
        {
            pieslice(cx, cy, st, en, r);
        }
        else
        {
            pieslice(cx, cy, st, 360, r);
            pieslice(cx, cy, 0, en - 360, r);
        }
    }
}

void main()
{
    int gd = DETECT, gm, err;
    int ang = 0;

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    setcolor(WHITE);
    circle(320, 240, 130);                  /* guard */

    while(!kbhit())
    {
        blades(320, 240, 120, ang, LIGHTBLUE);
        setcolor(WHITE);
        circle(320, 240, 12);               /* hub */
        delay(60);
        blades(320, 240, 120, ang, BLACK);
        ang = (ang + 15) % 360;
    }

    getch();
    closegraph();
}

Output

A graphics window opens. A fan with three light-blue blades turns round and round inside a white guard circle, with a white hub in the middle.
Press any key to stop it and close the window.

Explanation

  1. How the animation works: draw the picture, wait a short time with delay(), erase it by drawing the same picture in black, change its position or angle a little, and draw it again. Because the eye keeps an image for a moment (persistence of vision), the many still pictures look like movement.
  2. Helicopter: the function heli(x, y, color, frame) draws the whole helicopter relative to the point (x, y): an ellipse for the body, an arc for the window, lines for the tail, mast and skids. Calling it with BLACK erases it.
  3. The loop moves the helicopter 4 pixels right each time. y = 150 + 20 sin(x/25) makes it bob up and down as it flies.
  4. The rotor looks like it is turning because the main rotor and tail rotor are drawn flat in one frame and tilted in the next (frame % 2).
  5. Fan: the function blades() draws three filled sectors (pieslice) 120 degrees apart, each 35 degrees wide. At every step the start angle grows by 15 degrees, so the blades turn. A sector that would pass 360 degrees is drawn in two parts.
  6. The hub is drawn after the blades because erasing the blades also blanks the middle of the hub. The guard circle is drawn once because it never changes.
  7. kbhit() returns true when a key has been pressed, which ends the loop. The final getch() takes that key press.

Viva questions

What is computer animation?

Showing a series of pictures quickly, each slightly different from the last, so that the objects appear to move.

How is animation done in C graphics?

Draw the object, call delay(), erase it (draw it in the background colour or clear the screen), change its position, and repeat in a loop.

What does the delay function do?

delay(ms) pauses the program for the given milliseconds. It controls the speed of the animation.

Why do we erase the object before drawing it in the new position?

Otherwise the old copies stay on the screen and the object would leave a trail instead of moving.

What is flicker and how can it be reduced?

Flicker is visible blinking when a picture is erased and redrawn. It can be reduced by erasing only the moving part, by a smaller delay, or by drawing on a hidden page and showing it (double buffering with setactivepage and setvisualpage).

What does kbhit() do?

It checks whether a key has been pressed and returns non-zero if so, without waiting. It is used to stop animation loops.

What is the pieslice function?

pieslice(x, y, start, end, r) draws and fills a sector of a circle with its centre at (x, y), between the start and end angles.

What is the arc function?

arc(x, y, start, end, r) draws part of a circle between the start and end angles (measured anticlockwise from the 3 o’clock position).

Why is sin() used for the helicopter?

The sine of the x position gives a smooth up-and-down value between -1 and 1, so the helicopter bobs like it is flying.

What is persistence of vision?

The eye holds an image for a fraction of a second, so quickly changing pictures blend into smooth motion.

Why is initgraph necessary?

It loads the graphics driver and puts the screen into graphics mode, so graphics functions can draw.

What is closegraph and why is it needed?

It closes graphics mode, frees the memory used by the graphics system and returns the screen to text mode.
