Experiment 10: Cohen-Sutherland line clipping algorithm

Aim: To implement the Cohen-Sutherland 2D line clipping algorithm.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

#define RC_TOP 8
#define RC_BOTTOM 4
#define RC_RIGHT 2
#define RC_LEFT 1

int xmin, ymin, xmax, ymax;

int code(float x, float y)
{
    int c = 0;
    if(y < ymin) c = c | RC_TOP;
    if(y > ymax) c = c | RC_BOTTOM;
    if(x > xmax) c = c | RC_RIGHT;
    if(x < xmin) c = c | RC_LEFT;
    return c;
}

void main()
{
    int gd = DETECT, gm, err;
    int ox1, oy1, ox2, oy2, c1, c2, outc, accept = 0;
    float x1, y1, x2, y2, x, y;

    clrscr();
    printf("Enter window corners xmin ymin xmax ymax: ");
    scanf("%d%d%d%d", &xmin, &ymin, &xmax, &ymax);
    printf("Enter line end points x1 y1 x2 y2: ");
    scanf("%d%d%d%d", &ox1, &oy1, &ox2, &oy2);

    x1 = ox1; y1 = oy1;
    x2 = ox2; y2 = oy2;
    c1 = code(x1, y1);
    c2 = code(x2, y2);

    while(1)
    {
        if((c1 | c2) == 0)
        {
            accept = 1;
            break;
        }
        if((c1 & c2) != 0)
            break;

        if(c1 != 0)
            outc = c1;
        else
            outc = c2;

        if(outc & RC_TOP)
        {
            x = x1 + (x2 - x1) * (ymin - y1) / (y2 - y1);
            y = ymin;
        }
        else if(outc & RC_BOTTOM)
        {
            x = x1 + (x2 - x1) * (ymax - y1) / (y2 - y1);
            y = ymax;
        }
        else if(outc & RC_RIGHT)
        {
            y = y1 + (y2 - y1) * (xmax - x1) / (x2 - x1);
            x = xmax;
        }
        else
        {
            y = y1 + (y2 - y1) * (xmin - x1) / (x2 - x1);
            x = xmin;
        }

        if(outc == c1)
        {
            x1 = x; y1 = y;
            c1 = code(x1, y1);
        }
        else
        {
            x2 = x; y2 = y;
            c2 = code(x2, y2);
        }
    }

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    /* before clipping */
    setcolor(WHITE);
    rectangle(xmin, ymin, xmax, ymax);
    setcolor(RED);
    line(ox1, oy1, ox2, oy2);
    outtextxy(10, 10, "Before clipping (press a key)");
    getch();

    /* after clipping */
    cleardevice();
    setcolor(WHITE);
    rectangle(xmin, ymin, xmax, ymax);
    if(accept)
    {
        setcolor(GREEN);
        line((int)(x1 + 0.5), (int)(y1 + 0.5), (int)(x2 + 0.5), (int)(y2 + 0.5));
    }
    outtextxy(10, 10, "After clipping (press a key)");
    getch();
    closegraph();
}

The region codes here use screen coordinates (y grows downwards), so "top" is the smaller y. The manual’s algorithm lists the same four tests using ymax and ymin.

Explanation

  1. Idea: Only the part of a line that lies inside a rectangular window should be drawn. Every end point gets a 4-bit region code that says where it is compared to the window.
  2. Region code bits: top = 8 if y is above the window (y < ymin), bottom = 4 if y > ymax, right = 2 if x > xmax, left = 1 if x < xmin. A point inside the window has code 0. A corner outside has two bits set, for example top-left is 8 + 1 = 9.
  3. Trivial accept: if both codes are 0 ((c1 | c2) == 0), the whole line is inside and is drawn as it is.
  4. Trivial reject: if the bitwise AND of the codes is not 0 (c1 & c2), both end points are on the same outside side, so the line cannot enter the window and is discarded.
  5. Otherwise (clipping candidate): pick an end point that is outside, find where the line meets the window edge it is beyond (top, bottom, right or left), and replace that end point by the intersection. Then recompute its code and repeat from the start.
  6. Intersection formulas: with the top or bottom edge, x = x1 + (x2 - x1) * (edge_y - y1) / (y2 - y1). With the right or left edge, y = y1 + (y2 - y1) * (edge_x - x1) / (x2 - x1).
  7. Example: window (100,100) to (300,200) and line (50,50) to (350,250). The codes are 9 (top-left) and 6 (bottom-right). Their AND is 0, so the line is a candidate. Cut at the top edge: (125, 100). Cut at the bottom edge: (275, 200). Both new codes are 0, so the line (125,100) to (275,200) is drawn.
  8. The program shows the original line in red, then clears the screen and shows the clipped line in green.

Viva questions

What is line clipping?

Removing the part of a line that lies outside a given window (clipping region) and keeping only the visible part.

Explain the Cohen-Sutherland line clipping algorithm.

It gives each end point a 4-bit region code. Lines that are fully inside are accepted, lines fully outside on one side are rejected, and the others are cut at a window edge repeatedly until they are accepted or rejected.

Give an example of line clipping.

For window (100,100)-(300,200), the line (50,150)-(350,150) is clipped to (100,150)-(300,150). The two outside ends are cut at the left and right edges.

What are the steps of line clipping?

1) Compute the region code of both end points. 2) If both are 0, accept. 3) If their AND is not 0, reject. 4) Otherwise cut the line at a window edge for an outside end point, update that end point and its code, and go back to step 2.

Which is the best line clipping algorithm?

Cohen-Sutherland is simple and fast when most lines are clearly inside or outside. Liang-Barsky is generally faster because it works with parametric equations and needs fewer intersection calculations.

What is the condition for a line to be a clipping candidate?

The AND of the region codes of its end points is 0 and the OR is not 0. That means it is not fully inside and not fully on one outside side, so it may cross the window.

Why is clipping used in graphics?

To draw only what is visible in the window, which saves time and memory and stops drawing outside the screen or viewport.

How many methods of text clipping are there?

Three: all-or-none string clipping, all-or-none character clipping and component (character part) clipping.

What are the three types of clipping?

Point clipping, line clipping and polygon clipping (also curve and text clipping).

Why do we need clipping?

Objects can be larger than the display window. Clipping removes the invisible parts so only the part in the window is processed and shown.
