Experiment 9: JSP login form

Login with a static check (fixed username and password) and with a dynamic MySQL database.

Before you start

  • Tomcat 9 must be extracted (for example C:\apache-tomcat-9.0.123). JSP files need no compiling: put them in a folder under webapps.
  • If Tomcat is already running from an earlier experiment, you do not need to start it again. It picks up new folders by itself.

Set the paths

Change both paths to match the lab PC. Find the JDK with where javac. Use the path that ends in \bin\javac.exe, without that ending, and ignore the Common Files\Oracle\Java\javapath line.

Command Prompt
set JAVA_HOME=C:\Program Files\Java\jdk-26
set TOMCAT=C:\apache-tomcat-9.0.123

</body>
</html>
Process.jsp
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<%
String a = request.getParameter("uname");
String b = request.getParameter("pass");
if ("queue".equals(a) && "queue".equals(b)) {
    response.sendRedirect("Welcome.jsp");
} else {
    out.println("Invalid username or password. <a href='Index.html'>Try again</a>");
}
%>
Welcome.jsp
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<%
out.println("Welcome to world of jsp");
%>

The manual’s Process.jsp shows a blank page on a wrong login. This version adds an else branch with a message.

Part B: Code

Change root123 in servlet.jsp and wel.jsp to your MySQL password.

index.jsp (register form)
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
<title>Register</title>
</head>
<body>
<form action="servlet.jsp" method="post">
    Enter your UserName: <input type="text" name="name"><br><br>
    Enter your Password: <input type="password" name="pas"><br><br>
    Enter your email: <input type="email" name="email"><br><br>
    <input type="submit" value="Register">
</form>
</body>
</html>
servlet.jsp (saves to the database)
<%@page import="java.sql.*"%>
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<%
String name = request.getParameter("name");
String pass = request.getParameter("pas");
String email = request.getParameter("email");

Class.forName("com.mysql.cj.jdbc.Driver");
Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/labdb", "root", "root123");
PreparedStatement ps = con.prepareStatement("insert into reg values(?,?,?)");
ps.setString(1, name);
ps.setString(2, pass);
ps.setString(3, email);
int i = ps.executeUpdate();
if (i > 0) {
    response.sendRedirect("login.jsp");
} else {
    out.println("Try Again");
}
%>
login.jsp (login form)
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
<title>Login</title>
</head>
<body>
<form action="wel.jsp" method="post">
    Name: <input type="text" name="name"><br><br>
    Password: <input type="password" name="pas"><br><br>
    <input type="submit" value="Login">
</form>
</body>
</html>
wel.jsp (checks the login)
<%@page import="java.sql.*"%>
<%@page contentType="text/html" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
<title>Welcome</title>
</head>
<body>
<%
String name = request.getParameter("name");
String pass = request.getParameter("pas");

Class.forName("com.mysql.cj.jdbc.Driver");
Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/labdb", "root", "root123");
PreparedStatement ps = con.prepareStatement("select * from reg where name=? and pwd=?");
ps.setString(1, name);
ps.setString(2, pass);
ResultSet rs = ps.executeQuery();
if (rs.next()) {
    out.println("<h1>Welcome : " + name + "</h1>");
} else {
    out.println("<h1>Not Done</h1>");
}
%>
</body>
</html>

The manual uses the old driver com.mysql.jdbc.Driver. Newer connectors need com.mysql.cj.jdbc.Driver, which is used here.

Common errors

  • ClassNotFoundException com.mysql.cj.jdbc.Driver: the jar is not in WEB-INF\lib, or Tomcat was not restarted.
  • Access denied for user root: wrong password in servlet.jsp or wel.jsp.
  • Table reg doesn’t exist: the CREATE TABLE step was skipped, or it was run in the wrong database.
  • 404: wrong folder name in the URL, or a file saved as .txt.

How it works

  • Static: Process.jsp compares the input with fixed values and redirects with response.sendRedirect() on a match.
  • Dynamic: servlet.jsp inserts the user into the reg table with a PreparedStatement. wel.jsp runs a SELECT and logs in if rs.next() finds a matching row.
  • The JDBC code is the same as Experiment 4, just inside <% %> scriptlets.

Viva answers

  • JSP life-cycle methods: jspInit() once, _jspService() for every request, jspDestroy() once. Before that the page is translated into a servlet and compiled.
  • JSP comment syntax: <%-- comment --%>
  • Implicit objects: request, response, out, session, application, config, pageContext, page, exception.
  • Handling exceptions: use try-catch, or an error page with errorPage and isErrorPage="true", or an error-page entry in web.xml.
  • Forwarding to a servlet: <jsp:forward page="/MyServlet"/> or RequestDispatcher.forward().
