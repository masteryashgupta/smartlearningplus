Compiler Design Lab, 5CS4-22 (LEX, runs on Linux)

Experiment 8: LEX program to count blank spaces, words and lines

Aim: Write a LEX program to count blank spaces, words and lines in a given file.

The manual's version also counts tabs and characters and has no word counter, and its printf lines are missing closing quotes. This version counts exactly what the aim asks: spaces, words and lines.

How to compile and run

LEX does not run in Turbo C++. Use Linux or WSL. Install once: sudo apt install flex gcc. Then, for a program saved as exp8.l:

lex exp8.l
cc lex.yy.c -lfl
./a.out

If -lfl gives an error, use -ll. Type your input and press Enter. Press Ctrl+D to finish.

Create test.txt in the same folder with two lines: Geeks for Geeks and gfg gfg (press Enter after the last line).

Source code: Version 1: reads from a file

%{
#include<stdio.h>
int lc = 0, sc = 0, wc = 0;
%}

%%
\n          { lc++; }
[ ]         { sc++; }
\t          ;
[^ \t\n]+   { wc++; }
%%

int yywrap() { return 1; }

int main()
{
    char fname[30];
    printf("Enter file name: ");
    scanf("%s", fname);
    yyin = fopen(fname, "r");
    if(yyin == NULL)
    {
        printf("File not found\n");
        return 1;
    }
    yylex();
    fclose(yyin);
    printf("No. of lines  = %d\n", lc);
    printf("No. of blank spaces = %d\n", sc);
    printf("No. of words  = %d\n", wc);
    return 0;
}

Output

Enter file name: test.txt
No. of lines  = 2
No. of blank spaces = 3
No. of words  = 5

Source code: Version 2 (reads text typed at the keyboard)

Compile it the same way as above. There is no yyin or fopen, so LEX reads from the keyboard. Type your lines, then press Ctrl+D to end the input and see the counts.

%{
#include<stdio.h>
int lc = 0, sc = 0, wc = 0;
%}

%%
\n          { lc++; }
[ ]         { sc++; }
\t          ;
[^ \t\n]+   { wc++; }
%%

int yywrap() { return 1; }

int main()
{
    printf("Enter text (press Ctrl+D on a new line to finish):\n");
    yylex();
    printf("No. of lines  = %d\n", lc);
    printf("No. of blank spaces = %d\n", sc);
    printf("No. of words  = %d\n", wc);
    return 0;
}

Output

Enter text (press Ctrl+D on a new line to finish):
Geeks for Geeks
gfg gfg
(press Ctrl+D)
No. of lines  = 2
No. of blank spaces = 3
No. of words  = 5

Explanation

  1. The program opens the file named by the user and points yyin (the input file used by LEX) to it. Without this, LEX reads the keyboard.
  2. \n is a new line, so lc++ counts lines. [ ] is one blank space, so sc++ counts spaces.
  3. [^ \t\n]+ means one or more characters that are not space, tab or newline. That is a word, so wc++ counts words. The longest-match rule makes it take the whole word at once.
  4. The tab rule has an empty action ;, so tabs are skipped.
  5. yylex() returns at the end of the file and main prints the totals.

Viva questions

What is yyin?

The input file pointer of the LEX scanner. By default it is stdin (the keyboard).

How does the program count words?

Each maximal run of characters that are not space, tab or newline matches the word rule once.

What does [^ \t\n] mean?

Any single character except space, tab and newline. The ^ inside brackets means "not".

What does the + do?

It means one or more repetitions of the preceding pattern.

Why is the longest match important here?

It makes the scanner take a whole word as one match instead of one letter at a time.

What does an empty action (;) mean?

The pattern is matched and its text is discarded.

Why does the last line need Enter?

Lines are counted by newline characters, so a last line without a newline is not counted.

How do you stop keyboard input?

Press Ctrl+D. In this program the input comes from a file, so it stops at the end of the file.
