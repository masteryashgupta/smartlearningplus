Compiler Design Lab, 5CS4-22 (Turbo C++)

Experiment 2: Identify whether a string is a keyword

Aim: To identify whether a given string is a keyword or not.

Source code

#include<stdio.h>
#include<conio.h>
#include<string.h>

void main()
{
    char keyword[32][10] = {"auto","double","int","struct","break","else","long",
                            "switch","case","enum","register","typedef","char",
                            "extern","return","union","const","float","short",
                            "unsigned","continue","for","signed","void","default",
                            "goto","sizeof","volatile","do","if","static","while"};
    char string[10];
    int flag = 0, i;

    clrscr();
    printf("enter any string:");
    gets(string);

    for(i = 0; i < 32; i++)
    {
        if(strcmp(string, keyword[i]) == 0)
        {
            flag = 1;
        }
    }

    if(flag == 1)
        printf("%s is a keyword", string);
    else
        printf("%s is not a keyword", string);

    getch();
}

The manual spells volatile as "voltile". This version has it fixed, so volatile is now recognised.

Output

enter any string:void
void is a keyword

enter any string:int
int is a keyword

enter any string:string
string is not a keyword

How to run in Turbo C++

  1. Type or paste the code, then press F2 to save as EXP2.CPP.
  2. Press Alt+F9 to compile and Ctrl+F9 to run.
  3. Press Alt+F5 to see the output screen again.

Explanation

  1. keyword[32][10] is a 2D array holding the 32 C keywords, each up to 9 letters plus '\0'.
  2. gets(string) reads the word typed by the user.
  3. The for loop compares the input with every keyword using strcmp, which returns 0 when two strings are equal.
  4. On a match, flag is set to 1. The flag remembers that a match was found.
  5. After the loop, the program prints whether the word is a keyword, based on flag.

Viva questions

What is a keyword?

A reserved word with a fixed meaning in the language, like int or while. It cannot be used as a variable name.

Keyword vs identifier?

Keywords are reserved by the language. Identifiers are names chosen by the programmer for variables, functions and so on.

How many keywords are in C?

32 in standard C89/C90, the set used in this program.

What does strcmp return?

0 if the strings are equal, a negative value if the first is smaller, and a positive value if the first is larger.

Why can't we compare strings with ==?

For arrays, == compares memory addresses, not the characters. strcmp compares the characters.

What is the use of the flag variable?

It records whether a match was found while the loop runs, so the result can be printed after the loop.

Why is gets() unsafe?

It does not check the size of the array, so a long input overflows the buffer. It was removed from C11. Here the array holds only 9 characters.

Which compiler phase does this program belong to?

Lexical analysis, which classifies words as keywords or identifiers.

How can the search be made faster?

Sort the keyword table and use binary search (Exp 3 does this), or use a hash table.
