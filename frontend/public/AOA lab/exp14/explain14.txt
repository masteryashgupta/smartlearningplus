Naive String-Matching Algorithm kya hai?

Socho tere paas ek badi text string hai, jaise "AABAACAADAABAABA", aur ek chhoti pattern string hai jise tu is bade text mein dhundna chahta hai, jaise "AABA". Tujhe pata karna hai ki pattern text ke andar kahan-kahan match hota hai.

Naive (matlab "seedha-saada, bina kisi trick ke") tarika hai: pattern ko text ke upar rakh ke, ek-ek position slide karo, aur har position pe check karo ki pattern text ke us hisse se match kar raha hai ya nahi.

Process:
1. Pattern ko text ke shuru (index 0) pe rakho.
2. Character-by-character compare karo — agar sab match ho gaye to "match mil gaya" bol do us position pe.
3. Agar kahin bhi mismatch mile, to compare rokdo aur pattern ko ek position aage sarka do (slide karo).
4. Ye process text ke end tak repeat karte raho.

Isko "Naive" isliye kehte hain kyunki ye kisi bhi smart shortcut ka use nahi karta (jaise KMP ya Boyer-Moore algorithms karte hain) — bas seedha-seedha har position try karta hai.


Chhota example:

Text:    "AABAACAADAABAABA"
Pattern: "AABA"

Index 0: text[0..3] = "AABA" -> MATCH! (position 0)
Index 1: text[1..4] = "ABAA" -> pattern "AABA" se match nahi
Index 2: text[2..5] = "BAAC" -> match nahi
...
(aise hi har position try karte raho)
...
Index 9: text[9..12] = "AABA" -> MATCH! (position 9)
Index 12: text[12..15] = "AABA" -> MATCH! (position 12)

Result: Pattern "AABA" found at index 0, 9, aur 12


Speed ka mamla:

Naive String Matching ka time complexity worst case mein O(n x m) hai, jahan n text ki length hai aur m pattern ki length hai — kyunki har position pe pura pattern character-by-character check karna pad sakta hai. Bade texts ke liye ye slow ho sakta hai, isiliye real-world applications (jaise text editors, search engines) mein smarter algorithms (KMP, Boyer-Moore, Rabin-Karp) use hote hain jo repeated comparisons avoid karte hain. Lekin Naive method samajhne mein sabse aasan hai aur chhote texts ke liye bilkul theek kaam karta hai.


Tera program kya karta hai:

1. Tujhse text string aur pattern string enter karwayi jaati hai.
2. Program pattern ko text ke har possible position pe slide karke check karta hai (upar wala process).
3. Jahan bhi poora pattern match hota hai, us position (index) ko print kar deta hai.
4. Agar kahin bhi match nahi milta, to "Pattern not found" bol deta hai.
5. Calculation mein kitna time laga, wo bhi dikhaya jaata hai.

Bas itna hi — pattern ko text ke upar ek-ek position slide karo, har jagah character-by-character compare karo, jahan sab match ho wahan "found" bol do.
