Computer Graphics & Multimedia Lab, 5CS4-21 (Turbo C++)

Experiment 13: Drawing and animation: moving car, moving fish and a hut

Aim: To draw a moving car, a moving fish and a hut using simple graphics functions.

The manual’s car, fish and hut programs use C++ (iostream.h), bad BGI paths and long coordinate lists. These are shorter C versions. The manual’s fish and car programs are animations, and the hut is a still picture, as here.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

The car and fish are animations. They run until you press a key, and delay() comes from dos.h. In the hut program, the shape must be fully closed before floodfill is used, or the colour spreads over the whole screen.

Source code

1. Moving car

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<dos.h>
#include<graphics.h>

void car(int x, int y, int color)
{
    int wheel;
    if(color == BLACK)
        wheel = BLACK;
    else
        wheel = WHITE;

    setcolor(color);
    rectangle(x, y - 20, x + 100, y);              /* lower body */
    line(x + 20, y - 20, x + 35, y - 45);          /* roof, left slope */
    line(x + 35, y - 45, x + 70, y - 45);          /* roof, top */
    line(x + 70, y - 45, x + 85, y - 20);          /* roof, right slope */
    line(x + 52, y - 45, x + 52, y - 20);          /* window divider */

    setcolor(wheel);
    circle(x + 25, y + 5, 10);                     /* wheels */
    circle(x + 75, y + 5, 10);
    circle(x + 25, y + 5, 3);
    circle(x + 75, y + 5, 3);
}

void main()
{
    int gd = DETECT, gm, err;
    int x, y = 300;

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    for(x = 0; x < 530 && !kbhit(); x += 4)
    {
        setcolor(WHITE);
        line(0, y + 15, 639, y + 15);              /* road */
        car(x, y, RED);
        delay(30);
        car(x, y, BLACK);
    }

    setcolor(WHITE);
    line(0, y + 15, 639, y + 15);
    car(x, y, RED);

    getch();
    closegraph();
}

Output

A red car (body, roof, window and two wheels) drives from the left to the right along a white road line.
Press any key to stop it early. It stops by itself near the right side. Press a key to close.

2. Moving fish

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<math.h>
#include<dos.h>
#include<graphics.h>

void fish(int x, int y, int color)
{
    setcolor(color);
    ellipse(x, y, 0, 360, 35, 18);              /* body */
    line(x + 33, y - 5, x + 55, y - 18);        /* tail */
    line(x + 55, y - 18, x + 55, y + 18);
    line(x + 55, y + 18, x + 33, y + 5);
    line(x - 5, y - 17, x + 5, y - 30);         /* top fin */
    line(x + 5, y - 30, x + 15, y - 16);
    arc(x - 12, y, 100, 260, 12);               /* gill */
    circle(x - 20, y - 5, 3);                   /* eye */
}

void main()
{
    int gd = DETECT, gm, err;
    int x, y;

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    for(x = 560; x > 60 && !kbhit(); x -= 4)
    {
        y = 240 + (int)(30 * sin(x / 30.0));
        fish(x, y, LIGHTCYAN);
        delay(40);
        fish(x, y, BLACK);
    }

    y = 240 + (int)(30 * sin(x / 30.0));
    fish(x, y, LIGHTCYAN);

    getch();
    closegraph();
}

Output

A light-blue fish swims from the right to the left, moving up and down in a wave, with a tail, fin, gill and eye.
Press any key to stop it early. It stops by itself near the left side. Press a key to close.

3. Hut

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

void main()
{
    int gd = DETECT, gm, err;

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    setcolor(WHITE);

    /* outlines */
    rectangle(200, 250, 400, 370);              /* wall */
    line(190, 250, 300, 170);                   /* roof */
    line(300, 170, 410, 250);
    line(410, 250, 190, 250);
    rectangle(280, 300, 320, 370);              /* door */
    rectangle(220, 280, 260, 320);              /* window */
    circle(520, 100, 30);                       /* sun */
    line(0, 370, 639, 370);                     /* ground */

    /* colours */
    setfillstyle(SOLID_FILL, RED);
    floodfill(300, 220, WHITE);                 /* roof */
    setfillstyle(SOLID_FILL, BROWN);
    floodfill(230, 350, WHITE);                 /* wall */
    setfillstyle(SOLID_FILL, LIGHTBLUE);
    floodfill(240, 300, WHITE);                 /* window */
    setfillstyle(SOLID_FILL, DARKGRAY);
    floodfill(300, 340, WHITE);                 /* door */
    setfillstyle(SOLID_FILL, YELLOW);
    floodfill(520, 100, WHITE);                 /* sun */
    setfillstyle(SOLID_FILL, GREEN);
    floodfill(100, 420, WHITE);                 /* grass */

    /* window frame */
    line(240, 280, 240, 320);
    line(220, 300, 260, 300);

    outtextxy(260, 60, "My Hut");

    getch();
    closegraph();
}

Output

A still picture: a hut with a red roof, brown wall, grey door and blue window, a yellow sun in the sky, green grass below the ground line, and the text "My Hut".
Press any key to close it.

Explanation

  1. Car and fish (animation): the whole object is drawn by one function relative to (x, y). The loop draws it, waits with delay(), draws it again in BLACK to erase it, and moves x by 4 pixels. The car moves right, and the fish moves left (its head is on the left). Calling the same function with a colour and with black is the easiest way to erase an object.
  2. Car: a rectangle is the lower body, three lines make the sloping roof, one line divides the windows, and four circles make the two wheels with hubs. The road line is drawn again in every step, because erasing the wheels would otherwise cut a gap in it.
  3. Fish: an ellipse is the body, three lines make the triangular tail, two lines make the top fin, an arc is the gill and a small circle is the eye. y = 240 + 30 sin(x/30) makes it swim in a wave.
  4. Hut (still picture): the outlines are drawn first with rectangles, lines and a circle, all in white. Then setfillstyle picks a colour and floodfill(x, y, WHITE) fills the closed shape that contains the point (x, y), stopping at the white outline.
  5. The roof, wall, window, door, sun and grass are filled one by one. The window frame lines are drawn after the fill, so they stay visible on top of the colour.
  6. kbhit() ends an animation loop when a key is pressed, and the final getch() takes that key.

Viva questions

What is a graphics function?

A library function that draws on the screen in graphics mode, for example line, circle, rectangle and putpixel, declared in graphics.h.

What is viewing transformation?

The process of mapping a part of the world coordinate system (the window) onto the device screen (the viewport). It consists of windowing and viewport mapping.

What is an animation?

A series of pictures, each slightly different, shown quickly one after another so that the objects appear to move.

What are fractals?

Shapes that show the same pattern at every scale (self-similarity), made by repeating a simple rule. Examples are the Koch snowflake and the Mandelbrot set.

What are morphing and tweening?

Tweening creates the in-between frames between two key frames. Morphing is tweening that smoothly changes one shape into another.

What are blobby objects?

Objects whose shapes flow and join into each other like liquid drops when they come close, such as water drops or molecules.

Distinguish between window and viewport.

The window is the area chosen in world coordinates that we want to see. The viewport is the area of the screen where that window is displayed.

What is interactive computer graphics?

Graphics where the user can change the picture while it is shown, using input devices such as a mouse or keyboard, and the picture responds at once.

What does RGB mean?

Red, Green and Blue: the three primary colours of light. Any colour on a screen is made by mixing different amounts of them.

How do you erase and redraw an object in animation?

Draw the same object again in the background colour (black) to erase it, change its position, and draw it in its colour.

Which function fills a closed shape with colour?

floodfill(x, y, border), with the fill colour and pattern chosen by setfillstyle.
