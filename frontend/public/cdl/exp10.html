Compiler Design Lab, 5CS4-22 (YACC with LEX, runs on Linux)

Experiment 10: YACC program to recognize strings of the form a^n b^n

Aim: Write a YACC program to recognize strings such as ab, aabb and aaabbb using the grammar a^n b^n.

The manual's code is the same grammar for Exp 10 and Exp 12. Both are valid for n = 0 as well, so an empty line is accepted. Note that the strings "aaab" and "abbb" in the aim are not of the form a^n b^n, so they are rejected.

How to compile and run

YACC and LEX do not run in Turbo C++. Use Linux or WSL. Install once: sudo apt install flex bison gcc. Save the two files below in the same folder (exp10.l and exp10.y), then run the commands in this order. YACC must run first because the LEX file includes y.tab.h.

yacc -d exp10.y
lex exp10.l
cc y.tab.c lex.yy.c
./a.out

Type a string and press Enter. The program prints the result and stops.

Source code

Lexer: exp10.l

%{
#include "y.tab.h"
%}

%%
[aA]    { return A; }
[bB]    { return B; }
\n      { return NL; }
.       { return yytext[0]; }
%%

int yywrap() { return 1; }

Parser: exp10.y

%{
#include<stdio.h>
#include<stdlib.h>
int yylex();
int yyerror(char *msg);
%}

%token A B NL

%%
stmt : S NL    { printf("valid string\n"); exit(0); }
     ;

S    : A S B
     |
     ;
%%

int yyerror(char *msg)
{
    printf("invalid string\n");
    exit(0);
}

int main()
{
    printf("enter the string\n");
    yyparse();
    return 0;
}

Output

enter the string
ab
valid string

enter the string
aabb
valid string

enter the string
aab
invalid string

enter the string
aaab
invalid string

Explanation

  1. The grammar is S : A S B | (empty). It says a valid string is an a, then a valid string, then a b, or nothing at all. This gives ab, aabb, aaabbb and so on, with equal numbers of a and b.
  2. The LEX file turns each letter into a token: a becomes A, b becomes B and Enter becomes NL. Any other character is passed on as it is, which causes a syntax error.
  3. The rule stmt : S NL accepts the whole line. If the parse succeeds, the action prints "valid string".
  4. If the tokens do not fit the grammar, YACC calls yyerror, which prints "invalid string".
  5. exit(0) ends the program after the first result.

Viva questions

What is the language a^n b^n?

Strings with n a's followed by exactly n b's, for example ab, aabb, aaabbb.

Is aaab accepted? Why not?

No. It has 3 a's but only 1 b, so the counts are not equal.

Why can a regular expression not recognize a^n b^n?

A finite automaton cannot count an unlimited n. A context-free grammar (a stack) can.

What does the empty alternative in S do?

It lets S match nothing, which ends the recursion and also makes the empty string valid (n = 0).

What is a context-free grammar?

A set of rules where the left side is a single non-terminal, such as S : A S B.

What are terminals and non-terminals here?

Terminals are the tokens A, B and NL. Non-terminals are S and stmt.

What is YACC?

Yet Another Compiler Compiler: a tool that generates a parser in C from a context-free grammar.

What is the structure of a YACC program?

Declarations (%{ %}, %token), grammar rules between %% markers, and user C code.

How do LEX and YACC work together?

LEX reads characters and returns tokens. YACC calls yylex() to get tokens and checks that they follow the grammar.

What is y.tab.h?

A header file made by yacc -d that holds the token numbers (like A, B), so LEX and YACC agree on them.

What does yyparse() do?

It starts parsing. It returns 0 if the input is accepted and non-zero if there is a syntax error.

What is yyerror()?

The function YACC calls when it finds a syntax error. We define it to print a message.

What kind of parser does YACC build?

A bottom-up LALR(1) parser.
