5.1 Introduction to Cyclic Codes EXAM HOT

📖 Definition

Cyclic Code is a special subclass of linear block codes where every cyclic shift of a valid codeword produces another valid codeword in the same code. If c = (c₀, c₁, ..., cₙ₋₁) is a codeword, then (cₙ₋₁, c₀, c₁, ..., cₙ₋₂) is also a valid codeword.

🗣 Hinglish Explanation

Socho ek circle mein balls rakhi hain. Ek shift karo toh wahi arrangement phir valid hai! Cyclic code mein kisi bhi codeword ko left ya right shift karo, result bhi same code ka valid member hoga. Isliye inhe polynomial algebra se describe karna bahut easy hota hai aur hardware (shift register) se implement karna fast hota hai!

💡 Example: Cyclic Property

In (7,4) cyclic code, if 1011000 is a codeword, then ALL cyclic shifts are also valid codewords:

Original: 1 0 1 1 0 0 0 Shift 1: 0 1 0 1 1 0 0 Shift 2: 0 0 1 0 1 1 0 Shift 3: 0 0 0 1 0 1 1 Shift 4: 1 0 0 0 1 0 1 Shift 5: 1 1 0 0 0 1 0 Shift 6: 0 1 1 0 0 0 1

All 7 cyclic shifts are valid codewords! ✓

Key Advantages of Cyclic Codes

  • 🔧 Hardware Efficiency: LFSR (Linear Feedback Shift Register) + XOR gates only
  • 🧮 Algebraic Description: Entire code defined by ONE polynomial g(x)
  • 📡 Burst Error Detection: Excellent for detecting consecutive bit errors
  • ⚡ Fast Implementation: Much faster than matrix-based encoding
  • 📘 Examples in use: CRC codes, BCH codes, Reed-Solomon, Hamming codes

Polynomial Representation of Codewords MUST KNOW

Any n-bit codeword c = (c₀, c₁, ..., cₙ₋₁) is represented as:

c(x) = c₀ + c₁x + c₂x² + ... + cₙ₋₁xⁿ⁻¹

Each coefficient cᴵ is from GF(2) = {0, 1}. All arithmetic is mod 2 (XOR).

💡 Codeword to Polynomial

Codeword: 1 0 1 1 0 0 0 (n=7)

c(x) = 1 + 0x + 1x² + 1x³ + 0x⁴ + 0x⁵ + 0x⁶ = 1 + x² + x³

5.2 Code Algebra Basics 5-MARK

📖 Definition

Code Algebra treats cyclic codes as ideals in the polynomial ring R = GF(2)[x]/(xⁿ+1). A cyclic code C is an ideal of this ring, meaning: if c(x) is in C and r(x) is any polynomial in R, then r(x)·c(x) mod(xⁿ+1) is also in C. This ideal structure is what guarantees the cyclic property.

🗣 Hinglish

Code Algebra matlab polynomials ki ring mein kaam karna. Jaise integers mein "even numbers" ek ideal hain (even+even=even, even×anything=even), waise hi cyclic codes polynomials ki ring mein ideals hain. Yeh algebraic structure automatically cyclic property guarantee karta hai!

Ring Structure: R = GF(2)[x] / (xⁿ+1)
  • All polynomial coefficients from GF(2) = {0,1} only
  • Addition = XOR of coefficients (mod 2)
  • Multiplication = polynomial product, then mod (xⁿ+1)
  • Key: xⁿ ≡ 1 mod(xⁿ+1), since xⁿ+1 ≡ 0 means xⁿ = -1 = +1 in GF(2)
Cyclic shift: x·c(x) mod(xⁿ+1) = one cyclic left shift of codeword c

5.3 Galois Fields GF(2) and GF(2ⁿ) 10-MARK TOPIC

📖 Definition — Galois Field

A Galois Field GF(q) (finite field) is a set of q elements with two operations (+ and ·) satisfying all field axioms. GF(q) exists if and only if q = pⁿ where p is prime and n ≥ 1. Named after Evariste Galois (French mathematician, 1811-1832).

🗣 Hinglish

Galois Field ek finite (simit) set hai jisme addition aur multiplication dono properly defined hain. "Finite" isliye kyunki elements ki ginti limited hai. GF(2) mein sirf 2 elements: {0,1}. Digital systems ke liye perfect hai!

GF(2) — The Binary Field MUST KNOW

GF(2) = {0, 1} — simplest finite field, foundation of all binary coding.

GF(2ⁿ) — Extension Field Construction 10-MARK CRITICAL

GF(2ⁿ) has exactly 2ⁿ elements. Built from GF(2) using an irreducible polynomial p(x) of degree n:

GF(2ⁿ) = GF(2)[x] / p(x) [p(x) = irreducible polynomial of degree n]

Elements: all polynomials of degree ≤ n-1 with coefficients from GF(2). Total = 2ⁿ elements.

Introduce primitive element α as root of p(x): p(α) = 0. Then {α°, α¹, ..., α^(2ⁿ-2)} = all 2ⁿ-1 non-zero elements.

🗣 Hinglish

GF(2ⁿ) banane ke liye ek "irreducible polynomial" p(x) chahiye — yeh GF(2) mein factor nahi hota (like prime numbers). Is polynomial ka root α (alpha) introduce karte hain. Ab α ki powers se 2ⁿ elements ka ek field banta hai. GF(8) mein 8 elements hain, primitive element α ki 7 distinct powers hain (phir cycle!)

Properties of GF(2ⁿ) — 5-Mark Answer Ready EXAM LIST

  1. Order: GF(2ⁿ) has exactly 2ⁿ elements (1 zero + 2ⁿ-1 non-zero)
  2. Characteristic 2: a+a=0 for ALL elements a (since 1+1=0 in GF(2))
  3. Primitive Element α: Exists α of order (2ⁿ-1) such that {α°, α¹, ..., α^(2ⁿ-2)} = all non-zero elements
  4. Fermat's Theorem: a^(2ⁿ-1) = 1 for every non-zero a in GF(2ⁿ)
  5. Additive Group: (GF(2ⁿ), +) is an abelian group of order 2ⁿ
  6. Multiplicative Group: (GF(2ⁿ)\{0}, ×) is a cyclic group of order 2ⁿ-1
  7. Subfield: GF(2^m) is a subfield of GF(2ⁿ) if and only if m divides n
  8. Construction: GF(2ⁿ) = GF(2)[x]/p(x) where p(x) is irreducible of degree n
  9. Conjugates: If β is a root of p(x), then β², β⁴, β⁸, ... are also roots (Frobenius)

5.4 Polynomial Operations over GF(2) VERY IMPORTANT

🗣 Hinglish Intro

GF(2) mein polynomial operations normal algebra jaisi hain — bas ek change: subtraction = addition = XOR (kyunki -1=+1 in GF(2)). Koi carry nahi, koi negative numbers nahi. Yeh coding theory ka heart hai!

1. Polynomial Addition — XOR Coefficients

Add coefficient-by-coefficient using XOR. Same-power terms cancel if both are 1 (since 1+1=0).

💡 Example: Addition

a(x) = x⁴+x³+x+1 and b(x) = x³+x²+1

a(x): x⁴ + x³ + 0 + x + 1 b(x): 0 + x³ + x² + 0 + 1 ------------------------------- Sum: x⁴ + 0 + x² + x + 0 = x⁴ + x² + x Binary: [1,1,0,1,1] XOR [0,1,1,0,1] = [1,0,1,1,0] ✓

2. Polynomial Multiplication

Multiply normally (distribute), then XOR coefficients of same powers.

💡 Example: (x+1)(x²+x+1)
= x·(x²+x+1) + 1·(x²+x+1) = (x³+x²+x) + (x²+x+1) = x³ + (1+1)x² + (1+1)x + 1 = x³ + 0 + 0 + 1 = x³ + 1 Note: In GF(2), (x+1)² = x²+1 (NOT x²+2x+1, since 2x=0)

3. Polynomial Division (Long Division) RTU EXAM STAPLE

Find q(x) and r(x) such that: a(x) = q(x)·b(x) + r(x), where deg(r) < deg(b). Subtraction = XOR in GF(2).

💡 Step-by-Step Division: (x⁶+x⁴+x²+x+1) ÷ (x³+x+1)
Dividend: x⁶ + 0 + x⁴ + 0 + x² + x + 1 Divisor: x³ + x + 1 Step 1: x⁶ ÷ x³ = x³ Multiply: x³(x³+x+1) = x⁶+x⁴+x³ XOR with dividend: 0+0+x³+x²+x+1 = x³+x²+x+1 Step 2: x³ ÷ x³ = 1 Multiply: 1(x³+x+1) = x³+x+1 XOR: (x³+x²+x+1)-(x³+x+1) = x² Step 3: deg(x²) = 2 < deg(x³) = 3 => STOP! Result: q(x)=x³+1, r(x)=x² Check: (x³+1)(x³+x+1) + x² = x⁶+x⁴+x²+x+1 ✓
🗣 Hinglish Trick

Division trick: normal long division karo lekin subtract = XOR karo. Jab remainder ka degree divisor se chhota ho jaye, wahan rukna hai. Yahi remainder cyclic encoder mein parity bits banta hai!

Modular Arithmetic — Key Identity

xⁿ ≡ 1 mod(xⁿ+1) [since xⁿ+1≡0 means xⁿ=-1=+1 in GF(2)] x·c(x) mod(xⁿ+1) = one cyclic left shift of codeword c(x)

5.5 Generator Polynomial g(x) 10-MARK GOLD

📖 Definition

The generator polynomial g(x) of an (n,k) cyclic code is the unique monic polynomial of minimum degree (n-k) such that:

  1. g(x) divides (xⁿ+1): g(x) | (xⁿ+1)
  2. Every codeword c(x) is a multiple of g(x)
  3. deg[g(x)] = n-k (equals number of parity bits)
deg[g(x)] = n - k (parity bit count) g(x) | (xⁿ + 1) (g divides xⁿ+1) c(x) = m(x) · g(x) (non-systematic encoding)
🗣 Hinglish

Generator polynomial g(x) ek "master key" jaisa hai. Sare valid codewords isi g(x) ke multiples hote hain — jaise 3 ka pahaada (3,6,9,...). Agar g(x) pata hai to 2ᴷ codewords generate ho sakte hain. Iska degree = (n-k) = parity bits ki sankhya!

Step-by-Step: How to Find g(x) EXAM PROCEDURE

  1. Factorize (xⁿ+1) into irreducible polynomials over GF(2)
  2. Choose factors whose product has degree exactly (n-k)
  3. That product = g(x)
  4. Verify: g(x) divides (xⁿ+1) exactly (no remainder)
💡 Find g(x) for (7,4) Cyclic Code

n=7, k=4 => deg[g(x)] = n-k = 3

Step 1: Factor x⁷+1 over GF(2):

x⁷ + 1 = (x+1)(x³+x+1)(x³+x²+1)

Step 2: Need degree-3 factor(s):

Option A: g(x) = x³+x+1 [degree 3 ✓] Option B: g(x) = x³+x²+1 [degree 3 ✓]

Step 3: Verify Option A divides x⁷+1:

(x⁷+1) / (x³+x+1) = (x+1)(x³+x²+1) [exact, no remainder ✓]

Non-Systematic Encoding 5-MARK

c(x) = m(x) · g(x)

Simple multiplication. Drawback: message bits NOT visible in codeword.

💡 Non-Systematic: g(x)=x³+x+1, message=1101

m(x) = x³+x²+1

c(x) = (x³+x²+1)(x³+x+1) = x⁶+x⁴+x³ + x⁵+x³+x² + x³+x+1 = x⁶+x⁵+x⁴+(1+1+1)x³+x²+x+1 = x⁶+x⁵+x⁴+x³+x²+x+1 [3 mod 2 = 1] Codeword: 1111111

Systematic Encoding — Complete Procedure 10-MARK CRITICAL

Systematic codeword = [parity bits | message bits]. Message bits appear unchanged!

Step 1: Shift: T(x) = xⁿ⁻ᴷ · m(x) Step 2: Divide: T(x) = q(x)·g(x) + r(x) [r(x) = remainder = parity] Step 3: Codeword: c(x) = T(x) + r(x) = xⁿ⁻ᴷ·m(x) + r(x)

Why c(x) is valid: c(x) = q(x)g(x)+r(x)+r(x) = q(x)g(x) since r+r=0. So c(x) mod g(x)=0 ✓

💡 Systematic Encoding: (7,4) code, g(x)=x³+x+1

Example 1: m=1101 => m(x)=x³+x²+1

T(x) = x³(x³+x²+1) = x⁶+x⁵+x³ Divide by x³+x+1: x⁶/x³=x³: sub x⁶+x⁴+x³, rem=x⁵+x⁴ x⁵/x³=x²: sub x⁵+x³+x², rem=x⁴+x³+x² x⁴/x³=x: sub x⁴+x²+x, rem=x³+x x³/x³=1: sub x³+x+1, rem=1 r(x)=1 => parity=001 Codeword: 001 1101

Example 2: m=1010 => m(x)=x³+x

T(x) = x³(x³+x) = x⁶+x⁴ Divide by x³+x+1: x⁶/x³=x³: sub x⁶+x⁴+x³, rem=x³ x³/x³=1: sub x³+x+1, rem=x+1 r(x)=x+1 => parity=011 Codeword: 011 1010

5.6 Parity Check Polynomial h(x) EXAM MUST

📖 Definition

The parity check polynomial h(x) is:

h(x) = (xⁿ + 1) / g(x) [exact division] deg[h(x)] = k [equals message bit count] g(x) · h(x) = xⁿ + 1 [fundamental relationship]

A polynomial v(x) is a valid codeword if and only if: v(x) · h(x) ≡ 0 mod(xⁿ+1)

🗣 Hinglish

Agar g(x) "generator" hai jo codewords banata hai, to h(x) "validator" hai jo check karta hai ki polynomial valid codeword hai ya nahi. Dono milke poora (xⁿ+1) banate hain — perfect pair! Degree hamesha k hoti hai (message length).

💡 Find h(x) for (7,4) code, g(x)=x³+x+1

x⁷+1 = (x+1)(x³+x+1)(x³+x²+1)

h(x) = (x⁷+1)/(x³+x+1) = (x+1)(x³+x²+1) Expand: (x+1)(x³+x²+1) = x⁴+x³+x + x³+x²+1 = x⁴+(1+1)x³+x²+x+1 = x⁴ + x² + x + 1 deg[h(x)] = 4 = k ✓ Verify: (x³+x+1)(x⁴+x²+x+1) = x⁷+1 ✓

5.7 Cyclic Code Encoder — LFSR 10-MARK DIAGRAM

📖 Definition

A cyclic encoder uses a Linear Feedback Shift Register (LFSR) with (n-k) stages to compute parity r(x) = xⁿ⁻ᴷ·m(x) mod g(x). The LFSR connections are determined by the coefficients of g(x).

🗣 Hinglish — LFSR Encoder

LFSR encoder mein (n-k) flip-flops hain ek chain mein. Message bits ek-ek karke input mein jaate hain. g(x) ke coefficients feedback taps determine karte hain. k bits process hone ke baad, register = parity bits! Hardware mein bohot fast hai.

5.8 Cyclic Code Decoder — Syndrome Method IMPORTANT

📖 Definition

The cyclic decoder computes syndrome S(x) = r(x) mod g(x) from received word r(x).

r(x) = c(x) + e(x) [received = sent + error] S(x) = r(x) mod g(x) = [c(x)+e(x)] mod g(x) = e(x) mod g(x) [since c(x) mod g(x)=0]

S(x) depends ONLY on the error e(x), not on c(x). This is what enables error correction!

🗣 Hinglish

Decoder mein bhi ek LFSR hai — received bits r(x) ko g(x) se divide karo. Remainder = syndrome. Syndrome=0 means no error. Syndrome≠0 means error hai aur syndrome ki value se error location pata chalta hai!

Meggitt Decoder — Algorithm 5-MARK

  1. Compute syndrome S(x) = r(x) mod g(x) using LFSR
  2. Check if S(x) matches any stored error syndrome (for single error at position n-1)
  3. If match: flip bit at that position, update S(x), shift corrected bit out
  4. Else: cyclically shift r: r→x·r mod(xⁿ+1), update S: S→x·S mod g(x)
  5. Repeat up to n times
Key property: cyclic shift of r => cyclic shift of S (automatically!)

5.10 RTU Exam Q&A — Complete Bank EXAM READY

All questions based on RTU 5th Sem CSE ITC exam pattern. Answers ready for 2, 5, and 10 marks.

🔹 2-Mark Questions

Q1. Define cyclic code and state its fundamental property.
A cyclic code is a linear block code where every cyclic shift of a codeword is also a valid codeword. If (c₀,c₁,...,cₙ₋₁) is a codeword, then (cₙ₋₁,c₀,...,cₙ₋₂) is also a codeword. In polynomial form: if c(x) is a codeword, then x·c(x) mod(xⁿ+1) is also a codeword.
Q2. Define Galois Field. When does GF(q) exist?
A Galois Field GF(q) is a finite set of q elements with two operations (addition and multiplication) satisfying all field axioms (closure, commutativity, associativity, distributivity, identity, inverse). GF(q) exists if and only if q = pⁿ where p is prime and n ≥ 1. Examples: GF(2)={0,1}, GF(4), GF(8).
Q3. What is a generator polynomial g(x)?
The generator polynomial g(x) of an (n,k) cyclic code is the unique monic polynomial of degree (n-k) that divides (xⁿ+1), and every codeword c(x) is a multiple of g(x). Key properties: deg[g(x)]=n-k, g(x)|(xⁿ+1), code = {m(x)·g(x) : deg m < k}.
Q4. What is syndrome in cyclic code? What does S(x)=0 indicate?
Syndrome S(x) = r(x) mod g(x), where r(x) is the received polynomial. S(x) = 0 indicates r(x) is a valid codeword (no error detected). S(x) ≠ 0 indicates an error. Importantly, S(x) = e(x) mod g(x) depends only on the error polynomial e(x), not on the transmitted codeword c(x).
Q5. Define parity check polynomial h(x).
h(x) = (xⁿ+1)/g(x). Properties: deg[h(x)]=k, g(x)·h(x)=xⁿ+1. A polynomial v(x) is a valid codeword iff v(x)·h(x) ≡ 0 mod(xⁿ+1). h(x) is used to construct the parity check matrix H.
Q6. What is an irreducible polynomial over GF(2)?
A polynomial p(x) over GF(2) is irreducible if it has no factors of lower degree over GF(2), i.e., no roots in GF(2). Test for degree 2 or 3: p(0)≠0 AND p(1)≠0. Example: x²+x+1 is irreducible (p(0)=1≠0, p(1)=1≠0). Example: x²+1=(x+1)² is reducible (p(1)=0).

🔸 5-Mark Questions

Q7. State and explain the basic properties of Galois Field GF(2ⁿ). (5 marks)
Properties of GF(2ⁿ):

1. Order: GF(2ⁿ) has exactly 2ⁿ elements (1 zero + 2ⁿ-1 non-zero).
2. Characteristic 2: a+a=0 for every element a (1+1=0 in GF(2)).
3. Primitive Element: Exists α of order (2ⁿ-1) s.t. {α°,α¹,...,α^(2ⁿ-2)} = all non-zero elements.
4. Fermat's Theorem: a^(2ⁿ-1) = 1 for all non-zero a.
5. Additive Group: (GF(2ⁿ),+) is abelian group of order 2ⁿ.
6. Multiplicative Group: (GF(2ⁿ)\{0},×) is cyclic group of order 2ⁿ-1.
7. Subfield: GF(2^m) ⊂ GF(2ⁿ) iff m|n. GF(2) ⊂ GF(2ⁿ) always.
8. Construction: GF(2ⁿ)=GF(2)[x]/p(x), p(x) irreducible of degree n.

Example GF(8), p(x)=x³+x+1: α³=α+1, elements={0,1,α,α²,α+1,α²+α,α²+α+1,α²+1}, period=7.
Q8. Explain polynomial operations over GF(2) with examples. (5 marks)
Polynomial Operations over GF(2):

All coefficients from {0,1}, arithmetic mod 2. Subtraction = Addition = XOR.

1. Addition (XOR coefficients):
(x⁴+x³+x+1) + (x³+x²+1) = x⁴+(1+1)x³+x²+x+(1+1) = x⁴+x²+x

2. Multiplication (distribute, then XOR like powers):
(x+1)(x²+x+1) = x³+x²+x+x²+x+1 = x³+(1+1)x²+(1+1)x+1 = x³+1

3. Division (long division, subtract=XOR):
(x⁶+x⁴+x²+x+1) ÷ (x³+x+1):
• x⁶/x³=x³: sub x⁶+x⁴+x³, rem=x³+x²+x+1
• x³/x³=1: sub x³+x+1, rem=x²
• deg(x²) < 3: STOP. q(x)=x³+1, r(x)=x²

Key rules: No negative numbers. No carrying. 1+1=0. All operations mod 2.

Q11. Explain systematic encoding with example. Encode m=1001 using (7,4) code, g(x)=x³+x²+1. (5 marks)
Systematic Encoding Steps:
1. T(x) = xⁿ⁻ᴷ·m(x) [shift message left by n-k positions]
2. r(x) = T(x) mod g(x) [remainder = parity bits]
3. c(x) = T(x)+r(x) [add back remainder to get divisible codeword]

Example: m=1001, m(x)=x³+1, g(x)=x³+x²+1, n=7,k=4:

T(x) = x³(x³+1) = x⁶+x³

Divide x⁶+x³ by x³+x²+1:
x⁶/x³=x³: sub x⁶+x⁵+x³, rem=x⁵
x⁵/x³=x²: sub x⁵+x⁴+x², rem=x⁴+x²
x⁴/x³=x: sub x⁴+x³+x, rem=x³+x²+x
x³/x³=1: sub x³+x²+1, rem=x+1
r(x)=x+1 => parity bits = 011

Codeword c = 011 1001 (parity=011, message=1001)
Verify: c(x) mod g(x) = 0 ✓

Q12. Describe the encoder and decoder for cyclic codes with block diagrams. Explain syndrome-based error detection and Meggitt decoding. (10 marks)
PART A — CYCLIC ENCODER:

Uses LFSR (Linear Feedback Shift Register) with (n-k) stages.

Structure: (n-k) D flip-flops in series. Feedback XOR gates at positions where g(x) coefficient = 1. For g(x)=x³+x+1: taps at x³ (main feedback always present) and x¹ (g₁=1).

Phase 1 (k clock cycles):
• Message bits mᴷ₋₁,...,m₀ enter serially
• Switch connects to output channel → message flows to output
• LFSR computes remainder xⁿ⁻ᴷ·m(x) mod g(x) simultaneously

Phase 2 (n-k clock cycles):
• Input grounded (0s enter LFSR)
• Switch connects register to output
• Register contents shift out as parity bits r₀,...,rₙ₋ᴷ₋₁

Output: [message k bits][parity n-k bits] = systematic (n,k) codeword

PART B — CYCLIC DECODER:

Same LFSR structure computes syndrome S(x) = r(x) mod g(x).

Operation:
1. Load received r into n-bit buffer AND feed into syndrome LFSR simultaneously
2. After n clocks: LFSR = S(x) = r(x) mod g(x)
3. Decision: S(x)=0 → no error, output last k bits. S(x)≠0 → error, apply Meggitt.

PART C — SYNDROME & MEGGITT DECODER:

r(x) = c(x)+e(x) → S(x)=e(x) mod g(x) [syndrome = function of error only!]

Pre-stored table: for each correctable error pattern eᵢ, store Sᵢ=eᵢ mod g(x).

Meggitt Algorithm:
1. Compute S(x) from r(x)
2. If S(x) matches table entry for error at position n-1: flip that bit, update syndrome
3. Else: cyclically shift r → x·r mod(xⁿ+1), update S → x·S mod g(x)
4. Repeat until all errors corrected or n shifts done

Key: Cyclic shift of r → syndrome also shifts cyclically. This allows sequential scanning without recomputation.

Example: Received r, S(x)=110 → table says error at position 4 → flip bit 4 → corrected codeword. ✓
Q13. Explain Galois Field GF(2ⁿ), construction using irreducible polynomial, and polynomial operations over GF(2). Give complete example. (10 marks)
PART A — GALOIS FIELD GF(2ⁿ):

A finite field with 2ⁿ elements. GF(q) exists iff q=pⁿ (p prime). For digital comms: GF(2ⁿ).

Constructed as GF(2)[x]/p(x) where p(x) is irreducible of degree n over GF(2).

Properties: 2ⁿ elements; characteristic 2 (a+a=0); multiplicative group cyclic of order 2ⁿ-1; primitive element α with α^(2ⁿ-1)=1; GF(2^m) ⊂ GF(2ⁿ) iff m|n.

PART B — GF(8) COMPLETE EXAMPLE, p(x)=x³+x+1:

Verify: p(0)=1≠0, p(1)=1≠0 → irreducible ✓
Root α: α³+α+1=0 → α³=α+1

Elements: 0, 1, α, α², α+1, α²+α, α²+α+1, α²+1
Vectors: 000, 001, 010, 100, 011, 110, 111, 101
Period = 7 = 2³-1. α⁷=α°=1 ✓

GF(8) Arithmetic:
α⁴+α³ = (α²+α)+(α+1) = α²+(1+1)α+1 = α²+1 = α⁶ ✓
α⁴·α³ = α⁷ = α° = 1 ✓

PART C — POLYNOMIAL OPERATIONS OVER GF(2):

Addition (XOR coefficients):
(x²+x+1)+(x²+1) = (1+1)x²+x+(1+1) = x (middle terms cancel)

Multiplication (normal expand, XOR like terms):
(x+1)² = x²+2x+1 = x²+0+1 = x²+1 [2x=0 in GF(2)]

Division:
(x⁷+1)/(x³+x+1) = (x⁴+x²+x+1) [exact, since x⁷+1=(x³+x+1)·h(x)]

Relevance to Cyclic Codes:
• g(x) built from factors of xⁿ+1 over GF(2)
• BCH codes use minimal polynomials of α^i over GF(2ⁿ)
• Primitive element α locates error positions in decoding
• All encoding/decoding arithmetic done as polynomial operations over GF(2)
Q14. What is a cyclic code? Explain algebraic structure, generator polynomial, and systematic encoding. Encode m=1100, m=1010, m=0011 using (7,4) code with g(x)=x³+x+1. (10 marks)
CYCLIC CODE & ALGEBRAIC STRUCTURE:

A cyclic code C(n,k) is a linear code where every cyclic shift of a codeword is valid. Algebraically, C is an ideal in ring R=GF(2)[x]/(xⁿ+1), generated by g(x).

Ideal property: if c(x)∈C and r(x)∈R, then r(x)·c(x) mod(xⁿ+1) ∈ C.
The cyclic shift x·c(x) mod(xⁿ+1) is automatically in C. This is why cyclic property holds!

Generator Polynomial:
g(x) = unique monic poly of degree n-k dividing xⁿ+1. All 2ᴷ codewords are multiples of g(x).

Systematic Encoding: c(x)=xⁿ⁻ᴷm(x) + [xⁿ⁻ᴷm(x) mod g(x)]

Three Encoding Examples (n=7,k=4,g(x)=x³+x+1):

1. m=1100 → m(x)=x³+x²:
T(x)=x³(x³+x²)=x⁶+x⁵
Divide: x⁶/x³=x³→rem=x⁵+x⁴; x⁵/x³=x²→rem=x⁴+x³+x²; x⁴/x³=x→rem=x³+x; x³/x³=1→rem=1
r(x)=1→parity=001. Codeword: 001 1100

2. m=1010 → m(x)=x³+x:
T(x)=x³(x³+x)=x⁶+x⁴
Divide: x⁶/x³=x³→sub x⁶+x⁴+x³,rem=x³; x³/x³=1→sub x³+x+1,rem=x+1
r(x)=x+1→parity=011. Codeword: 011 1010

3. m=0011 → m(x)=x+1:
T(x)=x³(x+1)=x⁴+x³
Divide: x⁴/x³=x→sub x⁴+x²+x,rem=x³+x²+x; x³/x³=1→sub x³+x+1,rem=x²+1
r(x)=x²+1→parity=101. Codeword: 101 0011

All verified: c(x) mod g(x) = 0 ✓
Q15. Explain in detail: Galois Field concept, irreducible polynomial, primitive element, and how these relate to cyclic code construction. (10 marks)
1. GALOIS FIELD CONCEPT:
A Galois Field GF(q) is a finite algebraic structure with q=pⁿ elements where both addition and multiplication are well-defined and satisfy all field axioms. For binary coding: GF(2)={0,1} is the base field. GF(2ⁿ) extends it for more powerful codes.

2. IRREDUCIBLE POLYNOMIAL:
A polynomial p(x) over GF(2) is irreducible if it has no polynomial factors of lower degree over GF(2). Equivalently, it has no roots in GF(2).
Test: for degree 2 or 3, check p(0)≠0 AND p(1)≠0.
Example: x²+x+1: p(0)=1, p(1)=1 → no roots → irreducible ✓
Example: x³+1=(x+1)(x²+x+1): reducible ❌

3. PRIMITIVE ELEMENT:
An element α of GF(2ⁿ) is primitive if its multiplicative order = 2ⁿ-1. This means {α°,α¹,...,α^(2ⁿ-2)} generates ALL 2ⁿ-1 non-zero elements.
In GF(8) with p(x)=x³+x+1: α⁷=1, α has order 7=2³-1 → α is primitive ✓
Fermat: α^(2ⁿ-1)=1 for all non-zero elements.

4. RELATIONSHIP TO CYCLIC CODES:
• Basic cyclic codes (length n) operate over GF(2) — polynomials with binary coefficients
• xⁿ+1 must be factored over GF(2) to find g(x)
• BCH Codes: defined using GF(2ⁿ); g(x)=LCM of minimal polynomials of α,α²,...,α^(2t) for t-error correction
• Reed-Solomon: symbols ARE elements of GF(2ⁿ); extremely powerful burst error correction
• Primitive element α locates error positions in BCH/RS decoding (error locator polynomial)

Summary:
GF(2) → binary arithmetic for basic cyclic codes
Irreducible p(x) → builds GF(2ⁿ), defines α relations
Primitive α → generates all field elements, enables BCH code construction
g(x)|xⁿ+1 → all codewords are multiples of g(x), enabling LFSR encoding
