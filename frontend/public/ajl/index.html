Oral Exam Preparation

Essential Lab Viva Voce Questions

Q1. What is the core difference between AWT and Swing?

AWT components are heavyweight, platform-dependent, and use native OS peers. Swing components are lightweight, written purely in Java, highly customizable, and have a pluggable look-and-feel (PLAF).

Q2. Why use PreparedStatement over Statement in JDBC?

PreparedStatement is precompiled by the database engine, offering significantly faster execution for parameterized repeated queries and built-in protection against SQL Injection attacks.

Q3. Explain the lifecycle of a Java Servlet.

The lifecycle consists of three primary methods: init() (called once on initialization), service() (invoked per request, dispatching to doGet() or doPost() in separate worker threads), and destroy() (called upon server shutdown).

Q4. What is the role of rmiregistry in RMI?

The rmiregistry is a centralized naming service running on port 1099. The server binds its remote object stub with a name using Naming.rebind(), and the client queries it via Naming.lookup().

Q5. What is the difference between TCP Socket and ServerSocket?

ServerSocket runs on the server listening on a specific TCP port waiting for incoming connection requests via accept(). Socket represents the active two-way streaming communication channel between client and server.

Q6. How does JSP differ from a Servlet?

JSP is document-centric (HTML mixed with Java scriptlet tags) designed for the View layer. Servlets are code-centric (Java classes generating HTML) suited for Controller logic. Tomcat automatically converts JSP into a Servlet behind the scenes.
