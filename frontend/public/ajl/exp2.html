Experiment 2: Applet (college departments)

Show a list of college departments. The department you click appears in a text field.

Read this first

  • The real applet (Version A) needs JDK 8, because appletviewer and java.applet were removed from newer JDKs. Your laptop has JDK 26, so Version A will not compile there.
  • The Panel version (Version B) runs on any JDK, including your laptop. It has the same logic, so use it to practise.
  • In the exam, check the lab PC first. If java -version shows 1.8, write Version A.

Version A: classic applet (JDK 8 only)

Click Yes when Notepad asks to create the file.

Command Prompt
cd %USERPROFILE%\Desktop\ajl
notepad DeptApplet.java
DeptApplet.java
import java.applet.Applet;
import java.awt.*;
import java.awt.event.*;

/* <applet code="DeptApplet.class" width="350" height="250"></applet> */

public class DeptApplet extends Applet implements ItemListener {
    List list;
    TextField tf;

    public void init() {
        list = new List(5);
        list.add("Computer Science");
        list.add("Electronics");
        list.add("Mechanical");
        list.add("Civil");
        list.add("Electrical");

        tf = new TextField(25);

        add(new Label("Select Department:"));
        add(list);
        add(new Label("You selected:"));
        add(tf);

        list.addItemListener(this);
    }

    public void itemStateChanged(ItemEvent e) {
        tf.setText(list.getSelectedItem());
    }
}
Command Prompt
javac DeptApplet.java
appletviewer DeptApplet.java

The comment with the applet tag at the top is what appletviewer reads. Do not delete it. An applet has no main() method.

import java.awt.*;
import java.awt.event.*;

public class DeptPanel extends Panel implements ItemListener {
    List list;
    TextField tf;

    public void init() {
        list = new List(5);
        list.add("Computer Science");
        list.add("Electronics");
        list.add("Mechanical");
        list.add("Civil");
        list.add("Electrical");

        tf = new TextField(25);

        add(new Label("Select Department:"));
        add(list);
        add(new Label("You selected:"));
        add(tf);

        list.addItemListener(this);
    }

    public void itemStateChanged(ItemEvent e) {
        tf.setText(list.getSelectedItem());
    }

    public static void main(String[] args) {
        Frame f = new Frame("Departments");
        DeptPanel p = new DeptPanel();
        p.init();
        f.add(p);
        f.setSize(350, 250);
        f.setVisible(true);
        f.addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent e) {
                System.exit(0);
            }
        });
    }
}
Command Prompt
javac DeptPanel.java
java DeptPanel

Expected result for both versions: a list of departments. Click one and its name appears in the text field.

Applet lifecycle

  • init(): runs once when the applet loads. Create components here.
  • start(): runs each time the applet becomes visible.
  • paint(): runs whenever the display needs redrawing.
  • stop(): runs when the user leaves the page.
  • destroy(): runs once at the end to release resources.

How it works

  • extends Applet makes the class an applet. It runs inside a browser or appletviewer, not on its own.
  • List is the AWT list component. list.getSelectedItem() returns the clicked item.
  • addItemListener(this) and itemStateChanged() follow the same event pattern as Experiment 1.
  • Version B swaps Applet for Panel and adds a main() so it can run as a normal program.

Viva answers

  • Applet vs application: an applet runs inside a browser or appletviewer, has no main(), and has security restrictions such as no local file access. An application runs standalone with main().
  • Why are applets obsolete? Browsers removed Java plugin support, and the Applet API was deprecated and then removed from the JDK.
  • Hierarchy: Object, Component, Container, Panel, Applet.
  • init() vs start(): init() is called once on load. start() is called every time the applet becomes active again.
  • Passing parameters: use the param tag in the applet tag, and read it with getParameter("name").
