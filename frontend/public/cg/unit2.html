📗 UNIT 2 — Basics of Computer Graphics

Applications · Display Devices · Random & Raster Scan Systems · Graphics Input Devices · Graphics Software & Standards  |  Hours: 06

English

The basics of computer graphics cover the fundamental hardware (display devices, input devices) and software (graphics libraries, standards) that form the infrastructure for all graphics applications. Understanding how images are physically displayed on screen — pixel grids, scan lines, refresh rates — is essential before studying any rendering algorithm.

Hinglish

Pehle ye samajhna zaroori hai ki screen pe actually image kaise banta hai — screen pe lakhon chhote-chhote dots (pixels) hote hain, inhe sahi colour dene se image banta hai. Display hardware (monitor) aur input hardware (mouse, tablet) ke concepts + graphics software/APIs samajhe bina algorithms samajhna mushkil hai.

2. Display Devices High ⭐⭐⭐⭐

English

A display device converts digital image data (stored in a frame buffer) into visible light patterns on a screen. Key characteristics: resolution (total pixel count), refresh rate (how many times per second the screen redraws, in Hz), dot pitch (distance between adjacent same-colour phosphor dots — smaller = sharper), and aspect ratio (width:height ratio).

Hinglish

Display device wo hardware hai jo computer ke numbers (pixel colour data) ko screen pe visible light mein convert karta hai. Resolution = kitne pixels hain (1920×1080 = Full HD). Refresh rate = ek second mein screen kitni baar dubara draw hoti hai (60Hz, 144Hz). Dot pitch = pixels ke beech ki doori (jitni kam, utni sharp image).

3. Raster Scan vs Random Scan Systems High ⭐⭐⭐⭐⭐ (Most Important — comparison guaranteed every year)

Fig 2.1 — Raster scan covers every pixel line-by-line; Random/Vector scan draws only the actual lines needed

English

A Raster Scan System divides the screen into a rectangular grid of pixels (the frame buffer stores one colour value per pixel). The electron beam (CRT) or refresh logic sweeps left-to-right, top-to-bottom across every scan line, refreshing the entire screen at the refresh rate (typically 60–120 Hz) — regardless of what is drawn. Almost all modern displays are raster-based.

A Random Scan System (Vector display) directs the electron beam only to positions where lines/shapes are to be drawn — it does not cover the entire screen but only traces the picture's geometric components. The picture is stored as a display list of drawing commands.

Hinglish

Raster scan = har baar poori screen ka har ek pixel refresh hota hai (chahe kuch bhi draw ho ya nahi) — jaise ek painter puri canvas line-by-line paint kare. Random scan = sirf wahi lines draw karo jo actually chahiye — jaise ek painter seedha required shape trace kare, beech ke blank areas chhod ke. Modern screens (LCD/LED) sab raster hain.

4. Frame Buffer & Pixel Concepts High ⭐⭐⭐

English

A frame buffer (also called raster) is a dedicated area of memory that stores the colour value of every pixel on the screen. For a 1920×1080 display with 24-bit colour (8 bits each for R, G, B), the frame buffer size is 1920 × 1080 × 3 bytes = ~6.2 MB. The display controller continuously reads this buffer to refresh the screen at the set refresh rate.

A pixel (picture element) is the smallest addressable unit of a raster display, represented by a coordinate pair (x, y) and a colour value.

Hinglish

Frame buffer = RAM ka ek special area jahan har pixel ka colour store hota hai. Screen pe jo bhi dikhta hai, woh sab is buffer se read hota hai. Jab tum koi pixel ka colour change karte ho (drawing algorithm se), actually tum is buffer mein ek memory location update kar rahe ho — display controller automatically updated value screen pe dikhata hai.

Frame Buffer Size = Width × Height × Colour Depth (bits/pixel) Example (Full HD, 24-bit): = 1920 × 1080 × 24 bits = 49,766,400 bits ≈ 6.2 MB

5. Graphics Input Devices Medium ⭐⭐⭐

English

Graphics input devices allow users to interact with and provide geometric/coordinate data to graphics applications. They are classified by their logical input function into: locator (position data), stroke (sequence of positions), valuator (scalar value), choice (menu selection), pick (selecting objects), and string (text input).

Hinglish

Graphics input devices wo hardware hai jisse tum computer ko coordinate/geometric data dete ho. Mouse se click karte ho to x,y position computer ko milti hai (locator). Graphics tablet pe draw karte ho (stroke). Dial/slider se value set karte ho (valuator). Ye sab input devices different logical functions serve karte hain.

6. Graphics Software & Standards Medium ⭐⭐⭐

English

Graphics software provides programmers and users with the tools to create and manipulate graphics, ranging from low-level hardware abstraction APIs to high-level applications. Graphics standards are internationally agreed specifications that define how graphics APIs should behave, enabling portability of graphics programs across different hardware.

Hinglish

Agar har manufacturer alag-alag API/commands use kare, to ek graphics program ek computer pe chalega, doosre pe nahi. Graphics standards (jaise OpenGL, GKS) isliye banaye gaye ki ek hi code sab hardware pe same tarah kaam kare — same function calls, same results, different underlying hardware. Ye "write once, run anywhere" concept graphics ke liye hai.

Levels of Graphics Software

  • Hardware-Level: Device drivers that directly control display hardware (not used by application programmers).
  • Low-Level (Primitive) API: Drawing primitives — points, lines, polygons. E.g. OpenGL core, DirectX.
  • Mid-Level (Geometric Modeling): 3D scene construction tools, transformation/clipping functions. E.g. OpenGL with GLUT.
  • High-Level (Application Packages): End-user tools — AutoCAD (CAD), Blender (3D modeling/animation), Photoshop (2D graphics), Unity/Unreal (game engines).

Example — OpenGL (most asked standard)

A simple OpenGL snippet to draw a coloured triangle (the "Hello World" of graphics):

glBegin(GL_TRIANGLES); glColor3f(1.0, 0.0, 0.0); // Red glVertex2f(0.0, 0.5); // Top glColor3f(0.0, 1.0, 0.0); // Green glVertex2f(-0.5, -0.5); // Bottom-left glColor3f(0.0, 0.0, 1.0); // Blue glVertex2f(0.5, -0.5); // Bottom-right glEnd();

This sends three vertex positions and colours to the GPU; OpenGL handles the rasterization (filling in the pixels) automatically.

7. Colour Depth & Resolution Medium ⭐⭐

Resolution = number of addressable pixels in horizontal × vertical direction (e.g., 1920×1080). Higher resolution = sharper image but requires more frame buffer memory and processing.

Colour Depth = number of bits used to represent the colour of one pixel.

Hinglish Trick

Raster vs Random: Raster = TV/Monitor (Pura grid ek line se scan hota hai, aliasing aati hai). Random = Pen plotter (Sirf line pe beam ghumti hai, smooth sharp lines, koi aliasing nahi!).

Unit 2 · Definition
Q1. Define raster scan and random scan display systems. Compare them. ★★★★★ 7-10 Marks — guaranteed every year
10 Marks

Raster Scan: Electron beam/refresh logic scans all pixels line-by-line, left→right, top→bottom. Image stored as pixel array in frame buffer. Used in all modern monitors, TVs, mobiles. Supports full colour and any image type but shows aliasing on diagonal lines.

Random Scan (Vector): Beam directed only to positions where lines/curves are to be drawn. Image stored as display list of drawing commands. Mathematically precise lines (no aliasing), but only suitable for line drawings, not photographic images. Historical (oscilloscopes, old CAD plotters).

Q4. What are graphics standards? Explain GKS, PHIGS, and OpenGL. ★★★★ 5-7 Marks
5 Marks

Graphics standards are agreed specifications for graphics APIs ensuring portability across hardware. GKS (1985) — first ISO standard, 2D device-independent graphics. Unit 2 · Types
Q5. Explain different display technologies (CRT, LCD, LED, OLED) and compare them. ★★★ 5 Marks
5 Marks

CRT: Electron beam on phosphor — bulky, accurate colour, historical. LCD: Liquid crystals + backlight — thin, efficient, standard today. LED: LCD with LED backlight (brighter, thinner). OLED: Per-pixel light emission — true blacks, perfect contrast, flexible (phones, TVs), expensive. Full comparison table given above.

Unit 2 · Numerical
Q6. Calculate the frame buffer memory required for a 1024×768 display with 8-bit colour depth. Also for 16-bit and 24-bit. ★★★★ 5 Marks numerical
5 Marks

8-bit: 1024 × 768 × 8 = 6,291,456 bits = 768 KB

16-bit: 1024 × 768 × 16 = 12,582,912 bits = 1.5 MB

24-bit: 1024 × 768 × 24 = 18,874,368 bits = 2.25 MB

(Divide bits by 8 for bytes, then by 1024 for KB, then by 1024 for MB.)

Unit 2 · Conceptual
Q7. What are the applications of computer graphics? Explain any four with examples. ★★★ 5 Marks
5 Marks

Major applications: (1) Entertainment — video games, animated movies, VFX (Avatar, Avengers use CGI). (2) CAD/CAM — AutoCAD for engineering design, saves months of manual drafting. (3) Medical Imaging — MRI/CT volume rendering helps surgeons plan operations. (4) Scientific Visualization — weather forecasting, molecular dynamics rendered as 3D models. (5) AR/VR — VR training simulators for pilots/surgeons.

Unit 2 · Theory
Q8. Differentiate between pixel and resolution. What factors affect image quality on a display? ★★ 3-5 Marks
3 Marks

Pixel = smallest addressable display unit with (x,y) position and colour. Resolution = total number of pixels (horizontal × vertical). Factors affecting quality: resolution (more pixels = sharper), colour depth (more bits = more colours), refresh rate (higher = less flicker), dot pitch (smaller = sharper), screen size (same resolution on larger screen = lower pixel density = less sharp).
