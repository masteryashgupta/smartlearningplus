1. File Concept High ⭐⭐⭐⭐

English

A file is a named collection of related information stored on secondary storage (disk). It is the smallest allotment of logical secondary storage. The OS provides a uniform logical view of information storage through the file system.

Hinglish

File ek named collection hai data ki — jaise ek folder mein papers hote hain, waise hi secondary storage pe data organized form mein store hota hai. OS iske saath deal karta hai as a unit — create, open, read, write, close, delete.

File Operations

Basic Operations

  • Create — Naya file banao, space allocate karo
  • Write — Data file mein likho (write pointer use hota hai)
  • Read — Data file se padho (read pointer use hota hai)
  • Seek — File pointer ko specific position pe move karo

Management Operations

  • Delete — File hatao, space release karo
  • Truncate — File content clear karo but file rakhna hai
  • Open — File ko use ke liye ready karo (FCB memory mein laao)
  • Close — FCB wapas disk pe save karo

A Directory is a collection of nodes containing information about all files organized in a structured way. It maps file names to file control blocks (FCBs/inodes).

5. Access Matrix (Protection Matrix) High ⭐⭐⭐⭐

English

An Access Matrix is a security model that defines access rights. Rows represent domains (users/processes) and columns represent objects (files/resources). Each cell [domain, object] specifies the allowed operations (read, write, execute).

Hinglish

Access Matrix ek table hai — row mein users, columns mein files. Har cell mein likha hota hai ki us user ko us file pe kya permission hai (r=read, w=write, x=execute). Jaise Linux mein rwxr-xr-- — owner ko rwx, group ko r-x, others ko r--.

Adminread, write, executeread, writeread, write, execute

Implementation methods:

  • Access Control List (ACL) — Column of access matrix stored with each object (file). UNIX permission bits are simplified ACL.
  • Capability List — Row of access matrix stored with each domain (user/process). Process has a list of capabilities (tickets) it can use.

6. File Security High ⭐⭐⭐

English

File Security is the protection of files from unauthorized access, modification, or destruction. Main threats: unauthorized access (confidentiality), unauthorized modification (integrity), unauthorized deletion (availability).

Security Mechanisms:

  • Access Control Lists (ACL) — Per-file list of who can do what.
  • Encryption — Data encrypted so only authorized users can read (AES, RSA).
  • Audit Logs — Record all file access/modification attempts for forensics.
  • Backup — Regular copies to recover from accidental deletion or ransomware.
  • File Permissions (UNIX rwx) — Owner, Group, Others each get read/write/execute bits.

7. User Authentication High ⭐⭐⭐

English

User Authentication is the process of verifying the identity of a user before granting access to system resources. It answers the question "Who are you?" before authorization answers "What can you do?"

RTU EXAM Q&A
Q1. Define file. List and explain file attributes. ★★★★ 5 Marks
5 Marks

File = named collection of related data on secondary storage. Attributes: Name (human-readable), Identifier (inode), Type (extension), Location (disk block pointer), Size (bytes), Protection (rwx permissions), Time & Date (creation/modification), User ID (owner). Full attribute table above.

RTU EXAM Q&A
Q2. Explain directory structures with diagrams: Single-Level, Two-Level, Tree, Acyclic Graph. ★★★★★ 10 Marks — guaranteed
10 Marks

Single-level = all files in one directory (no organization, name conflicts). Two-level = one UFD per user under master MFD (path: /user/file). Tree = hierarchical, subdirectories, absolute/relative paths (modern OS standard). Acyclic Graph = shared files via hard links / symlinks without cycles. Full comparison table above.

RTU EXAM Q&A
Q3. Explain access matrix. Distinguish ACL and Capability List. ★★★★ 7 Marks
7 Marks

Access Matrix = table of domain × object where each cell = allowed operations (read/write/execute). ACL = column of matrix stored with each object (file) — "who can access this file." Capability List = row stored with each process/user — "what files can this process access." UNIX permission bits (rwxr-xr--) = simplified ACL per file for owner, group, others.

RTU EXAM Q&A
Q4. What are file access methods? Explain sequential, direct, and indexed sequential. ★★★ 5 Marks
5 Marks

Sequential = read/write records in order (pointer advances); used for log files. Direct = any record accessible by block/record number; used for databases. Index Sequential = index file maps keys to blocks — hybrid of both; used in ISAM. Sequential most common for streaming data; direct for random-access applications.

RTU EXAM Q&A
Q5. What is file security? Explain its threats and mechanisms. ★★★★ 5 Marks
5 Marks

File security = protecting files from unauthorized access/modification/deletion. Threats: confidentiality breach (unauthorized read), integrity attack (unauthorized modify), availability attack (delete/ransomware). Mechanisms: ACL, encryption, audit logs, backup, UNIX permission bits (rwx for owner/group/others).

RTU EXAM Q&A
Q6. Define user authentication. What are its types? ★★★ 5 Marks
5 Marks

Authentication = verifying user identity before granting access. Types: (1) Knowledge-based — passwords, PINs. (2) Possession-based — smart cards, OTP tokens. (3) Biometric-based — fingerprint, iris scan, face recognition. (4) Multi-Factor Authentication (MFA) — combining 2+ types. MFA is strongest since attacker needs to compromise multiple factors.
