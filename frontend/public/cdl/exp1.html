Phases of a compiler

A compiler translates source code into machine code in stages. The output of each phase is the input of the next.

  1. Lexical analysis: reads characters and groups them into tokens (keywords, identifiers, operators). Exp 2 to 9 belong here.
  2. Syntax analysis: checks tokens against the grammar and builds a parse tree. Exp 10 to 13 belong here.
  3. Semantic analysis: checks meaning, such as type matching and declared variables.
  4. Intermediate code generation: produces machine-independent code such as three-address code.
  5. Code optimization: makes the intermediate code faster or smaller.
  6. Code generation: produces the target machine code.

The symbol table (Exp 6) and the error handler are used by every phase.

Viva questions

What is a compiler?

A program that translates a whole source program written in a high-level language into machine code (or another target language) and reports errors.

Compiler vs interpreter?

A compiler translates the whole program first and then runs the result. An interpreter translates and runs one statement at a time. Compiled programs usually run faster.

Name the phases of a compiler.

Lexical analysis, syntax analysis, semantic analysis, intermediate code generation, code optimization and code generation.

What are front end and back end?

The front end (lexical, syntax, semantic analysis, intermediate code) depends on the source language. The back end (optimization, code generation) depends on the target machine.

What is a token, a lexeme and a pattern?

A lexeme is the actual text, like count. A token is its category, like identifier. A pattern is the rule that describes the lexemes of a token.

What is the role of the symbol table?

It stores information about names (type, address, scope) and is used by all phases.

What are LEX and YACC?

LEX generates a lexical analyzer from regular expressions. YACC generates a parser from a grammar.

What is the difference between LL and LR parsers?

LL parsers are top-down: they read left to right and build a leftmost derivation. LR parsers are bottom-up: they read left to right and build a rightmost derivation in reverse. LR handles more grammars.

What is a cross compiler?

A compiler that runs on one machine but produces code for a different machine.
