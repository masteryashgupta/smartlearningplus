Experiment 8: Minimum Cost Spanning Tree using Prim's Algorithm

Aim: Find Minimum Cost Spanning Tree of a given undirected graph using Prim's algorithm.

Source code

This is the program from the lab manual, unchanged. Compile it with gcc aoa_exp8.c -o exp8 and run ./exp8 (on Windows with MinGW, exp8).

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define INF 9999
int main()
{
    int n, i, j;
    clock_t start, end;
    double cpu_time_used;
    printf("Enter number of vertices: ");
    scanf("%d", &n);
    int cost[n][n];
    printf("Enter the adjacency/cost matrix (enter %d for no edge):\n", INF);
    for(i = 0; i < n; i++)
    {
        for(j = 0; j < n; j++)
        {
            printf("cost[%d][%d]: ", i, j);
            scanf("%d", &cost[i][j]);
        }
    }
    int visited[n];
    for(i = 0; i < n; i++)
    visited[i] = 0;
    int edgeCount = 0;
    int totalCost = 0;
    visited[0] = 1;
    // Start timing
    start = clock();
    printf("\nEdges in Minimum Cost Spanning Tree (Prim's Algorithm):\n");
    while(edgeCount < n - 1)
    {
        int min = INF, a = -1, b = -1;
        for(i = 0; i < n; i++)
        {
            if(visited[i])
            {
                for(j = 0; j < n; j++)
                {
                    if(!visited[j] && cost[i][j] != 0 && cost[i][j] < min)
                    {
                        min = cost[i][j];
                        a = i;
                        b = j;
                    }
                }
            }
        }
        if(a != -1 && b != -1)
        {
            printf("Edge %d: (%d -> %d) cost = %d\n", edgeCount + 1, a, b, min);
            totalCost += min;
            visited[b] = 1;
            edgeCount++;
        }
    }
    // End timing
    end = clock();
    cpu_time_used = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("\nMinimum Cost of Spanning Tree = %d\n", totalCost);
    printf("\nTime Required = %f seconds\n", cpu_time_used);
    return 0;
}

Explanation (from the manual)

Concept

Consider a set of cities ("vertices") connected by roads ("edges"), each road having its own cost. The goal is to connect all cities so that the total cost is as small as possible, every city remains reachable, and no cycles (loops) are formed. This final connected structure is called the Minimum Cost Spanning Tree (MST).

Prim's Algorithm idea: start from any one city (e.g. city 0). Then repeatedly find the cheapest road that connects the currently-connected group of cities to any new (not-yet-connected) city, and add that city to the group. Repeat until every city is connected. Prim's Algorithm behaves like a "growing tree" — a single connected group keeps expanding, always choosing the cheapest next edge available.

Worked Example

  5 cities (0 to 4), with roads and their costs:
  0-1 = 2, 0-3 = 6, 1-2 = 3, 1-3 = 8, 1-4 = 5, 2-4 = 7, 3-4 = 9
  Start at city 0, connected group = {0}
  Step 1: cheapest road out of {0} is 0-1 (cost=2). Group = {0, 1}
  Step 2: cheapest road out of {0,1} is 1-2 (cost=3). Group = {0, 1, 2}
  Step 3: cheapest road out of {0,1,2} is 1-4 (cost=5). Group = {0, 1, 2, 4}
  Step 4: cheapest road out of {0,1,2,4} is 0-3 (cost=6). Group = {0, 1, 2, 3, 4} — all
  cities connected!
  Total minimum cost = 2+3+5+6 = 16

Time Complexity

In this simple adjacency-matrix implementation, Prim's Algorithm takes O(n²) time, where n is the number of cities. Faster (priority-queue based) versions exist for very large graphs, but this simple version works well for small to medium-sized graphs.

What the Program Does

  1. The user enters the number of vertices (cities).
  2. The user enters the full cost matrix (the cost between every pair of cities; 9999 indicates no direct road).
  3. Starting from city 0, the program repeatedly finds the cheapest edge leading out of the connected group and adds it to the MST (the process above).
  4. Each chosen edge is printed, along with its cost.
  5. The total minimum cost is printed at the end.
  6. The time taken (in seconds) is displayed.

In short: start from one city, always grab the cheapest road leading to a new city, and repeat until every city is connected.

Viva questions

What is a spanning tree?

A subgraph that connects all vertices of a graph with no cycle. It has V - 1 edges.

What is a Minimum Cost Spanning Tree?

The spanning tree whose total edge weight is the smallest.

Explain Prim’s algorithm.

Start from any vertex and repeatedly add the cheapest edge that joins a vertex in the tree to a vertex outside it, until all vertices are in the tree.

What is the time complexity of Prim’s algorithm?

O(V²) with an adjacency matrix, as in this program. It is O(E log V) with a heap.

Why is 9999 entered in the cost matrix?

It stands for infinity, meaning there is no edge between those two vertices.

Compare Prim’s and Kruskal’s algorithms.

Prim grows one tree vertex by vertex and suits dense graphs. Kruskal sorts the edges and joins components, and suits sparse graphs.

How many edges does the tree have?

V - 1, where V is the number of vertices. For example, 3 edges for 4 vertices.

Is the minimum spanning tree always unique?

No. It is unique only if all edge weights are different.
