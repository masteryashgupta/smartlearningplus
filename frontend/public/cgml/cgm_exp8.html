Computer Graphics & Multimedia Lab, 5CS4-21 (Turbo C++)

Experiment 8: Flood fill algorithm

Aim: To implement the flood fill algorithm for filling a rectangle with a given colour.

Source code

#include<stdio.h>
#include<conio.h>
#include<stdlib.h>
#include<graphics.h>

extern unsigned _stklen = 40000U;

void floodfill4(int x, int y, int newcol, int oldcol)
{
    if(getpixel(x, y) == oldcol)
    {
        putpixel(x, y, newcol);
        floodfill4(x + 1, y, newcol, oldcol);
        floodfill4(x - 1, y, newcol, oldcol);
        floodfill4(x, y + 1, newcol, oldcol);
        floodfill4(x, y - 1, newcol, oldcol);
    }
}

void main()
{
    int gd = DETECT, gm, err;
    int col, oldcol;

    clrscr();
    printf("Enter fill colour (1 to 14): ");
    scanf("%d", &col);
    if(col < 1 || col > 14)
    {
        printf("Colour must be between 1 and 14");
        getch();
        exit(0);
    }

    initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");
    err = graphresult();
    if(err != grOk)
    {
        printf("Graphics error: %s", grapherrormsg(err));
        getch();
        exit(1);
    }

    setcolor(WHITE);
    rectangle(100, 100, 160, 140);

    oldcol = getpixel(130, 120);
    floodfill4(130, 120, col, oldcol);

    getch();
    closegraph();
}

The manual's Exp 8 program uses the new graphics.h library for modern compilers and does not run under Turbo C. This version is written for Turbo C++ and fills a rectangle, as the experiment list says.

Before you run

These programs open a graphics screen, so they need the Turbo C++ BGI driver files. Two things to check once:

  1. BGI path: the code uses "C:\\TURBOC3\\BGI" (double backslashes are required in C). It must match the BGI folder of your Turbo C++ install, which holds files such as EGAVGA.BGI. If the program prints "Graphics error", correct this path.
  2. Graphics library: in Turbo C++ choose Options > Linker > Libraries and tick Graphics library. Without it you get "undefined symbol _initgraph" when linking.
  3. File type: save the file with the .C extension (for example EXP4.C) so Turbo C++ compiles it as a C program.

The fill is recursive. Turbo C gives only a 4 KB stack by default, which overflows on thousands of pixels, so the program raises it with extern unsigned _stklen = 40000U;. Keep the rectangle small as shown.

Output

Enter fill colour (1 to 14): 4
(a graphics window opens, a white rectangle is drawn, and its inside is filled with red, colour 4)
Press any key to close it.

Explanation

  1. Idea: Start from a seed pixel inside the shape. The colour of the inside is the old colour. Replace the old colour with the new colour, then do the same for every neighbour that still has the old colour.
  2. floodfill4 checks the pixel with getpixel. If it still has the old colour, it paints it with putpixel and calls itself for the right, left, down and up neighbours. This is called 4-connected fill.
  3. The rectangle border is white, which is not the old colour, so the fill stops there. The area outside is also black, but the fill can never reach it because the closed white border is in the way. If the border had a gap, the colour would leak out.
  4. oldcol is read from the seed pixel, (130, 120), which is inside the rectangle, so the program works for whatever the background colour is.
  5. The fill colour is limited to 1 to 14. Colour 0 (black) is the background, so using it would never end, and colour 15 is the white border.
  6. The stack size is raised with _stklen because each recursive call uses stack space, and about 2300 pixels are filled.

Viva questions

What is a fill algorithm?

A method for colouring all the pixels inside a closed region of the screen.

What are the approaches for filling?

Scan-line fill and seed fill. Seed fill has two forms: flood fill and boundary fill.

What is the flood fill algorithm?

A seed fill that starts at a point inside the region and replaces the old interior colour with the new colour, spreading to all connected neighbours that have the old colour.

What are the steps of the flood fill algorithm?

1) Choose a seed pixel inside the region and read its colour as the old colour. 2) If a pixel has the old colour, change it to the new colour. 3) Repeat for its neighbours (4 or 8). 4) Stop when no neighbour has the old colour.

What is a seed pixel?

The starting pixel, chosen inside the region, from where the filling spreads.

What is the 4-connected approach?

Each pixel is connected to its left, right, top and bottom neighbours.

What is the 8-connected approach?

Each pixel is connected to those four neighbours and also to the four diagonal neighbours.

What is the difference between the 4-connected and 8-connected approaches?

8-connected fill can pass through diagonal gaps and fill regions that 4-connected fill cannot reach, but it can also leak through a boundary that is only diagonally connected. 4-connected is safer for such boundaries.

What are the merits of the flood fill algorithm?

It is simple, it works for any shape, and the boundary may have several colours because only the interior colour matters.

What are the demerits of the flood fill algorithm?

Recursion can overflow the stack on large regions, it is slow because of many getpixel calls, and the whole interior must be one single colour.
