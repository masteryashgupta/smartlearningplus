Experiment 1: Quick Sort Method

THEORY & EXPLANATION · English + Hinglish
Definition
English

Quick Sort is a divide-and-conquer sorting algorithm. It selects an element from the array called the pivot, and rearranges (partitions) the array so that all elements smaller than the pivot come before it, and all elements greater come after it. The same process is then applied recursively to the two resulting sub-arrays until the whole array is sorted.

Hinglish

Quick Sort ek divide-and-conquer wala sorting algorithm hai. Isme array mein se ek element ko pivot bana lete hain, aur baaki sab elements ko is tarah rearrange karte hain ki pivot se chhote elements uske left mein aa jaayein aur bade elements right mein. Fir yehi process left aur right dono parts pe dobara (recursively) chalate hain, jab tak pura array sorted na ho jaaye.

How It Works (Algorithm Steps)
  1. Choose a pivot — in this program, the last element of the array/sub-array is picked as the pivot.
  2. Partition — go through the array and move every element smaller than the pivot to its left side, and every element larger to its right side. After this step, the pivot lands exactly at its correct sorted position.
  3. Recurse on the left part — apply the same Quick Sort process to all elements before the pivot.
  4. Recurse on the right part — apply the same Quick Sort process to all elements after the pivot.
  5. Base case — a sub-array with 0 or 1 element is already sorted, so recursion stops there.
Hinglish

Sabse pehle last element ko pivot bana lete hain. Fir partition() function chalta hai jo array ko is tarah todta hai ki pivot se chhote number left mein aur bade number right mein chale jaayein — is process ke baad pivot apni final sorted position pe pahunch jaata hai. Uske baad wahi function left wale part pe aur right wale part pe alag-alag call hota hai (recursion), jab tak har chhota sa part sirf 1 ya 0 element ka na reh jaaye — wahi base case hai jahan recursion ruk jaata hai.

Example Walkthrough
Example

Let's sort [10, 7, 8, 9, 1, 5] using Quick Sort:

Step-by-step trace (pivot = last element) Initial array: [10, 7, 8, 9, 1, 5] pivot = 5 Partition around 5: [1] 5 [10, 7, 8, 9] → 5 is now at its correct position (index 1) Left sub-array [1]: already sorted (1 element) Right sub-array [10, 7, 8, 9] pivot = 9 Partition around 9: [10, 7, 8] 9 [] → 9 is now at its correct position Sub-array [10, 7, 8] pivot = 8 Partition around 8: [7] 8 [10] → 8 fixed Final merged result: [1, 5, 7, 8, 9, 10]
Hinglish

Dekh kaise chal raha hai: 5 ko pivot banaya, usse chhote number (1) uske left mein chala gaya aur bade number (10, 7, 8, 9) right mein — ab 5 apni sahi jagah pe fix ho gaya. Ab yehi kaam left part [1] pe (jo already sorted hai, kuch karne ki zarurat nahi) aur right part [10, 7, 8, 9] pe alag se hota hai. Ye process tab tak chalta rehta hai jab tak har part 1 element ka na reh jaaye — end mein sab jagah pivot fix hote hote pura array sorted ban jaata hai: [1, 5, 7, 8, 9, 10].

Hinglish

Normal (random data) case mein Quick Sort O(n log n) time leta hai, jo kaafi fast hai. Lekin worst case mein (jaise agar array pehle se hi sorted ho aur pivot hamesha last element ho), ye O(n²) tak slow ho sakta hai kyunki partition har baar sirf ek element ko alag karta hai. Isi wajah se practical implementations mein random pivot ya median-of-three jaisi techniques use ki jaati hain worst case avoid karne ke liye.

Output Scenario (What the Program Actually Does)
English

When you run exp1.c, the program first asks you how many elements to sort. It then uses rand() (seeded with the current time via srand(time(NULL))) to generate that many random numbers between 0 and 999, and prints them as the Unsorted Array. It then starts a timer using clock(), runs the quickSort() function on the array, stops the timer, and prints the same array — now rearranged in ascending order — as the Sorted Array. Finally, it prints the Execution Time, which is the CPU time taken purely by the sorting step (not including input/output), calculated as (end - start) / CLOCKS_PER_SEC.

Hinglish

Program chalate hi sabse pehle pucha jaata hai kitne elements sort karne hain. Fir random numbers generate hote hain (0 se 999 ke beech) aur unhe Unsorted Array ke naam se print kar diya jaata hai. Uske baad clock() se ek timer start hota hai, quickSort() function chalta hai jo array ko sort kar deta hai, timer stop hota hai, aur wahi array ab sorted form mein Sorted Array ke naam se print hota hai. Last mein Execution Time print hota hai — ye bas sorting mein lagne wala actual CPU time hai (input/output ka time isme count nahi hota), seconds mein. Numbers har run pe alag-alag aayenge kyunki random hain, lekin logic aur output ka format hamesha same rahega.
